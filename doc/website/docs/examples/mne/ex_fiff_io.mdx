# ex_fiff_io

Example of the FiffIO interface class.

**Libraries:** [MNE Core](../../api/mne/index.mdx), [FIFF I/O](../../api/fiff/index.mdx)

## Build and run

```bash
cmake --build build/developer-dynamic --target ex_fiff_io
./out/Release/examples/ex_fiff_io
```

The default inputs come from the [MNE sample dataset](../../manual/sample-dataset.mdx).
