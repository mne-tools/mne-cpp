# mne_edf2fiff

## Overview

`mne_edf2fiff` converts EDF (European Data Format), EDF+ and BioSemi BDF files to FIFF. It reads the file with
`BIDSLIB::EDFReader`, so the samples match `mne.io.read_raw_edf` / `mne.io.read_raw_bdf`.

## Usage

```bash
mne_edf2fiff --fileIn <file> [--fileOut <file>]
```

## Options

| Option | Description |
|---|---|
| `--fileIn <file>` | Input `.edf` or `.bdf` file **(required)** |
| `--fileOut <file>` | Output FIFF file (default: same name with `.fif` extension) |

## Description

Each channel is scaled from its physical dimension (µV, mV, V) to SI units, so voltages are stored in volts.
Channels named `Status` or `Trigger` become stim channels holding the low 17 bits of their value (the raw value for BDF). Other channel types are
taken from the label (EEG, ECoG, sEEG, MEG, ECG, EOG, EMG); unrecognised labels are EEG, as in MNE-Python.

### Limitations

- Only the channels sampled at the highest rate are converted; channels sampled more slowly are skipped
- Interrupted (EDF+D) recordings are **not** supported
- EDF+ annotations are not converted

## Example

```bash
mne_edf2fiff --fileIn recording.edf --fileOut recording_raw.fif
```
