# mne_inverse_operator

## Overview

`mne_inverse_operator` assembles a linear inverse operator from a forward solution and noise covariance matrix. It supports advanced options for source orientation, regularization, and output formats.

This is a C++ port of the original MNE-C tool by Matti Hämäläinen.

## Usage

```bash
mne_inverse_operator [options]
```

## Options

| Option | Description |
|---|---|
| `--fwd <file>` | Input forward solution file (required) |
| `--noisecov, --senscov <file>` | The noise (sensor) covariance matrix file. |
| `--srccov <file>` | Source covariance matrix file (default: identity). |
| `--meg` | Use MEG channels only |
| `--eeg` | Use EEG channels only |
| `--fixed` | Fixed source orientations |
| `--loose <amount>` | Loose orientation constraint (0=fixed, 1=free) |
| `--depth` | Depth weighting exponent |
| `--weightexp <value>` | Depth weighting exponent (0.0-1.0, default: 0.8). |
| `--weightlimit <value>` | Depth weighting upper limit (default: 10.0). |
| `--nodepth` | Disable depth weighting. |
| `--reg <amount>` | Regularization factor for all channel types. |
| `--magreg <amount>` | Regularization factor for magnetometers (default: 0.1). |
| `--gradreg <amount>` | Regularization factor for gradiometers (default: 0.1). |
| `--eegreg <amount>` | Regularization factor for EEG channels (default: 0.1). |
| `--diagnoise` | Omit off-diagonal terms from the noise covariance matrix. |
| `--proj <file>` | Load SSP projectors from file (can be repeated). |
| `--bad <file>` | Mark channel as bad (repeatable) |
| `--inv <file>` | Output file for the inverse operator (default: `<fwd>`-inv.fif). |

## Description

This tool creates a linear inverse operator for source localization. It supports loose/fixed orientation, depth weighting, and channel selection. The output is a FIFF inverse operator file compatible with MNE-CPP and MNE-Python.
