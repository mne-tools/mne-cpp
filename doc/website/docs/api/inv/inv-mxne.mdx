# InvMxne

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

:::info[Python equivalent]
`mne.inverse_sparse.mixed_norm` in MNE-Python.
:::

`#include <inv/inv_mxne.h>`

```cpp
class INVLIB::InvMxne
```

Mixed-Norm Estimate (MxNE) sparse inverse solver.

Minimizes: 0.5 * ||M - G*X||^2_F + alpha * sum_i ||X_i||_2, the objective of mne.inverse_sparse.mixed_norm (without debiasing) using an Iteratively Reweighted Least Squares (IRLS) approach for the L21-norm (group lasso).

MxNE sparse inverse solver.

```cpp title="src/examples/ex_inv_api/main.cpp"
// Whitened data and a gain per nAm make the noise level 1, as mne.inverse_sparse.mixed_norm does.
const auto [whitener, rank] = computeWhitener(*inverse.noise_cov); // rank 360: 364 channels minus 4 projectors
QFile fixedFile(fwdFile.fileName());
const MNEForwardSolution fixedFwd = MNEForwardSolution(fixedFile, true, true).pick_regions({v1}).pick_channels(inverse.noise_cov->names);
const MatrixXd gain = whitener * fixedFwd.sol->data * 1e-9;
const MatrixXd measured = whitener * evoked.pick_channels(inverse.noise_cov->names).data.middleCols(170, 40); // 83-148 ms
const double alphaMax = (gain.transpose() * measured).rowwise().norm().maxCoeff();
const InvMxneResult mxne = InvMxne::compute(gain, measured, 0.5 * alphaMax, 1000, 1e-10);
```

## Static Methods

### compute(matGain, matData, alpha, nIterations, tolerance)

Compute the MxNE inverse solution.

**Parameters:**

- **matGain** : *const Eigen::MatrixXd &*
  Forward gain matrix (n_channels x n_sources).

- **matData** : *const Eigen::MatrixXd &*
  Measurement data (n_channels x n_times).

- **alpha** : *double*
  Regularization parameter.

- **nIterations** : *int*
  Maximum number of IRLS iterations.

- **tolerance** : *double*
  Convergence tolerance on weight change.

**Returns:**

- *InvMxneResult* — The MxNE result containing the sparse source estimate.
