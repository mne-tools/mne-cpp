# InvEcdSet

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Inverse Library &nbsp;·&nbsp; **Source:** [`inv/dipole_fit/inv_ecd_set.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/inv/dipole_fit/inv_ecd_set.h)

class mne::InvEcdSet

Implements Electric Current Dipole Set (Replaces *ecdSet,ecdSetRec struct of MNE-C fit_types.h).

Holds a set of Electric Current Dipoles.

```cpp title="src/examples/ex_inv_dipole_fit/main.cpp"
InvDipoleFitSettings settings; // the options of the MNE-C mne_dipole_fit tool
settings.measname = tmp.filePath("synthetic-ave.fif").toStdString();
settings.include_meg = true;
settings.include_eeg = false;
settings.guess_mindist = 0.0f;
settings.tmin = 0.0f;
settings.dipname = tmp.filePath("fit.dat").toStdString(); // MNE-C .dat dipole file
settings.checkIntegrity();
InvDipoleFit fit(&settings);
InvEcdSet dipoles = fit.calculateFit();
const std::filesystem::path dipPath = tmp.filePath("fit.dip").toStdU16String();
const bool saved = dipoles.save_dipoles_dip(dipPath); // readable by mne.read_dipole
const InvEcdSet reread = InvEcdSet::read_dipoles_dip(dipPath);
```

## Static Methods

### read_dipoles_dip(path)

Read dipoles from the dip format compatible with mrilab, as written by save_dipoles_dip, MNE-C and MNE-Python (whose khi^2 and free columns are read too).

**Parameters:**

- **path** : *const std::filesystem::path &*
  File to read from.

**Returns:**

- *[InvEcdSet](/docs/api/inv/inv-ecd-set)* — The dipole set read from the file; empty if the file could not be read or holds a malformed line.

settings.dipname = tmp.filePath("fit.dat").toStdString(); // MNE-C .dat dipole file
settings.checkIntegrity();
InvDipoleFit fit(&settings);
InvEcdSet dipoles = fit.calculateFit();
const std::filesystem::path dipPath = tmp.filePath("fit.dip").toStdU16String();
const bool saved = dipoles.save_dipoles_dip(dipPath); // readable by mne.read_dipole
const InvEcdSet reread = InvEcdSet::read_dipoles_dip(dipPath);
const Vector3d posMm = dipoles.size() > 0 ? Vector3d(1e3 * dipoles[0].rd.cast<double>()) : Vector3d::Zero();
ok &= expect(saved && dipoles.size() == 1 && dipoles[0].valid && (posMm - mnePosMm).norm() < 1.0 && std::abs(100.0 * dipoles[0].good - 99.99996959113513) < 0.01 && dipoles[0].nfree == 297 && reread.size() == 1 && (reread[0].rd - dipoles[0].rd).norm() < 1e-4f,
             "InvDipoleFitSettings/InvDipoleFit/InvEcdSet: the pipeline fit matches mne.fit_dipole and round-trips through .dip");

### [ex_disp3d_scene](../../examples/viz_qt/ex_disp3d_scene.mdx)

Disp3D scene data: sensor-to-surface interpolation, electrodes, MRI slices, video overlay and layers.

````cpp title="src/examples/ex_disp3d_scene/main.cpp, line 270"
InvEcdSet dipoles;
InvEcd strong;
strong.rd = Vector3f(0.0f, 0.0f, 0.05f);
strong.Q = Vector3f(0.0f, 0.0f, 20e-9f);
InvEcd weak;
weak.rd = Vector3f(0.03f, 0.0f, 0.05f);
weak.Q = Vector3f(10e-9f, 0.0f, 0.0f);
dipoles.push_back(strong);
dipoles.push_back(weak);
DipoleObject dipoleGlyphs;
dipoleGlyphs.load(dipoles); // one cone per dipole, scaled by moment
float dipoleDistance = 0.0f;
const int pickedDipole = dipoleGlyphs.intersect(QVector3D(0.03f, 0.0f, 0.2f), QVector3D(0.0f, 0.0f, -1.0f), dipoleDistance);
````
