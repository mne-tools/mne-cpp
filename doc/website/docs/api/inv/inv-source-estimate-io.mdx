# InvSourceEstimateIO

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

:::info[Python equivalent]
`mne.SourceEstimate.save / read` in MNE-Python.
:::

`#include <inv/inv_source_estimate_io.h>`

```cpp
class INVLIB::InvSourceEstimateIO
```

Extended I/O methods for [`InvSourceEstimate`](/docs/api/inv/inv-source-estimate).

```cpp title="src/examples/ex_inv_api/main.cpp"
InvSourceEstimateIO::writeCsv(stc, tmp.filePath("v1-dspm.csv"));
const InvSourceEstimate fromCsv = InvSourceEstimateIO::readCsv(tmp.filePath("v1-dspm.csv"));
QFile stcFile(tmp.filePath("v1-dspm-lh.stc"));
InvSourceEstimate(stc).write(stcFile); // MNE .stc format, readable by mne.read_source_estimate
QFile stcBack(stcFile.fileName());
const InvSourceEstimate fromStc(stcBack);
```

---

## Static Methods

### writeCsv(stc, sPath, cDelim)

Export source estimate to CSV format.

Writes a header line with vertex indices, then one row per time point. First column is time (seconds).

**Parameters:**

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate to export.

- **sPath** : *const QString &*
  Output file path.

- **cDelim** : *char*
  Delimiter character (default comma).

**Returns:**

- *bool* — true if successful.

---

### readCsv(sPath, cDelim)

Read source estimate from CSV format.

**Parameters:**

- **sPath** : *const QString &*
  Input file path.

- **cDelim** : *char*
  Delimiter character (default comma).

**Returns:**

- *[InvSourceEstimate](/docs/api/inv/inv-source-estimate)* — Source estimate (empty if failed).

---

### writeMatrix(stc, sPath)

Export source estimate as a tab-separated matrix for easy import.

No header; pure numeric matrix (n_vertices × n_times).

**Parameters:**

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate to export.

- **sPath** : *const QString &*
  Output file path.

**Returns:**

- *bool* — true if successful.
