# InvVolumeSourceEstimate

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

:::info[Python equivalent]
`mne.VolumeSourceEstimate` in MNE-Python.
:::

`#include <inv/inv_volume_source_estimate.h>`

```cpp
class INVLIB::InvVolumeSourceEstimate
```

Volume source estimate: scalar values at voxel locations.

Extends [`InvSourceEstimate`](/docs/api/inv/inv-source-estimate) with grid shape information to allow reshaping the flat data into a 3D volume.

```cpp title="src/examples/ex_inv_api/main.cpp"
// A volume estimate keeps the grid shape, so a time slice can be written back into the full grid.
InvVolumeSourceEstimate volumeStc(stc.data.topRows(4), VectorXi::LinSpaced(4, 0, 6), stc.tmin, stc.tstep);
volumeStc.setShape({2, 2, 2}); // 8 voxels, 4 of them sources
const VectorXd grid = volumeStc.toVolume(200);
```

### toVolume(timeIdx)

Extract a 3D volume for a given time point, filling the grid with zeros where no source is active.

**Parameters:**

- **timeIdx** : *int*
  Time sample index.

**Returns:**

- *Eigen::VectorXd* — Flattened volume (nx*ny*nz) with values at active voxels.

### centreOfMass(timeIdx)
