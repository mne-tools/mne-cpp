# InvGuessData

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

`#include <inv/inv_guess_data.h>`

```cpp
class INVLIB::InvGuessData
```

Implements [`InvGuessData`](/docs/api/inv/inv-guess-data) (Replaces *guessData,guessDataRec struct of MNE-C fit_types.h).

Precomputed guess point grid with forward fields for initial dipole position candidates.

```cpp title="src/examples/ex_inv_dipole_fit/main.cpp"
// MEG channels and SSP projectors from the sample file, sphere at (0, 0, 40) mm, ad-hoc noise
// (5e-13 T/m gradiometers, 20 fT magnetometers).
Vector3f r0(0.0f, 0.0f, 0.04f);
std::unique_ptr<InvDipoleFitData> fitData(InvDipoleFitData::setup_dipole_fit_data(
    QString(), sampleAve, QString(), &r0, nullptr, false, QString(), QString(),
    5e-13f, 20e-15f, 0.2e-6f, 0.1f, 0.1f, 0.1f, false, {sampleAve}, true, false));
MatrixXf gain(fitData->nmeg, 3);
const bool fieldOk = InvDipoleFitData::compute_dipole_field(*fitData, truePos, false, gain) == 0; // projected, not whitened
VectorXf field = gain * trueMoment;

InvGuessData guesses(QString(), QString(), 0.0f, 0.02f, 0.015f, fitData.get(), 0.08f); // 15 mm grid in an 80 mm sphere
std::unique_ptr<InvDipoleForward> atTruth(InvDipoleFitData::dipole_forward_one(fitData.get(), truePos, nullptr));
InvEcd dipole;
VectorXf b = field; // fit_one projects and whitens in place
const bool fitted = InvDipoleFitData::fit_one(fitData.get(), &guesses, 0.0f, b, false, dipole);
```

### InvGuessData(guessname, guess_surfname, mindist, exclude, grid, f, guessrad)

Constructs the Guess Data from given Data Refactored: make_guess_data (dipole_fit_setup.c).

**Parameters:**

- **guessname** : *const QString &*
  File with a predefined guess point set (empty = build a grid).

- **guess_surfname** : *const QString &*
  Surface file bounding the guess grid (empty = inner skull of the BEM, or a sphere).

- **mindist** : *float*
  Minimum distance of guess points from the bounding surface (m).

- **exclude** : *float*
  Exclude guess points closer than this to the sphere origin (m).

- **grid** : *float*
  Spacing of the guess grid (m).

- **f** : *[InvDipoleFitData](/docs/api/inv/inv-dipole-fit-data) **
  Dipole fit data providing the forward model.

- **guessrad** : *float*
  Radius of the spherical guess volume when no surface bounds it (m).
