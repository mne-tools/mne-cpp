### InvGuessData(guessname, guess_surfname, mindist, exclude, grid, f, guessrad)

Constructs the Guess Data from given Data Refactored: make_guess_data (dipole_fit_setup.c).

**Parameters:**

- **guessname** : *const QString &*
  File with a predefined guess point set (empty = build a grid).

- **guess_surfname** : *const QString &*
  Surface file bounding the guess grid (empty = inner skull of the BEM, or a sphere).

- **mindist** : *float*
  Minimum distance of guess points from the bounding surface (m).

- **exclude** : *float*
  Exclude guess points closer than this to the sphere origin (m).

- **grid** : *float*
  Spacing of the guess grid (m).

- **f** : *[InvDipoleFitData](/docs/api/inv/inv-dipole-fit-data) **
  Dipole fit data providing the forward model.

- **guessrad** : *float*
  Radius of the spherical guess volume when no surface bounds it (m).
