# InvFocalDipole

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

`#include <inv/inv_focal_dipole.h>`

```cpp
struct INVLIB::InvFocalDipole
```

Represents a single focal (off-grid) current dipole, typically the result of an equivalent current dipole (ECD) fit.

The dipole has a free 3D position (not constrained to a source-space grid), a current moment, and associated fit quality metrics.

Single focal dipole with free 3D position, moment, and fit-quality metrics.
