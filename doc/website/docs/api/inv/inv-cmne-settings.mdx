# InvCMNESettings

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library &nbsp;·&nbsp; **Source:** [`inv/minimum_norm/inv_cmne_settings.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/inv/minimum_norm/inv_cmne_settings.h)

`#include <inv/inv_cmne_settings.h>`

```cpp
struct INVLIB::InvCMNESettings
```

Settings for the Contextual [MNE](/docs/api/mne/mne-class) (CMNE) inverse solver (Dinh et al.

2021).

CMNE settings

```cpp title="src/examples/ex_inverse_cmne/main.cpp"
InvCMNESettings settings;
settings.lambda2 = 1.0 / 9.0;                           // SNR 3
settings.lookBack = parser.value(lookBackOption).toInt(); // k = 20 samples = 133 ms at 150 Hz
settings.numSources = fwd.nsource;
settings.onnxModelPath = parser.value(onnxOption);      // empty: the paper's control estimate
```
