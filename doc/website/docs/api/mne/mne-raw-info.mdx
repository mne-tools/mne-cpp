# MNERawInfo

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_raw_info.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_raw_info.h)

`#include <mne/mne_raw_info.h>`

```cpp
class mne::MNERawInfo
```

Information about raw data in a FIFF file.

```cpp title="src/examples/ex_mne_api/main.cpp"
// MNE-C style reader: buffer directory, channel selection, projection and overlap-add filter
MNEFilterDef filter; // 40 Hz lowpass, 5 Hz transition, 4096-sample blocks
filter.filter_on = true;
filter.size = 4096;
filter.taper_size = 2048;
filter.lowpass = filter.eog_lowpass = 40.0f;
filter.lowpass_width = filter.eog_lowpass_width = 5.0f;
std::unique_ptr<MNERawData> mneRaw(MNERawData::open_file(rawFile.fileName().toStdU16String(), false, false, filter));
const MNERawInfo& rawInfo = *mneRaw->info;
const MNERawBufDef& firstBuffer = mneRaw->bufs.front();

MNEChSelection sel; // channel names are stored without spaces
sel.chspick = sel.chspick_nospace = {"MEG 0113", "EEG 001", "EOG 061"};
sel.pick_deriv = VectorXi::Constant(sel.nchan(), -1);
sel.pick.resize(sel.nchan());
for (int c = 0; c < sel.nchan(); ++c) {
    sel.pick[c] = static_cast<int>(mne::index_of(mneRaw->ch_names, sel.chspick[c]));
}

const int ns = 25;
MNERawData::RowMajorMatrixXf segment(sel.nchan(), ns);
mneRaw->pick_data(&sel, mneRaw->first_samp + 2990, segment); // calibrated, across a buffer boundary
const double eegRaw = segment(1, 0);
mneRaw->pick_data_filt(&sel, mneRaw->first_samp + 2990, segment);
const double eegFilt = segment(1, 0);

// The file stores its 4 SSP projectors as inactive; make_projection switches them on
std::unique_ptr<MNEProjOp> proj = MNEProjOp::make_projection({rawFile.fileName().toStdU16String()}, rawInfo.chInfo).value();
proj->assign_channels(mneRaw->ch_names);
const bool compiled = proj->make_proj();
const MNEProjItem& firstItem = proj->items[0];
mneRaw->proj = std::move(proj);
mneRaw->pick_data_proj(&sel, mneRaw->first_samp + 2990, segment);
const double eegProj = segment(1, 0);
```

## Static Methods

### find_meas(node)

Finds the nearest FIFFB_MEAS parent node in the FIFF directory tree.

Walks up the tree from the given node by following parent pointers until a node of type FIFFB_MEAS is found.

**Parameters:**

- **node** : *const std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  Starting node from which to search upward.

**Returns:**

- *std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt;* — Shared pointer to the enclosing FIFFB_MEAS node, or an empty shared pointer if no such node is found.

---

### find_meas_info(node)

Finds the FIFFB_MEAS_INFO child node within the nearest FIFFB_MEAS block.

First locates the enclosing FIFFB_MEAS node by walking up the tree from the given node, then searches its immediate children for a node of type FIFFB_MEAS_INFO.

**Parameters:**

- **node** : *const std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  Starting node from which to search.

**Returns:**

- *std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt;* — Shared pointer to the FIFFB_MEAS_INFO node, or an empty shared pointer if not found.

---

### find_raw(node)

Finds the raw data block in the FIFF directory tree.

Searches the tree under the given node for a FIFFB_RAW_DATA block. If none is found, falls back to searching for a FIFFB_CONTINUOUS_DATA block.

**Parameters:**

- **node** : *const std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  Root node of the subtree to search.

**Returns:**

- *std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt;* — Shared pointer to the raw data directory node, or an empty shared pointer if neither raw nor continuous data blocks are found.

---

### find_maxshield(node)

Finds the MaxShield raw data block in the FIFF directory tree.

Searches the tree under the given node for a FIFFB_SMSH_RAW_DATA block, which contains [SSS](/docs/api/dsp/sss)/MaxShield processed raw data.

**Parameters:**

- **node** : *const std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  Root node of the subtree to search.

**Returns:**

- *std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt;* — Shared pointer to the MaxShield raw data directory node, or an empty shared pointer if no such block is found.

### get_meas_info(stream, node, id, nchan, sfreq, highpass, lowpass, chp, trans, start_time)

Reads measurement information from the nearest FIFFB_MEAS_INFO parent of a node.

Extracts channel information, sampling frequency, filter parameters, coordinate transformation (device-to-head), and measurement ID from the FIFF file. Lowpass and highpass default to sfreq/2 and 0 respectively if not explicitly present in the file.

**Parameters:**

- **stream** : *[FiffStream](/docs/api/fiff/fiff-stream) &*
  Open FIFF stream to read tags from.

- **node** : *std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  Starting directory node (typically the raw data node).

- **id** : *std::unique_ptr&lt; [FiffId](/docs/api/fiff/fiff-id) &gt; &*
  Measurement ID (managed via unique_ptr). Reset if absent.

- **nchan** : *int **
  Number of channels.

- **sfreq** : *float **
  Sampling frequency in Hz.

- **highpass** : *float **
  Highpass filter cutoff frequency in Hz.

- **lowpass** : *float **
  Lowpass filter cutoff frequency in Hz.

- **chp** : *std::vector&lt; [FiffChInfo](/docs/api/fiff/fiff-ch-info) &gt; &*
  List of channel information structures, one per channel.

- **trans** : *[FiffCoordTrans](/docs/api/fiff/fiff-coord-trans) &*
  Device-to-head coordinate transformation.

- **start_time** : *[FiffTime](/docs/api/fiff/fiff-time) &*
  Measurement start time. Populated from FIFF_MEAS_DATE if present; otherwise from the measurement ID time; otherwise zeroed.

**Returns:**

- *int* — 0 on success, -1 on failure.

### load(name, allow_maxshield, infop)

Loads raw data information from a FIFF file.

Opens the specified FIFF file, locates the raw data block (or MaxShield data block if allowed and no standard raw data is found), reads the measurement information, determines the buffer size from the first data buffer tag, and assembles a complete [`MNERawInfo`](/docs/api/mne/mne-raw-info) structure.

**Parameters:**

- **name** : *const std::filesystem::path &*
  Path to the FIFF file to load.

- **allow_maxshield** : *int*
  If non-zero, fall back to MaxShield ([`SSS`](/docs/api/dsp/sss)) data when no standard raw data block is found.

- **infop** : *std::unique_ptr&lt; [MNERawInfo](/docs/api/mne/mne-raw-info) &gt; &*
  Pointer to receive the newly allocated [`MNERawInfo`](/docs/api/mne/mne-raw-info) structure. Only valid on success.

**Returns:**

- *int* — FIFF_OK on success, FIFF_FAIL on failure.
