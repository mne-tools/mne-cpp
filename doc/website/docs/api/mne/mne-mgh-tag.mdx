# MNEMghTag

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library

`#include <mne/mne_mgh_tag.h>`

```cpp
class MNELIB::MNEMghTag
```

Single tag entry in a FreeSurfer MGH/MGZ file header.

MGH files can carry optional typed metadata tags in the file footer. Each tag has an integer identifier, a byte length, and a raw payload.

## Example

No example of its own: Raw FreeSurfer MGH tag record kept by the surface reader inside MNESourceSpace; never constructed by callers.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// A FreeSurfer surface with its curvature and the volume geometry from the file footer
const auto white = MNESourceSpace::load_surface(data + "/subjects/sample/surf/lh.white", data + "/subjects/sample/surf/lh.curv");
const MNEVolGeom& geometry = *white->vol_geom; // sizes and centre converted to metres
````
