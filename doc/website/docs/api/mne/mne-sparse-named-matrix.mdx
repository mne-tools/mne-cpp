# MNESparseNamedMatrix

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_sparse_named_matrix.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mne/mne_sparse_named_matrix.h)

Sparse named matrix - matrix specification with row/column name lists.

```cpp title="src/examples/ex_mne_api/main.cpp"
// A bipolar EOG-like montage in MNE-C's text syntax, saved as a derivation file and applied while reading raw data
const QString montage = tmp.filePath("montage.txt");
QFile montageFile(montage);
ok &= montageFile.open(QIODevice::WriteOnly | QIODevice::Text);
montageFile.write("\"EEG 001-EEG 002\" = \"EEG 001\" - \"EEG 002\"\n\"FRONT\" = 0.5 * \"EEG 001\" + 0.5 * \"EEG 002\" - \"EEG 999\"\n");
montageFile.close();
const auto derivations = MNEDerivSet::readText(montage.toStdU16String());
derivations->write(tmp.filePath("montage-deriv.fif").toStdU16String());
const auto fromFif = MNEDerivSet::read(tmp.filePath("montage-deriv.fif").toStdU16String());
const int usable = mneRaw->attachDerivations(*fromFif); // FRONT needs EEG999 and is dropped
MNEChSelection bipolar;
bipolar.chspick = bipolar.chspick_nospace = {"EEG 001-EEG 002", "EEG 001", "EEG 002"};
bipolar.pick = (VectorXi(3) << -1, mne::index_of(mneRaw->ch_names, "EEG 001"), mne::index_of(mneRaw->ch_names, "EEG 002")).finished();
bipolar.pick_deriv = (VectorXi(3) << 0, -1, -1).finished();
mneRaw->proj.reset();
mneRaw->pick_data(&bipolar, mneRaw->first_samp + 2990, segment);
```

## Static Methods

### read(stream, node, kind)

Reads a sparse named matrix (MNE-C `mne_read_sparse_named_matrix`).

**Parameters:**

- **stream** : *[FiffStream](/docs/api/fiff/fiff-stream) &*
  An open FIFF stream.

- **node** : *const std::shared_ptr&lt; [FiffDirNode](/docs/api/fiff/fiff-dir-node) &gt; &*
  A `FIFFB_MNE_NAMED_MATRIX` block, or a block whose direct children contain one.

- **kind** : *int*
  The tag holding the sparse matrix.

**Returns:**

- *std::unique_ptr&lt; MNESparseNamedMatrix &gt;* — The matrix, or nullptr if it is missing or its name lists do not fit.
