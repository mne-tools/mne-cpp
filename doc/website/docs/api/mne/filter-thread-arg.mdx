# FilterThreadArg

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/filter_thread_arg.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/filter_thread_arg.h)

`#include <mne/filter_thread_arg.h>`

```cpp
class MNELIB::FilterThreadArg
```

Implements a Filter Thread Argument (Replaces *filterThreadArg,filterThreadArgRec; struct of MNE-C filter_source_space.c).

Thread-local arguments for parallel raw data filtering (channel range, filter kernel, buffer).

---

## Public Methods

### FilterThreadArg()

---

### ~FilterThreadArg()

## Example

No example of its own: Per-thread work item of the parallel source-space filter inside MNESourceSpace::filter_source_space; built and consumed only there, never by callers.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// Drop sources outside the inner skull or closer than 5 mm to it (mne make_forward_solution(mindist=5))
std::vector<std::unique_ptr<MNESourceSpace>> spaces;
MNESourceSpace::read_source_spaces(srcFile.fileName(), spaces);
const FiffCoordTrans mriHeadT = FiffCoordTrans::readTransform(data + "/MEG/sample/all-trans.fif", FIFFV_COORD_MRI, FIFFV_COORD_HEAD);
MNESourceSpace::filter_source_spaces(0.005f, data + "/subjects/sample/bem/sample-5120-bem.fif", mriHeadT, spaces, nullptr, true);
````
