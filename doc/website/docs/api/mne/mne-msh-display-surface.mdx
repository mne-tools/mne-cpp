# MNEMshDisplaySurface

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library

`#include <mne/mne_msh_display_surface.h>`

```cpp
class MNELIB::MNEMshDisplaySurface
```

Replaces *mshDisplaySurface, mshDisplaySurfaceRec struct (analyze_types.c).

The [`MNE`](/docs/api/mne/mne-class) Msh Display [FsSurface](/docs/api/fs/fs-surface) class holds information about a surface to be rendered.

```cpp title="src/examples/ex_mne_api/main.cpp"
// Total solid angle seen from a point: 4 pi inside a closed surface, 0 outside
auto skull = MNESurface::read_bem_surface2(bemFile.fileName(), FIFFV_BEM_SURF_ID_BRAIN, true);
skull->compute_surface_cm();
const double inside = skull->sum_solids(Map<const Vector3f>(skull->cm)) / (4.0 * M_PI);
const double outside = skull->sum_solids(Vector3f(0.0f, 0.0f, 0.2f)) / (4.0 * M_PI);

// The same surface as an MNE-C viewer display surface
MNEMshDisplaySurfaceSet display;
display.add_bem_surface(bemFile.fileName(), FIFFV_BEM_SURF_ID_BRAIN, "inner skull", 1, 1); // checks closure
const MNEMshDisplaySurface& shown = *display.surfs[0];
```

### align_fiducials(head_dig, mri_dig, niter, scale_head, omit_dist, scales)

Align MEG and MRI coordinate systems using fiducial points and ICP.

**Parameters:**

- **head_dig** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  MEG digitizer data (transformed in-place).

- **mri_dig** : *const [FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  MRI digitizer data with fiducial locations.

- **niter** : *int*
  Number of ICP iterations.

- **scale_head** : *int*
  If non-zero, scale the head surface to match digitizer.

- **omit_dist** : *float*
  Discard digitizer points farther than this from the surface (m).

- **scales** : *Eigen::Vector3f &*
  If non-null, receives the per-axis scale factors applied.

**Returns:**

- *int* — OK on success, FAIL on error.

---

### get_head_scale(dig, mri_fid, scales)

Compute a uniform head scale factor by fitting spheres.

**Parameters:**

- **dig** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  Digitizer data; points with positive z are used for the sphere fit.

- **mri_fid** : *const Eigen::Matrix3f &*
  MRI fiducial locations (LPA, nasion, RPA rows), in m.

- **scales** : *Eigen::Vector3f &*
  Receives the per-axis scale factors (all set to 1 if a sphere fit fails).

---

### discard_outlier_digitizer_points(d, maxdist)

Mark digitizer points whose distance to the head surface exceeds maxdist.

**Parameters:**

- **d** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  Digitizer data; its discard flags and distances are updated.

- **maxdist** : *float*
  Maximum allowed distance to the surface, in m; cardinal and HPI points are never discarded.

**Returns:**

- *int* — Number of points discarded.

---

### calculate_digitizer_distances(dig, do_all, do_approx)

Compute the distance from each active digitizer point to the head surface.

**Parameters:**

- **dig** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  Digitizer data; dist, closest and closest_point are updated.

- **do_all** : *bool*
  If true, include inactive and discarded points.

- **do_approx** : *bool*
  If true, start the closest-point search from the previously found triangles.

---

### iterate_alignment_once(dig, nasion_weight, nasion_mri, last_step)

Perform one iteration of ICP-like alignment.

**Parameters:**

- **dig** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  Digitizer data; head_mri_t_adj and distances are updated.

- **nasion_weight** : *int*
  Weight of the nasion point in the Procrustes fit.

- **nasion_mri** : *const std::optional&lt; Eigen::Vector3f &gt; &*
  Optional fixed MRI location of the nasion, in m.

- **last_step** : *int*
  Non-zero if this is the final iteration (enables exact distances).

**Returns:**

- *int* — OK on success, FAIL if no adjustable transform exists, fewer than 3 points are active, or the fit fails.

---

### rms_digitizer_distance(dig)

Compute the RMS distance from active digitizer points to the head surface.

**Parameters:**

- **dig** : *[FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &*
  Digitizer data; distances are recomputed if not valid.

**Returns:**

- *float* — RMS distance of the active, non-discarded points, in m.

### decide_curv_display(name)

Set the curvature display mode based on a surface type name.

Inflated, sphere, and white surfaces use overlay mode; others use none.

**Parameters:**

- **name** : *const QString &*
  FsSurface type name.
