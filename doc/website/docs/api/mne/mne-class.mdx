# MNE

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne.h)

`#include <mne/mne.h>`

```cpp
class MNELIB::MNE
```

DECLARE [`MNE`](/docs/api/mne/mne-class) WRAPPER CLASS.

The [`MNE`](/docs/api/mne/mne-class) class provides wrapper functions to stay consistent with mne matlab toolbox.

```cpp title="src/examples/ex_mne_api/main.cpp"
// The MNE facade mirrors the MNE-Matlab/Python toolbox functions
const QString eveName = tmp.filePath("audvis-eve.fif");
{
    QFile eveOut(eveName);
    MNE::write_events_to_fif(eveOut, events.events);
}
MatrixXi eventsBack;
MNE::read_events(eveName, rawFile.fileName(), eventsBack);
QList<FiffProj> projs = raw.info.projs; // stored inactive in the raw file
FiffProj::activate_projs(projs);
MatrixXd ssp; // like mne._fiff.proj.make_projector(info['projs'], ch_names, bads)
const int nProj = MNE::make_projector(projs, raw.info.ch_names, ssp, raw.info.bads);
```

### compute_epoch_covariance(raw, events, eventCodes, tmin, tmax, bmin, bmax, doBaseline, removeMean)

compute_epoch_covariance

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  The raw data.

- **events** : *const Eigen::MatrixXi &*
  Event matrix (nEvents x 3): [sample, before, after].

- **eventCodes** : *const QList&lt; int &gt; &*
  Which event codes to include.

- **tmin** : *float*
  Start of time window relative to event (seconds).

- **tmax** : *float*
  End of time window relative to event (seconds).

- **bmin** : *float*
  Baseline start (seconds, relative to event). Only used if doBaseline is true.

- **bmax** : *float*
  Baseline end (seconds, relative to event). Only used if doBaseline is true.

- **doBaseline** : *bool*
  Whether to apply baseline correction before covariance computation.

- **removeMean** : *bool*
  Whether to remove sample mean from the covariance estimate.

**Returns:**

- *[FiffCov](/docs/api/fiff/fiff-cov)* — The computed noise covariance matrix, or empty FiffCov on failure.
