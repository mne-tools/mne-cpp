**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_nearest.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_nearest.h)

Implements the MNE Nearest description (Replaces *mneNearest,mneNearestRec; struct of MNE-C `mne_types.h`).

## Example

No example of its own: Per-vertex nearest-source record stored in MNESurfaceOrVolume::nearest; filled while reading a source space.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
const QString srcPath = data + "/subjects/sample/bem/sample-oct-6-src.fif";
const MNESourceSpaces src(srcPath.toStdU16String()); // with normals, triangle data and patches
const auto& lh = dynamic_cast<const MNEHemisphere&>(src[0]);
std::vector<VectorXi> vertno = src.get_vertno(); // used vertices per hemisphere
````
