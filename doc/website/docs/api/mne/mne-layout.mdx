# MNELayout

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_layout.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mne/mne_layout.h)

`#include <mne/mne/mne_layout.h>`

```cpp
class mne::MNELayout
```

Plotter layout with viewports, channel matching and zoom.

```cpp title="src/examples/ex_mne_api/main.cpp"
// The Neuromag Vectorview layout: one viewport per channel
auto layout = MNELayout::read((layoutDir + "/Vectorview-all.lout").toStdU16String());
const std::map<std::string, Eigen::Vector2d> positions = layout->channelPositions();                                  // lower-left corners, keyed "MEG 0113"
const int leftHalf = layout->confine(Eigen::AlignedBox2d(Eigen::Vector2d(-85.0, -83.0), Eigen::Vector2d(0.0, 75.0))); // zoom to the left half
const int shownTriplet = layout->matchPorts({"MEG 0113", "MEG 0112", "MEG 0111"});
```

---

## Public Methods

### channelPositions()

Returns the lower-left corner of every channel's viewport, keyed by the name in the file.

**Returns:**

- *std::map&lt; std::string, Eigen::Vector2d &gt;* — Channel name -&gt; viewport origin; a port listing several channels contributes each of them.

---

### matchPorts(channel)

Marks the visible ports that show `channel` (MNE-C `mne_lout_match_ports`).

**Parameters:**

- **channel** : *std::string_view*
  A channel name in any spelling.

**Returns:**

- *int* — The number of ports marked.

---

### matchPorts(channels)

Matches many channels at once (MNE-C `mne_lout_match_ports_many`) and fills `matches()`.

**Parameters:**

- **channels** : *const mne::StringList &*
  Channel names in any spelling.

**Returns:**

- *int* — The number of port/channel pairs found.

---

### matches()

Returns which port shows which channel after `matchPorts(const mne::StringList&)`.

**Returns:**

- *const Eigen::MatrixXi &* — Ports x channels, 1 where the port shows the channel.

---

### portAt(point)

Returns the port whose interior contains a point.

**Parameters:**

- **point** : *const Eigen::Vector2d &*
  A point in layout coordinates.

**Returns:**

- *int* — The index into ports, or -1.

---

### confine(area)

Zooms to the ports inside `area` (MNE-C `mne_lout_confine`).

The visible area becomes the bounding box of those ports plus a 1 % margin; without any port inside it stays unchanged.

**Parameters:**

- **area** : *const Eigen::AlignedBox2d &*
  The requested area.

**Returns:**

- *int* — The number of ports inside the area.

---

### resetConfine()

Shows the whole layout again.

---

### isVisible(port)

Returns whether a port lies completely inside the visible area.

**Parameters:**

- **port** : *const [MNELayoutPort](/docs/api/mne/mne-layout-port) &*
  A port of this layout.

**Returns:**

- *bool* — True if the port is visible.

---

### extent()

Returns the drawing area given on the first line of the file.

**Returns:**

- *const Eigen::AlignedBox2d &* — The extent in layout coordinates.

---

### visibleArea()

Returns the area currently shown (the extent unless `confine()` zoomed in).

**Returns:**

- *const Eigen::AlignedBox2d &* — The visible area in layout coordinates.

---

## Static Methods

### read(path)

Reads an MNE-C .lout file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The layout file.

**Returns:**

- *std::optional&lt; [MNELayout](/docs/api/mne/mne-layout) &gt;* — The layout, or no value if the file cannot be read or a line is malformed.

````cpp title="src/examples/ex_mne_api/main.cpp, line 500"
// The Neuromag Vectorview layout: one viewport per channel
auto layout = MNELayout::read((layoutDir + "/Vectorview-all.lout").toStdU16String());
const std::map<std::string, Eigen::Vector2d> positions = layout->channelPositions();                                  // lower-left corners, keyed "MEG 0113"
const int leftHalf = layout->confine(Eigen::AlignedBox2d(Eigen::Vector2d(-85.0, -83.0), Eigen::Vector2d(0.0, 75.0))); // zoom to the left half
const int shownTriplet = layout->matchPorts({"MEG 0113", "MEG 0112", "MEG 0111"});
// mne.channels.read_layout("Vectorview-all.lout", scale=False): 306 viewports in -85 ... 90 x -83 ... 75, MEG 0113 at (-73.4162, 33.4167); 138 boxes left of x = 0
ok &= expect(layout && layout->ports.size() == 306 && (positions.at("MEG 0113") - Eigen::Vector2d(-73.416206, 33.416687)).lpNorm<1>() < 1e-4 && leftHalf == 138 && shownTriplet == 3,
             "MNELayout/MNELayoutPort: Vectorview layout like mne.channels.read_layout, zoom and channel matching");
````
