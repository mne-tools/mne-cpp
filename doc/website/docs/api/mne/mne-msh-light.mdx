# MNEMshLight

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_msh_light.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mne/mne_msh_light.h)

`#include <mne/mne/mne_msh_light.h>`

```cpp
class mne::MNEMshLight
```

Replaces *mshLight,mshLightRec struct (analyze_types.c).

Single light source with position, color, and state for 3-D surface rendering.

---

## Public Methods

### MNEMshLight()

Constructs a switched-off light at the origin.

---

### MNEMshLight(state, posX, posY, posZ, diffX, diffY, diffZ)

Constructs the [`MNEMshLight`](/docs/api/mne/mne-msh-light).

**Parameters:**

- **state** : *bool*
  Whether the light is switched on.

- **posX** : *float*
  Light position x coordinate.

- **posY** : *float*
  Light position y coordinate.

- **posZ** : *float*
  Light position z coordinate.

- **diffX** : *float*
  Diffuse intensity, red component.

- **diffY** : *float*
  Diffuse intensity, green component.

- **diffZ** : *float*
  Diffuse intensity, blue component.

## Example

No example of its own: Light of the legacy MNE-C mesh viewer held by MNEMshDisplaySurfaceSet; UI state with no computation to demonstrate.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// Total solid angle seen from a point: 4 pi inside a closed surface, 0 outside
auto skull = MNESurface::read_bem_surface2(bemPath.toStdU16String(), FIFFV_BEM_SURF_ID_BRAIN, true);
skull->compute_surface_cm();
const double inside = skull->sum_solids(Map<const Vector3f>(skull->cm)) / (4.0 * std::numbers::pi);
const double outside = skull->sum_solids(Vector3f(0.0f, 0.0f, 0.2f)) / (4.0 * std::numbers::pi);

// The same surface as an MNE-C viewer display surface
MNEMshDisplaySurfaceSet display;
display.add_bem_surface(bemPath.toStdU16String(), FIFFV_BEM_SURF_ID_BRAIN, "inner skull", 1, 1); // checks closure
const MNEMshDisplaySurface& shown = *display.surfs[0];
````
