# MNEMghTagGroup

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_mgh_tag_group.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mne/mne_mgh_tag_group.h)

`#include <mne/mne/mne_mgh_tag_group.h>`

```cpp
class mne::MNEMghTagGroup
```

Collection of [`MNEMghTag`](/docs/api/mne/mne-mgh-tag) entries from a FreeSurfer MGH/MGZ file footer.

Holds its tags by value.

## Example

No example of its own: Container of MNEMghTag records filled by the surface reader inside MNESourceSpace; never constructed by callers.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// A FreeSurfer surface with its curvature and the volume geometry from the file footer
const auto white = MNESourceSpace::load_surface((data + "/subjects/sample/surf/lh.white").toStdU16String(), (data + "/subjects/sample/surf/lh.curv").toStdU16String());
const MNEVolGeom& geometry = *white->vol_geom; // sizes and centre converted to metres
````

From [ex_mne_api](../../examples/fs/ex_mne_api.mdx).
