# MNEVolGeom

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_vol_geom.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_vol_geom.h)

`#include <mne/mne_vol_geom.h>`

```cpp
class MNELIB::MNEVolGeom
```

Implements the [`MNE`](/docs/api/mne/mne-class) Volume Geometry description (Replaces *mneVolGeom,mneVolGeomRec; struct of MNE-C `mne_types.h`).

MRI data volume geometry information like FreeSurfer keeps it

---

## Public Methods

### MNEVolGeom()

Constructs the [`MNE`](/docs/api/mne/mne-class) Volume Geometry.

---

### ~MNEVolGeom()

Destroys the [`MNE`](/docs/api/mne/mne-class) Volume Geometry Refactored: mne_free_vol_geom (mne_mgh_mri_io.c).

---

## Example

No example of its own: FreeSurfer volume geometry header decoded from MGH tags by the surface reader; a field of MNESurfaceOrVolume, not built by callers.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// A FreeSurfer surface with its curvature and the volume geometry from the file footer
const auto white = MNESourceSpace::load_surface(data + "/subjects/sample/surf/lh.white", data + "/subjects/sample/surf/lh.curv");
const MNEVolGeom& geometry = *white->vol_geom; // sizes and centre converted to metres
````

From [ex_mne_api](../../examples/fs/ex_mne_api.mdx).
