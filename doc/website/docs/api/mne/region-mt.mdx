# RegionMT

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_inverse_operator.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_inverse_operator.h)

`#include <mne/mne_inverse_operator.h>`

```cpp
struct MNELIB::RegionMT
```

Input parameters for multi-threaded [KMeans](/docs/api/math/k-means) clustering on a single cortical region.

---

## Public Methods

### cluster()

Run [KMeans](/docs/api/math/k-means) clustering on this region.

**Returns:**

- *[RegionMTOut](/docs/api/mne/region-mt-out)* — Clustering result including centroid positions and assignments.

---

## Example

No example of its own: Per-region work item of the parallel KMeans clustering in MNEInverseOperator::cluster_kernel; built and consumed only there.

It is exercised by:

````cpp title="src/examples/ex_inv_api/main.cpp"
// The same clustering on the inverse kernel: one x/y/z column triple per cluster of the transposed kernel
InvMinimumNorm clusteredMne(inverse, lambda2, "MNE");
clusteredMne.doInverseSetup(evoked.nave);
MatrixXd kernelMean; // 3 x 70 source components -> 3 x nClusters, averaging per orientation
const MatrixXd clusteredKernelT = clusteredMne.getPreparedInverseOperator().cluster_kernel(aparc, 20, kernelMean, "sqeuclidean");
````

From [ex_inv_api](../../examples/inv/ex_inv_api.mdx).
