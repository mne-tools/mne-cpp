# MNELayoutPort

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_layout_port.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_layout_port.h)

`#include <mne/mne_layout_port.h>`

```cpp
class mne::MNELayoutPort
```

Single viewport of a plotter layout (one line of an MNE-C .lout file).

Channel names are stored in matching form: lower case, without spaces and without anything after a dash (MNE-C `mne_lout_clean_name`), so "MEG 0113" and "meg0113" select the same port and a CTF "MLC11-2622" matches "MLC11".

```cpp title="src/examples/ex_mne_api/main.cpp"
// The Neuromag Vectorview layout: one viewport per channel
auto layout = MNELayout::read((layoutDir + "/Vectorview-all.lout").toStdU16String());
const std::map<std::string, Eigen::Vector2d> positions = layout->channelPositions();                                  // lower-left corners, keyed "MEG 0113"
const int leftHalf = layout->confine(Eigen::AlignedBox2d(Eigen::Vector2d(-85.0, -83.0), Eigen::Vector2d(0.0, 75.0))); // zoom to the left half
const int shownTriplet = layout->matchPorts({"MEG 0113", "MEG 0112", "MEG 0111"});
```

## Public Methods

### contains(channel)

Returns whether `channel` (any spelling) is one of the port's channels.

**Parameters:**

- **channel** : *std::string_view*
  A channel name.

**Returns:**

- *bool* — True if the cleaned name equals one of the port's channel names.

---

### rect()

Returns the viewport box.

**Returns:**

- *Eigen::AlignedBox2d* — The box from (xmin, ymin) to (xmax, ymax).

## Static Methods

### cleanName(name)

Returns `name` in matching form.

**Parameters:**

- **name** : *std::string_view*
  A channel name.

**Returns:**

- *std::string* — The name in lower case, without spaces and cut at the first dash.
