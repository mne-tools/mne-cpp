**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_msh_color_scale_def.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_msh_color_scale_def.h)

Replaces *mshColorScaleDef, mshColorScaleDefRec struct (analyze_types.c).

Color scale definition with value range and color mapping for surface visualization.

---

## Example

No example of its own: Colour-scale setting of the legacy MNE-C mesh viewer held by MNEMshDisplaySurface; UI state with no computation to demonstrate.

It is exercised by:

````cpp title="src/examples/ex_mne_api/main.cpp"
// Total solid angle seen from a point: 4 pi inside a closed surface, 0 outside
auto skull = MNESurface::read_bem_surface2(bemPath.toStdU16String(), FIFFV_BEM_SURF_ID_BRAIN, true);
skull->compute_surface_cm();
const double inside = skull->sum_solids(Map<const Vector3f>(skull->cm)) / (4.0 * std::numbers::pi);
const double outside = skull->sum_solids(Vector3f(0.0f, 0.0f, 0.2f)) / (4.0 * std::numbers::pi);

// The same surface as an MNE-C viewer display surface
MNEMshDisplaySurfaceSet display;
display.add_bem_surface(bemPath.toStdU16String(), FIFFV_BEM_SURF_ID_BRAIN, "inner skull", 1, 1); // checks closure
const MNEMshDisplaySurface& shown = *display.surfs[0];
````
