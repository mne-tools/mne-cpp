# MNECTFCompData

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_ctf_comp_data.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_ctf_comp_data.h)

`#include <mne/mne_ctf_comp_data.h>`

```cpp
class mne::MNECTFCompData
```

Represents a single CTF compensation data element.

Holds the compensation matrix together with optional sparse pre-/post-selectors and intermediate computation buffers used by `MNECTFCompDataSet::apply()` and apply_transpose().

```cpp title="src/examples/ex_mne_api/main.cpp"
// Open a third-order gradiometer recording and read it uncompensated (grade 0)
std::unique_ptr<MNERawData> ctfRaw(MNERawData::open_file_comp(ctfPath.toStdU16String(), false, false, MNEFilterDef(), 0));
const MNECTFCompDataSet& comp = *ctfRaw->comp; // grades 1, 2, 3 and two 4D kinds
const MNECTFCompData* third = nullptr;
for (const auto& c : comp.comps) {
    if (c->kind == MNECTFCompDataSet::map_comp_kind(3)) {
        third = c.get();
    }
}
const int grade = MNECTFCompDataSet::get_comp(ctfRaw->info->chInfo, ctfRaw->info->nchan);
MNERawData::RowMajorMatrixXf ctf(ctfRaw->info->nchan, 21);
ctfRaw->pick_data(nullptr, ctfRaw->first_samp, ctf);
```

### calibrate(chs, nch, do_it)

Apply or remove channel calibration to/from the compensation matrix by scaling each element by (row_cal / col_cal) or its inverse.

**Parameters:**

- **chs** : *const std::vector&lt; [FiffChInfo](/docs/api/fiff/fiff-ch-info) &gt; &*
  Channel information used for calibration factors.

- **nch** : *int*
  Number of channels.

- **do_it** : *bool*
  If true, apply calibration; if false, remove it.

**Returns:**

- *int* — OK on success, FAIL if a channel is not found.
