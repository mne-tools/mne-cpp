# FiffCtfComp

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_ctf_comp.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_ctf_comp.h)

`#include <fiff/fiff_ctf_comp.h>`

```cpp
class FIFFLIB::FiffCtfComp
```

One CTF software-gradient compensation matrix: grade kind, calibration flag and the gradiometer × reference named matrix.

A list of [`FiffCtfComp`](/docs/api/fiff/fiff-ctf-comp) lives inside [`FiffInfo`](/docs/api/fiff/fiff-info) and lets raw / evoked data be moved between compensation grades by chaining the appropriate matrices. The `save_calibrated` flag controls whether the matrix was stored already-calibrated (and therefore must not be re-multiplied by the channel cals on apply).

```cpp title="src/examples/ex_fiff_structure/main.cpp"
// CTF third-order gradient compensation: info.comps holds one FiffCtfComp per grade.
QFile ctfFile(parser.value(ctfOption));
const FiffRawData ctf(ctfFile);
FiffCtfComp toGrade1;
ok &= ctf.info.make_compensator(0, 1, toGrade1); // uncompensated -> grade 1
```

### calibrate(chs)

Brings a compensator stored uncalibrated into calibrated units, as mne _read_ctf_comp does: each matrix element is scaled by its row channel's range * cal and divided by its column channel's.

The factors are kept in rowcals and colcals so that write_ctf_comp can undo them. A compensator saved calibrated is left as it is.

**Parameters:**

- **chs** : *const QList&lt; [FiffChInfo](/docs/api/fiff/fiff-ch-info) &gt; &*
  The channels the compensator refers to by name.

**Returns:**

- *bool* — false if a row or column channel is missing from, or ambiguous in, chs.

````cpp title="src/examples/ex_fiff_structure/main.cpp, line 140"
// CTF third-order gradient compensation: info.comps holds one FiffCtfComp per grade.
QFile ctfFile(parser.value(ctfOption));
const FiffRawData ctf(ctfFile);
FiffCtfComp toGrade1;
ok &= ctf.info.make_compensator(0, 1, toGrade1); // uncompensated -> grade 1
// mne._fiff.compensator.make_compensator(info, 0, 1) on ctf_grade0_raw.fif: 36 x 36, ||C - I||_F = 0.1947596520139745
const MatrixXd& compensator = toGrade1.data->data;
ok &= expect(ctf.info.comps.size() == 5 && compensator.rows() == 36 && std::abs((compensator - MatrixXd::Identity(36, 36)).norm() - 0.1947596520139745) < 1e-6,
             "FiffCtfComp: 5 compensation grades; the grade-1 compensator matches mne make_compensator");
````
