# FiffAnnotation

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library

`#include <fiff/fiff_annotations.h>`

```cpp
struct FIFFLIB::FiffAnnotation
```

One FIFF / [MNE](/docs/api/mne/mne-class) annotation: onset (s), duration (s) and description string.

Field-for-field counterpart of one row of `mne.Annotations` in MNE-Python. Onset is given in seconds relative to the recording start (matching the `first_samp` / `sfreq` convention of [`FiffRawData`](/docs/api/fiff/fiff-raw-data)).
