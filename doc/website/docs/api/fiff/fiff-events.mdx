# FiffEvents

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library

`#include <fiff/fiff_events.h>`

```cpp
class FIFFLIB::FiffEvents
```

FIFF event list: (sample, prev, new) integer triples with read / write / detect / filter helpers.

On-disk representation matches `mne.io.write.write_events` output and the `-eve.fif` files consumed by `mne.read_events`; the detection path mirrors `mne.find_events`. Used by [`FiffEpochs`](/docs/api/fiff/fiff-epochs) and the batch-averaging path in [`FiffEvokedSet`](/docs/api/fiff/fiff-evoked-set) to drive epoch extraction.

```cpp title="src/examples/ex_fiff_api/main.cpp"
FiffEvents events;
FiffEvents::detect_from_raw(raw, events, "STI 014"); // rising edges of the trigger channel
QFile eventFile(tmp.filePath("sample-eve.fif"));
const bool eventsWritten = eventFile.open(QIODevice::WriteOnly) && events.write_to_fif(eventFile);
eventFile.close();
FiffEvents eventsBack(eventFile); // mne.read_events reads this file too
```

## Public Methods

### FiffEvents()

Default constructor.

### FiffEvents(p_IODevice)

Constructs [`FiffEvents`](/docs/api/fiff/fiff-events) by reading from an I/O device.

Attempts to read as FIFF first; if that fails, tries ASCII format.

**Parameters:**

- **p_IODevice** : *QIODevice &*
  The I/O device to read from.

### pick(include, exclude, step)

Select events by code, like mne.pick_events.

**Parameters:**

- **include** : *const QList&lt; int &gt; &*
  Codes to keep; if empty, all codes except `exclude` are kept.

- **exclude** : *const QList&lt; int &gt; &*
  Codes to drop when `include` is empty.

- **step** : *bool*
  Also match the code before the step (column 1).

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — The selected events in their original order.

---

### merge(ids, newId, replaceEvents)

Replace codes in both code columns by a new one, like mne.merge_events.

**Parameters:**

- **ids** : *const QList&lt; int &gt; &*
  Codes to replace.

- **newId** : *int*
  The new code.

- **replaceEvents** : *bool*
  If false, the original events are kept as well, sorted by row.

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — The merged events.

---

### count(ids)

Count the events per code (column 2), like mne.count_events.

**Parameters:**

- **ids** : *const QList&lt; int &gt; &*
  Codes to report (0 if absent); if empty, every code that occurs.

**Returns:**

- *QMap&lt; int, int &gt;* — Code to count.

### read(t_sEventName, t_fileRawName, p_Events)

Read events from a FIFF or ASCII event file.

If t_sEventName is empty, the event file name is derived from the raw file name (replacing ".fif" with "-eve.fif").

**Parameters:**

- **t_sEventName** : *const QString &*
  Path to the event file (empty = derive from raw file name).

- **t_fileRawName** : *const QString &*
  Path to the raw data file (used to derive event file name if needed).

- **p_Events** : *[FiffEvents](/docs/api/fiff/fiff-events) &*
  The loaded events.

**Returns:**

- *bool* — true if succeeded, false otherwise.

### detect_from_raw(raw, p_Events, triggerCh, triggerMask, leadingEdge)

Detect trigger events from raw data using a stimulus channel.

Ported from detect_events (MNE-C).

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  The raw data.

- **p_Events** : *[FiffEvents](/docs/api/fiff/fiff-events) &*
  The detected events.

- **triggerCh** : *const QString &*
  Name of the trigger channel (empty = default "STI 014").

- **triggerMask** : *unsigned int*
  Bitmask to apply to trigger values.

- **leadingEdge** : *bool*
  If true, only detect rising edges (default = true).

**Returns:**

- *bool* — true if events were detected, false otherwise.

---

### find_stim_steps(stimData, firstSamp, padStart, padStop, merge)

Find the samples where all stimulus channels change at once, like mne.find_stim_steps.

**Parameters:**

- **stimData** : *const Eigen::MatrixXi &*
  Stimulus channel data (channels x samples); steps carry the values of the first row.

- **firstSamp** : *int*
  Sample number of the first column.

- **padStart** : *std::optional&lt; int &gt;*
  If set, a step from this value at sample 0 is added when the data start elsewhere.

- **padStop** : *std::optional&lt; int &gt;*
  If set, a step to this value after the last sample is added.

- **merge** : *int*
  Merge steps at most |merge| samples apart (&gt; 0: into the later, &lt; 0: into the earlier).

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — Steps as [sample, value before, value after].

---

### make_fixed_length(raw, id, start, stop, duration, firstSamp, overlap)

Events at regular intervals, like mne.make_fixed_length_events.

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  The recording.

- **id** : *int*
  Event code.

- **start** : *double*
  First event time in s.

- **stop** : *double*
  Time in s after which no event may start (negative: end of the recording).

- **duration** : *double*
  Duration of each segment in s.

- **firstSamp** : *bool*
  Whether times count from the recording's first sample (true) or from 0.

- **overlap** : *double*
  Overlap of consecutive segments in s, 0 &lt;= overlap &lt; duration.

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — The events (empty if none fit or the overlap is invalid).
