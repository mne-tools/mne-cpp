# AverageDescription

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library

`#include <fiff/fiff_evoked_set.h>`

```cpp
struct FIFFLIB::AverageDescription
```

Top-level MNE-C ave-description record: comment, category list, shared rejection limits and output file paths.

Port of `aveDataRec` from MNE-C `browser_types.h`. Owns the list of [`AverageCategory`](/docs/api/fiff/average-category) entries, the shared [`RejectionParams`](/docs/api/fiff/rejection-params), the skew-correction flag and the I/O paths (output ave file, event source, log file) so an entire batch-averaging job can be described as one value.

```cpp title="src/examples/ex_mne_api/main.cpp"
// An MNE-C averaging description (mne_process_raw --ave), parsed and run on the raw recording
const QString aveDesc = tmp.filePath("audvis.ave");
QFile descFile(aveDesc);
ok &= descFile.open(QIODevice::WriteOnly | QIODevice::Text);
descFile.write("average {\n"
               "    category {\n"
               "        name   \"Left Auditory\"\n"
               "        event  1\n"
               "        tmin   -0.1\n"
               "        tmax   0.3\n"
               "        bmin   -0.1\n"
               "        bmax   0.0\n"
               "    }\n"
               "}\n");
descFile.close();
AverageDescription averaging;
MNEDescriptionParser::parseAverageFile(aveDesc, averaging);
QString log;
const FiffEvokedSet averages = FiffEvokedSet::computeAverages(raw, averaging, events.events, log);
```
