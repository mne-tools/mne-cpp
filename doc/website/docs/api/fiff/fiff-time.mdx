# FiffTime

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library

`#include <fiff/fiff_time.h>`

```cpp
class FIFFLIB::FiffTime
```

FIFF time stamp: Unix seconds plus a microsecond fraction matching the on-disk `fiffTimeRec` record.

Layout is two 32-bit fields (secs, usecs) — the exact representation used by `FIFF_MEAS_DATE` and the per-buffer timestamps embedded in raw data blocks, so an instance can be streamed in and out without per-field marshalling.

```cpp title="src/examples/ex_fiff_structure/main.cpp"
QFile structureFile(rawPath);
FiffStream::SPtr stream(new FiffStream(&structureFile));
ok &= stream->open();
const QList<FiffDirEntry::SPtr>& directory = stream->dir(); // every tag (kind, type, size, position) + a kind -1 end
const FiffTime created = stream->id().time;                 // seconds and microseconds since 1970
stream->close();
```
