# FiffEvoked

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_evoked.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_evoked.h)

`#include <fiff/fiff_evoked.h>`

<Connections topics={["fiff-io", "epochs-averaging"]} context="api" current="FiffEvoked" />

```cpp
class FIFFLIB::FiffEvoked
```

Single averaged evoked response: time axis, data, baseline, channel info and averaging metadata.

Holds one `FIFFB_EVOKED` block: `times`, `data`, `first` / `last` sample indices, `baseline`, `kind`, `nave`, `comment` and the [`FiffInfo`](/docs/api/fiff/fiff-info) describing the channels. Use [`FiffEvokedSet`](/docs/api/fiff/fiff-evoked-set) for recordings that contain multiple averaging conditions.

```cpp title="src/examples/ex_fiff_api/main.cpp"
QFile aveFile(dir + "/sample_audvis-ave.fif");
FiffEvokedSet evokedSet(aveFile); // all conditions of an -ave.fif file
const FiffEvoked& leftAuditory = evokedSet.evoked[0];
```

### FiffEvoked(p_IODevice, setno, t_baseline, proj, p_aspect_kind)

Constructs fiff evoked data, by reading from a IO device.

**Parameters:**

- **p_IODevice** : *QIODevice &*
  IO device to read from the evoked data set.

- **setno** : *QVariant*
  The set to pick. Dataset ID number (int) or comment/name (str). Optional if there isonly one data set in file.

- **t_baseline** : *QPair&lt; float, float &gt;*
  The time interval to apply rescaling / baseline correction. If None do not apply it. If baseline is (a, b). the interval is between "a (s)" and "b (s)". If a is None the beginning of the data is used and if b is None then b is set to the end of the interval. If baseline is equal ot (None, None) all the time interval is used. If None, no correction is applied.

- **proj** : *bool*
  Apply SSP projection vectors (optional, default = true).

- **p_aspect_kind** : *fiff_int_t*
  Either "FIFFV_ASPECT_AVERAGE" or "FIFFV_ASPECT_STD_ERR". The type of data to read. Only used if "setno" is a str.

### combine(evokeds, weights)

Merges evoked data by weighted addition or subtraction (mne.combine_evoked).

All data sets must have the same channels and time instants. The result carries the union of the bad channels, the weighted sum of the data, a comment such as "0.474 × A + 0.526 × B" and nave = 1 / sum(w_i^2 / nave_i), rounded to an integer as required by the FIFF format.

**Parameters:**

- **evokeds** : *const QList&lt; [FiffEvoked](/docs/api/fiff/fiff-evoked) &gt; &*
  The evoked data sets.

- **weights** : *const Eigen::VectorXd &*
  One weight per data set.

**Returns:**

- *[FiffEvoked](/docs/api/fiff/fiff-evoked)* — The combined evoked data, or an empty [`FiffEvoked`](/docs/api/fiff/fiff-evoked) if the inputs are inconsistent.
