# FiffRawData

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_raw_data.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/fiff/fiff_raw_data.h)

:::info[Python equivalent]
`mne.io.Raw` in MNE-Python.
:::

`#include <mne/fiff/fiff_raw_data.h>`

<Connections topics={["fiff-io"]} context="api" current="FiffRawData" />

```cpp
class mne::FiffRawData
```

Continuous FIFF raw recording: [`FiffInfo`](/docs/api/fiff/fiff-info) plus a random-access directory of `FIFF_DATA_BUFFER` tags.

The directory built into [`FiffRawDir`](/docs/api/fiff/fiff-raw-dir) lets segment reads jump straight to the buffers covering the requested sample window, decode them through the channel cals and active projectors and return a contiguous channel × sample Eigen matrix without rescanning the file.

Open a recording and pick the MEG channels plus the trigger channel:

```cpp title="src/examples/ex_read_raw/main.cpp"
//
//   Setup for reading the raw data
//
FiffRawData raw(parser.value(inputOption).toStdString());

//
//   Set up pick list: MEG + STI 014 - bad channels
//
StringList include{"STI 014"};
bool want_meg = true;
bool want_eeg = false;
bool want_stim = false;

RowVectorXi picks = raw.info.pick_types(want_meg, want_eeg, want_stim, include, raw.info.bads);
```

Read a window of the picked channels, in seconds or in samples:

```cpp title="src/examples/ex_read_raw/main.cpp"
//
//   Read a data segment
//   times output argument is optional
//
bool readSuccessful = false;
MatrixXd data;
MatrixXd times;
if (in_samples)
    readSuccessful = raw.read_raw_segment(data, times, (qint32)from, (qint32)to, picks);
else
    readSuccessful = raw.read_raw_segment_times(data, times, from, to, picks);

if (!readSuccessful) {
    Log::warning("Could not read raw segment.\n");
    return -1;
}
```

### read_raw_segment(data, times, from, to, sel, do_debug)

Read a specific raw data segment.

**Parameters:**

- **data** : *Eigen::MatrixXd &*
  returns the data matrix (channels x samples).

- **times** : *Eigen::MatrixXd &*
  returns the time values corresponding to the samples.

- **from** : *fiff_int_t*
  first sample to include. If omitted, defaults to the first sample in data (optional).

- **to** : *fiff_int_t*
  last sample to include. If omitted, defaults to the last sample in data (optional).

- **sel** : *const Eigen::RowVectorXi &*
  channel selection vector (optional).

- **do_debug** : *bool*
  Print diagnostic output while reading.

**Returns:**

- *bool* — true if succeeded, false otherwise.

### save(path, picks, decim, from, to)

Save raw data to a FIFF file, optionally with decimation and channel picking.

Ported from save.c (MNE-C).

**Parameters:**

- **path** : *const std::filesystem::path &*
  The file to write.

- **picks** : *const Eigen::RowVectorXi &*
  Channel indices to include (empty = all channels).

- **decim** : *int*
  Decimation factor (1 = no decimation).

- **from** : *int*
  First sample to save (-1 = from start of raw data).

- **to** : *int*
  Last sample to save (-1 = to end of raw data).

**Returns:**

- *bool* — true on success.

## Static Methods

### read(path, allow_maxshield)

Opens a raw FIFF file, like mne.io.read_raw_fif(path, preload=False): reads the measurement info and the directory of data buffers, and keeps the file for reading segments.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The raw data file.

- **allow_maxshield** : *bool*
  Accept unprocessed Internal Active Shielding (MaxShield) data.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [FiffRawData](/docs/api/fiff/fiff-raw-data) &gt;* — The raw data, or why the file cannot be read: Io if it cannot be opened, NotFound if it holds no raw data, Format if it is damaged or holds MaxShield data that is not allowed.

### [ex_fiff_structure](../../examples/fiff/ex_fiff_structure.mdx)

FIFF library: fixed-length epochs, CTF compensation, the file directory and raw buffers, and handing recordings to another application.

````cpp title="src/examples/ex_fiff_structure/main.cpp, line 94"
FiffRawData raw(rawPath.toStdString());
MatrixXd data;
MatrixXd times;
ok &= raw.read_raw_segment(data, times); // all 6007 samples
const double sfreq = raw.info.sfreq;
const std::vector<FiffEpochData> epochs = FiffEpochs::makeFixedLengthEpochs(data, sfreq, 2.0, 0.5); // 2 s, 0.5 s overlap
const FiffEvoked average = FiffEpochs::averageEpochs(epochs, sfreq);
// mne.make_fixed_length_epochs(raw, duration=2, overlap=0.5): 13 epochs of 601 samples, 450 samples apart
ok &= expect(epochs.size() == 13 && epochs[0].data.cols() == 601 && std::lround((epochs[1].tmin - epochs[0].tmin) * sfreq) == 450 && average.nave == 13,
             "FiffEpochs/FiffEpochData: 13 fixed-length epochs like mne.make_fixed_length_epochs, averaged over 13");
````
