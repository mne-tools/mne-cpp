# StatsFtestResult

**Namespace:** `STSLIB` &nbsp;·&nbsp; **Library:** Statistics Library

`#include <sts/sts_ftest.h>`

```cpp
struct STSLIB::StatsFtestResult
```

Result structure for F-tests.

Per-call output of a one-way ANOVA F-test: F-statistics, p-values, and between/within degrees of freedom.

```cpp title="src/examples/ex_sts_statistics/main.cpp"
const StatsFtestResult anova = StatsFtest::oneWay({a, b, c}); // one-way ANOVA per column
```
