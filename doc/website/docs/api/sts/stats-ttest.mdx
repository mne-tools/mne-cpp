# StatsTtest

**Namespace:** `STSLIB` &nbsp;·&nbsp; **Library:** Statistics Library

`#include <sts/sts_ttest.h>`

```cpp
class STSLIB::StatsTtest
```

Provides t-test implementations: one-sample, paired, and independent two-sample.

One-sample, paired and independent two-sample Student t-tests with exact p-values via the regularised incomplete beta function.

```cpp title="src/examples/ex_sts_statistics/main.cpp"
const StatsTtestResult oneSample = StatsTtest::oneSample(a);        // H0: column mean = 0
const StatsTtestResult paired = StatsTtest::paired(a, b);           // H0: mean(a - b) = 0
const StatsTtestResult independent = StatsTtest::independent(a, b); // pooled variance, df = 10
const StatsTtestResult rightTail = StatsTtest::oneSample(a, 0.0, StatsTailType::Right);
```

---

## Static Methods

### oneSample(data, mu, tail)

One-sample t-test.

Each column of data is tested against mu.

**Parameters:**

- **data** : *const Eigen::MatrixXd &*
  Matrix of observations (rows = observations, cols = variables).

- **mu** : *double*
  Hypothesized mean (default 0.0).

- **tail** : *StatsTailType*
  Tail type for the test.

**Returns:**

- *StatsTtestResult* — `StatsTtestResult` with t-statistics, p-values, and degrees of freedom.

---

### paired(dataA, dataB, tail)

Paired t-test.

Tests dataA - dataB against 0.

**Parameters:**

- **dataA** : *const Eigen::MatrixXd &*
  Matrix of observations for condition A.

- **dataB** : *const Eigen::MatrixXd &*
  Matrix of observations for condition B (same dimensions as dataA).

- **tail** : *StatsTailType*
  Tail type for the test.

**Returns:**

- *StatsTtestResult* — `StatsTtestResult` with t-statistics, p-values, and degrees of freedom.

---

### independent(dataA, dataB, tail)

Independent two-sample t-test.

**Parameters:**

- **dataA** : *const Eigen::MatrixXd &*
  Matrix of observations for group A (rows = observations, cols = variables).

- **dataB** : *const Eigen::MatrixXd &*
  Matrix of observations for group B (same number of columns as dataA).

- **tail** : *StatsTailType*
  Tail type for the test.

**Returns:**

- *StatsTtestResult* — `StatsTtestResult` with t-statistics, p-values, and degrees of freedom.

---

### tCdf(t, df)

Compute the CDF of the t-distribution using the regularized incomplete beta function.

**Parameters:**

- **t** : *double*
  The t-value.

- **df** : *int*
  Degrees of freedom.

**Returns:**

- *double* — The probability P(T &lt;= t).

---

### regularizedBeta(x, a, b)

Regularized incomplete beta function I_x(a, b).

Public because it is also used by [`StatsFtest`](/docs/api/sts/stats-ftest).

**Parameters:**

- **x** : *double*
  Upper integration limit in [0, 1].

- **a** : *double*
  First shape parameter (positive).

- **b** : *double*
  Second shape parameter (positive).

**Returns:**

- *double* — I_x(a, b) in [0, 1]; 0 for x at or below 0 and 1 for x at or above 1.
