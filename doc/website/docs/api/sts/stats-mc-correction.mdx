# StatsMcCorrection

**Namespace:** `STSLIB` &nbsp;·&nbsp; **Library:** Statistics Library

`#include <sts/sts_correction.h>`

```cpp
class STSLIB::StatsMcCorrection
```

Multiple comparison correction methods.

Bonferroni, Holm-Bonferroni and Benjamini-Hochberg FDR adjustments for mass-univariate p-value maps.

```cpp title="src/examples/ex_sts_statistics/main.cpp"
MatrixXd pValues(1, 8);
pValues << 0.001, 0.008, 0.039, 0.041, 0.042, 0.06, 0.074, 0.205;
const MatrixXd pBonferroni = StatsMcCorrection::bonferroni(pValues);
const MatrixXd pHolm = StatsMcCorrection::holmBonferroni(pValues);
const MatrixXd pFdr = StatsMcCorrection::fdr(pValues); // Benjamini-Hochberg adjusted p-values
```

---

## Static Methods

### bonferroni(pValues, alpha, reject)

Bonferroni correction as mne.stats.bonferroni_correction: corrected_p = min(p * n, 1.0).

**Parameters:**

- **pValues** : *const Eigen::MatrixXd &*
  Matrix of p-values.

- **alpha** : *double*
  Significance level for `reject`.

- **reject** : *RejectMask **
  If not null, receives corrected_p &lt; alpha.

**Returns:**

- *Eigen::MatrixXd* — Corrected p-values (same shape as input).

---

### holmBonferroni(pValues)

Holm-Bonferroni step-down correction.

**Parameters:**

- **pValues** : *const Eigen::MatrixXd &*
  Matrix of p-values.

**Returns:**

- *Eigen::MatrixXd* — Corrected p-values (same shape as input).

---

### fdr(pValues, alpha, method, reject)

False Discovery Rate correction as mne.stats.fdr_correction.

**Parameters:**

- **pValues** : *const Eigen::MatrixXd &*
  Matrix of p-values.

- **alpha** : *double*
  False discovery rate for `reject`.

- **method** : *FdrMethod*
  Benjamini-Hochberg or Benjamini-Yekutieli.

- **reject** : *RejectMask **
  If not null, receives the hypotheses rejected by the step-up procedure.

**Returns:**

- *Eigen::MatrixXd* — Corrected p-values (same shape as input).
