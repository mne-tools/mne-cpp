# BidsTree

**Namespace:** `mne::viewmodels` &nbsp;·&nbsp; **Library:** View Models Library &nbsp;·&nbsp; **Source:** [`viewmodels/bids_tree.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viewmodels/bids_tree.h)

`#include <mne/viewmodels/bids_tree.h>`

```cpp
class mne::viewmodels::BidsTree
```

Subjects, sessions, data-type folders and data items of a BIDS browser.

Nodes are addressed by ids that stay valid until the node is removed. The item types use the values of the BIDS_* constants of [`BidsViewModel`](/docs/api/disp/bids-view-model) (subject 1, session 2, folder 3, functional 10, anatomical 11, behavioral 12, iEEG 13, average 20, event 21, dipole 22, electrodes 23, coordinate system 24, unknown 99).

### add_session(subject, session)

Adds a session to every subject called `subject`.

With several such subjects they are renamed by appending 1, 2, ... so that they become distinguishable.

**Parameters:**

- **subject** : *std::string_view*
  Subject name as displayed.

- **session** : *std::string_view*
  Session name; the BIDS prefix is added.

**Returns:**

- *std::vector&lt; int &gt;* — The new sessions, one per matching subject; empty when no subject matches.
