# MriCorFifIO

**Namespace:** `MRILIB` &nbsp;·&nbsp; **Library:** MRI Library

`#include <mri/mri_cor_fif_io.h>`

```cpp
class MRILIB::MriCorFifIO
```

Stateless serialiser that turns an [`MriVolData`](/docs/api/mri/mri-vol-data) into a FIFF MRI set (COR.fif).

Writes MRI slice data  whether originally loaded from a FreeSurfer COR tree, an MGH/MGZ volume, or a NIfTI file  into the FIFF block hierarchy (`FIFFB_MRI` / `FIFFB_MRI_SET` / `FIFFB_MRI_SLICE`) understood by every downstream [MNE](/docs/api/mne/mne-class) C / MNE-Python step that needs an MRI volume in source-space coordinates. The class exposes only `static` methods so callers can use it without owning any state; the input [`MriVolData`](/docs/api/mri/mri-vol-data) is consumed verbatim.

Ported from `save_slices()` / `write_slice()` in [MNE](/docs/api/mne/mne-class) C `write_mri_set.c` by Matti Hamalainen.

```cpp title="src/examples/ex_mri/main.cpp"
const QString corFif = dir.filePath("COR.fif");
MriCorFifIO::write(corFif, corSlices, extraTransforms);
```

## Static Methods

### write(fileName, slices, additionalTrans)

Writes COR.fif file from slice data.

**Parameters:**

- **fileName** : *const QString &*
  Output FIFF file path.

- **slices** : *const QVector&lt; [MriSlice](/docs/api/mri/mri-slice) &gt; &*
  Vector of [`MriSlice`](/docs/api/mri/mri-slice) structures to write.

- **additionalTrans** : *const QVector&lt; [FiffCoordTrans](/docs/api/fiff/fiff-coord-trans) &gt; &*
  Additional coordinate transforms (Talairach etc.).

**Returns:**

- *bool* — True on success, false on error.
