# MriSlicer

**Namespace:** `MRILIB` &nbsp;·&nbsp; **Library:** MRI Library

`#include <mri/mri_slicer.h>`

```cpp
class MRILIB::MriSlicer
```

Orthogonal-plane resampler (axial / coronal / sagittal) from [`MriVolData`](/docs/api/mri/mri-vol-data) to [`MriSliceImage`](/docs/api/mri/mri-slice-image).

Pure `static` methods  no instance state is owned. For a given orientation and slice index, samples the source volume at the matching row/column/depth plane, normalises voxel intensities into 8-bit grayscale via the volume's percentile-clipped window, and emits the result with the slice→RAS transform the viewer needs to draw rulers and crosshairs in millimetres.

```cpp title="src/examples/ex_mri/main.cpp"
const Vector3f ras(0.001f, -0.0005f, -0.002f); // metres; voxel (2,3,1)
const Vector3i voxel = MriSlicer::rasToVoxel(vox2ras, ras);
const QVector<MriSliceImage> planes = MriSlicer::extractOrthogonal(voxels, mgh.dims(), vox2ras, ras); // axial, coronal, sagittal
```

## Static Methods

### extractSlice(volData, dims, vox2ras, orientation, sliceIndex)

Extract a 2D slice from a 3D volume stored as a flat array.

**Parameters:**

- **volData** : *const QVector&lt; float &gt; &*
  Flat array of voxel intensities (dimX x dimY x dimZ, x-fastest).

- **dims** : *const QVector&lt; int &gt; &*
  Volume dimensions \{dimX, dimY, dimZ\}.

- **vox2ras** : *const Eigen::Matrix4f &*
  4x4 voxel-to-RAS transform.

- **orientation** : *SliceOrientation*
  Slice orientation (Axial, Coronal, or Sagittal).

- **sliceIndex** : *int*
  Index along the slicing axis.

**Returns:**

- *[MriSliceImage](/docs/api/mri/mri-slice-image)* — The extracted slice image.

---

### voxelAxisForOrientation(vox2ras, orientation)

Return the voxel axis used as the fixed slicing axis for an anatomical orientation.

Uses the voxel-to-RAS transform to map anatomical planes onto the source volume's storage axes. For FreeSurfer tkRAS volumes, axial maps to voxel Y and coronal maps to voxel Z, while an identity transform keeps the conventional Z/Y/X mapping.

**Parameters:**

- **vox2ras** : *const Eigen::Matrix4f &*
  4x4 voxel-to-RAS transform.

- **orientation** : *SliceOrientation*
  Anatomical slice orientation.

**Returns:**

- *int* — Voxel axis index: 0 = X, 1 = Y, 2 = Z.

---
