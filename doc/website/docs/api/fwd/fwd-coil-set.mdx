# FwdCoilSet

**Namespace:** `FWDLIB` &nbsp;·&nbsp; **Library:** Forward Library &nbsp;·&nbsp; **Source:** [`fwd/fwd_coil_set.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fwd/fwd_coil_set.h)

`#include <fwd/fwd_coil_set.h>`

<Connections topics={["forward-modeling"]} context="api" current="FwdCoilSet" />

```cpp
class FWDLIB::FwdCoilSet
```

Implements [`FwdCoilSet`](/docs/api/fwd/fwd-coil-set) (replaces `fwdCoilSet` / `fwdCoilSetRec` from MNE-C ``fwd_types.h``).

Container of [`FwdCoil`](/docs/api/fwd/fwd-coil) instances acting both as the in-memory image of the `coil_def.dat` template database and as a per-channel sensor array in a chosen coordinate frame (device / head / MRI).

```cpp title="src/examples/ex_fwd_api/main.cpp"
auto templates = FwdCoilSet::read_coil_defs(coilDefs); // integration points per coil type
auto coils = templates->create_meg_coils(meg, meg.size(), FWD_COIL_ACCURACY_ACCURATE, raw.info.dev_head_t);
const FwdCoil& first = *coils->coils[0]; // MEG 0113 in head coordinates
```

````cpp title="src/examples/ex_fwd_api/main.cpp, line 121"
auto templates = FwdCoilSet::read_coil_defs(coilDefs); // integration points per coil type
auto coils = templates->create_meg_coils(meg, meg.size(), FWD_COIL_ACCURACY_ACCURATE, raw.info.dev_head_t);
const FwdCoil& first = *coils->coils[0]; // MEG 0113 in head coordinates
// mne _create_meg_coils(accurate): 3012 planar gradiometer, 8 points, r0 (-106.15, 29.14, -14.73) mm
ok &= expect(coils->ncoil() == 306 && first.type == 3012 && first.np == 8 && coils->is_planar_coil_type(first.type) && (first.r0 - Vector3f(-0.10614990f, 0.02914091f, -0.01472596f)).norm() < 1e-6f,
             "FwdCoilSet/FwdCoil: 306 accurate MEG coils, MEG0113 a planar gradiometer with 8 points");
````
