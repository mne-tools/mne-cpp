# Fwd

**Namespace:** `FWDLIB` &nbsp;·&nbsp; **Library:** Forward Library &nbsp;·&nbsp; **Source:** [`fwd/fwd.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fwd/fwd.h)

`#include <fwd/fwd.h>`

```cpp
class FWDLIB::Fwd
```

Static-method façade that re-exposes [MNEForwardSolution](/docs/api/mne/mne-forward-solution) toolbox-equivalent entry points under their familiar `mne_*` names.

```cpp title="src/examples/ex_fwd_api/main.cpp"
MNEForwardSolution back;
Fwd::read_forward_solution(solFile, back); // all 366 rows, like mne.read_forward_solution
MNEForwardSolution good;
MNEForwardSolution::read(solFile, good, false, false, {}, {}, true); // without the channels marked bad
```

## Static Methods

### read_forward_solution(p_IODevice, fwd, force_fixed, surf_ori, include, exclude)

mne_read_forward_solution

**Parameters:**

- **p_IODevice** : *QIODevice &*
  A fiff IO device like a fiff QFile or QTCPSocket.

- **fwd** : *[MNEForwardSolution](/docs/api/mne/mne-forward-solution) &*
  A forward solution from a fif file.

- **force_fixed** : *bool*
  Force fixed source orientation mode? (optional).

- **surf_ori** : *bool*
  Use surface based source coordinate system? (optional).

- **include** : *const QStringList &*
  Include these channels (optional).

- **exclude** : *const QStringList &*
  Exclude these channels (optional).

**Returns:**

- *bool* — true if succeeded, false otherwise.
