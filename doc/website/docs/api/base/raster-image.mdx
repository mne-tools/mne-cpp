# RasterImage

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/raster_image.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/base/raster_image.h)

`#include <mne/base/raster_image.h>`

```cpp
class mne::RasterImage
```

An RGB image in memory that fills polygons, draws text and writes PNG files.

Polygons are filled with the non-zero winding rule and anti-aliased by 4 x 4 supersampling, so their edges blend with what is underneath like QPainter's anti-aliased drawing.

```cpp title="src/examples/ex_base/main.cpp"
// Qt:   QImage image(64, 48, QImage::Format_RGB32); QPainter p(&image); p.drawPolygon(...); image.save("frame.png");
RasterImage frame(64, 48, {0, 0, 0});
const std::array<PointF, 3> triangle = {{{4.0, 40.0}, {60.0, 40.0}, {32.0, 4.0}}};
frame.fill_polygon(triangle, {255, 128, 0}); // anti-aliased edges
frame.draw_text(2, 47, "t = 12.5 ms", {255, 255, 255});
const std::vector<std::uint8_t> png = frame.encode_png(); // or frame.save_png(path)
```

## Public Methods

### RasterImage(width, height, background)

Creates an image filled with one colour.

**Parameters:**

- **width** : *int*
  Width in pixels; negative values count as 0.

- **height** : *int*
  Height in pixels; negative values count as 0.

- **background** : *[Rgb](/docs/api/base/rgb)*
  Colour of every pixel.

### fill(color)

Sets every pixel to `color`.

**Parameters:**

- **color** : *[Rgb](/docs/api/base/rgb)*
  New colour.

---

### fill_polygon(points, color, opacity)

Fills a polygon, anti-aliased.

Parts outside the image are clipped.

**Parameters:**

- **points** : *std::span&lt; const [PointF](/docs/api/base/point-f) &gt;*
  Corners in order; fewer than three fill nothing.

- **color** : *[Rgb](/docs/api/base/rgb)*
  Fill colour.

- **opacity** : *int*
  Opacity of the fill, 0 (transparent) to 255 (opaque).

---

### fill_polygons(polygons, color, opacity)

Fills the area enclosed by several polygons at once, anti-aliased, with the non-zero winding rule over all of them: polygons of the same orientation fill their union, so overlapping pieces of a stroke blend once.

**Parameters:**

- **polygons** : *std::span&lt; const std::vector&lt; [PointF](/docs/api/base/point-f) &gt; &gt;*
  Polygons, each with its corners in order; those with fewer than three are skipped.

- **color** : *[Rgb](/docs/api/base/rgb)*
  Fill colour.

- **opacity** : *int*
  Opacity of the fill, 0 (transparent) to 255 (opaque).

---

### blend_pixel(x, y, color, alpha)

Mixes a colour into one pixel; pixels outside the image are ignored.

**Parameters:**

- **x** : *int*
  Column.

- **y** : *int*
  Row.

- **color** : *[Rgb](/docs/api/base/rgb)*
  Colour to mix in.

- **alpha** : *int*
  Weight of `color`, 0 (none) to 255 (replaces the pixel).

---

### draw_text(x, baseline, text, color, scale)

Draws text with the built-in 5 x 7 pixel font, one pixel of spacing between characters.

The font covers digits, letters (upper-case letters are drawn as lower-case ones) and the characters space . , : ; + - = / % ( ) _ ; other characters are drawn as a box.

**Parameters:**

- **x** : *int*
  Left edge of the first character.

- **baseline** : *int*
  Row below the last row of the characters.

- **text** : *std::string_view*
  ASCII text.

- **color** : *[Rgb](/docs/api/base/rgb)*
  Text colour.

- **scale** : *int*
  Size of a font pixel in image pixels, at least 1.

---

## Static Methods

### decode_png(png)

Decodes a PNG file of 8-bit RGB or RGBA pixels without interlacing, e.g.

one written by `encode_png()`; an alpha channel is dropped.

**Parameters:**

- **png** : *std::span&lt; const std::uint8_t &gt;*
  The file contents.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [RasterImage](/docs/api/base/raster-image) &gt;* — The image, or a Format error for other or damaged files.

---

### load_png(path)

Reads a PNG file as `decode_png()` does.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Input file.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [RasterImage](/docs/api/base/raster-image) &gt;* — The image, an Io error if the file cannot be read, or a Format error.
