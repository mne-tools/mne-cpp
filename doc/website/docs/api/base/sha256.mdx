# Sha256

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/sha256.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/sha256.h)

`#include <base/sha256.h>`

```cpp
class mne::Sha256
```

Computes SHA-256 digests in one call or incrementally, e.g.

to fingerprint pipeline inputs.

Use `to_hex()` from `string_utils.h` for the hex text QCryptographicHash::hash(...).toHex() gives.

```cpp title="src/examples/ex_base/main.cpp"
// Qt:   QCryptographicHash::hash(text.toUtf8(), QCryptographicHash::Sha256).toHex()
const std::string fingerprint = to_hex(Sha256::hash("abc"));
Sha256 incremental; // or feed a large file block by block
incremental.update("a").update("bc");
```
