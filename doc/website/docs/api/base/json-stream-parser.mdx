# JsonStreamParser

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/json_stream_parser.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/json_stream_parser.h)

`#include <base/json_stream_parser.h>`

```cpp
class mne::JsonStreamParser
```

Incremental JSON parser for real-time streams: feed bytes as they arrive, get documents as they close.

The stream holds root objects or arrays back to back, with or without whitespace in between, which covers NDJSON (one document per line) and concatenated JSON (\{"event":1\}\{"event":2\}). Every root that closes is either

- queued for `take_document()`, the default,
- passed to the callback set with `set_document_callback()`, or
- reported token by token to the [`JsonHandler`](/docs/api/base/json-handler) set with `set_handler()`, without building any [`JsonDocument`](/docs/api/base/json-document).

Memory is bounded by `Options`: nesting depth, the bytes of one string or number held between chunks, and the bytes of one document. On malformed input `feed()` returns false, `error()` tells why and where, and the parser ignores input until `reset()`. Nothing throws, apart from std::bad_alloc and exceptions thrown by callbacks.

```cpp title="src/examples/ex_base/main.cpp"
JsonStreamParser stream; // NDJSON from a socket, split anywhere
std::vector<double> latencies;
stream.set_document_callback([&](JsonDocument&& event) { latencies.push_back(event["latency"].to_double()); });
for (const std::string_view packet : {"{\"latency\":1.5}\n{\"lat", "ency\":2", ".25}\n{\"latency\":3}"}) {
    if (!stream.feed(packet)) { // malformed input: report and resynchronize
        Log::warning("bad JSON at byte {}: {}", stream.error().offset, stream.error().error_string());
        stream.reset();
    }
}
```

### set_document_callback(callback)

Passes completed documents to `callback` instead of queueing them; call it between documents.

**Parameters:**

  Receives each document; an empty function queues documents again.

### set_handler(handler)

Reports tokens to `handler` instead of building documents; call it between documents.

**Parameters:**

- **handler** : *[JsonHandler](/docs/api/base/json-handler) **
  Receives the tokens and must outlive its use; nullptr builds documents again.

### feed(chunk)

Parses the next piece of the stream; tokens may be split anywhere, even inside a UTF-8 sequence.

**Parameters:**

- **chunk** : *std::string_view*
  The next bytes of the stream, of any length; they need not stay valid after the call.

**Returns:**

- *bool* — Whether the stream is still valid JSON; false once an error occurred, until `reset()`.

### finish()

Ends the stream: input that stops inside a document is an error, e.g.

UnterminatedObject. The parser stays usable for a new stream if this succeeds.

**Returns:**

- *bool* — Whether the stream ended between documents.

---

### reset()

Clears the error and any partial document so that parsing restarts with the next byte fed, e.g.

after a corrupt line of NDJSON; the options, handler, callback and the queue of complete documents are kept.
