# JsonDocument

**Namespace:** `BASELIB` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/json.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/json.h)

`#include <base/json.h>`

```cpp
class BASELIB::JsonDocument
```

A JSON document whose root is an array or an object, parsed from or written as UTF-8 text, like QJsonDocument.

```cpp title="src/examples/ex_base/main.cpp"
// Qt:   QJsonParseError error;
//       QJsonObject cfg = QJsonDocument::fromJson(bytes, &error).object();
//       int rate = cfg.value("sfreq").toInt(1000);
//       cfg["channels"] = QJsonArray{"MEG 0113", "EEG 001"};
//       QByteArray out = QJsonDocument(cfg).toJson(QJsonDocument::Compact);
JsonParseError parseError;
JsonObject cfg = JsonDocument::from_json(R"({"sfreq": 600, "device": "neuromag"})", &parseError).object();
const int rate = cfg.value("sfreq").to_int(1000);       // safe fallback on a missing key or wrong type
const bool hasGain = !cfg.value("gain").is_undefined(); // missing keys are undefined; non-const [] inserts, as in Qt
cfg["channels"] = JsonArray{"MEG 0113", "EEG 001"};
const std::string out = JsonDocument(cfg).to_json(JsonDocument::Compact); // keys sorted, like Qt
```

## Static Methods

### from_json(json, error)

Parses a whole document like QJsonDocument::fromJson(): the root must be an object or an array and only whitespace may follow it.

A UTF-8 byte order mark is skipped. Nesting is limited to 1024 levels, as in Qt.

**Parameters:**

- **json** : *std::string_view*
  UTF-8 text.

- **error** : *[JsonParseError](/docs/api/base/json-parse-error) **
  Receives the outcome if not null; error is NoError on success.

**Returns:**

- *[JsonDocument](/docs/api/base/json-document)* — The document, or a null document if `json` is not valid JSON.
