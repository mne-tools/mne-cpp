# Connectivity

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library

:::info[Python equivalent]
`mne_connectivity.spectral_connectivity_epochs` in MNE-Python.
:::

`#include <connectivity/connectivity.h>`

```cpp
class CONNECTIVITYLIB::Connectivity
```

Dispatcher that runs one or more functional-connectivity estimators over a batch of pre-processed trials and returns one [`Network`](/docs/api/connectivity/network) per estimator.

The selected methods are read from `CONNECTIVITYLIB::ConnectivitySettings::getConnectivityMethods` "[ConnectivitySettings](/docs/api/connectivity/connectivity-settings)::getConnectivityMethods" and matched by string against the supported metric set ("COR", "XCOR", "COH", "IMAGCOH", "PLI", "USPLI", "WPLI", "DSWPLI", "PLV", "GC", "DTF", "PDC"). All spectral metrics share the same DPSS tapered FFT and CSD accumulator inside [`ConnectivitySettings`](/docs/api/connectivity/connectivity-settings), so running e.g. PLI + wPLI + dwPLI in one call costs only one FFT pass.

Runs the selected functional-connectivity metrics over a [`ConnectivitySettings`](/docs/api/connectivity/connectivity-settings) batch.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
ConnectivitySettings settings;
for (int i = 0; i < kTrials; ++i) {
    settings.append(makeTrial(gen)); // channels x samples, one call per trial
}
settings.setSamplingFrequency(kSFreq);
settings.setFFTSize(kSamples);
settings.setWindowType("hanning");

MatrixX3f positions(3, 3);
positions << 0.0f, 0.0f, 0.0f, 0.05f, 0.0f, 0.0f, 0.0f, 0.05f, 0.0f;
settings.setNodePositions(positions);
```

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
settings.setConnectivityMethods({"COH", "PLV", "WPLI"});
const QList<Network> networks = Connectivity::calculate(settings);
for (Network network : networks) {
    network.setFrequencyRange(8.0f, 12.0f); // average the per-bin weights over the alpha band
    qInfo().noquote() << network.getConnectivityMethod() << "0-1:" << edgeWeight(network, 0, 1);
}
```

## Static Methods

### calculate(connectivitySettings)

Computes the network based on the current settings.

**Parameters:**

- **connectivitySettings** : *[ConnectivitySettings](/docs/api/connectivity/connectivity-settings) &*
  Input trials and requested methods; per-trial spectral caches are filled in during computation.

**Returns:**

- *QList&lt; [Network](/docs/api/connectivity/network) &gt;* — Returns the list with calculated networks for each provided method.
