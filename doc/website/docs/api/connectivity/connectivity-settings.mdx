# ConnectivitySettings

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/connectivitysettings.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/connectivitysettings.h)

`#include <connectivity/connectivitysettings.h>`

<Connections topics={["connectivity"]} context="api" current="ConnectivitySettings" />

```cpp
class mne::ConnectivitySettings
```

Mutable container that aggregates the inputs and intermediate spectral results required by every metric implementation in `mne_connectivity`.

Each call to `mne::ConnectivitySettings::append` "append" adds one trial; the trial matrices live in `m_trialData`, while DPSS tapered spectra, cross-spectral densities and their imaginary-part derivatives are filled in lazily by whichever metric runs first. Cross-trial sums accumulate in `m_intermediateSumData` so that a second metric run on the same data set reuses those sums and skips the FFT pass entirely. Node positions can be derived from a [`FiffInfo`](/docs/api/fiff/fiff-info) (sensor space) or from a forward solution + [`FsSurfaceSet`](/docs/api/fs/fs-surface-set) (source space) and are propagated into the resulting [`Network`](/docs/api/connectivity/network) nodes.

Aggregates trial data, spectral cache and node geometry shared by all `mne_connectivity` metrics.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
ConnectivitySettings settings;
for (int i = 0; i < kTrials; ++i) {
    settings.append(makeTrial(gen)); // channels x samples, one call per trial
}
settings.setSamplingFrequency(kSFreq);
settings.setFFTSize(kSamples);
settings.setWindowType("hanning");

MatrixX3f positions(3, 3);
positions << 0.0f, 0.0f, 0.0f, 0.05f, 0.0f, 0.0f, 0.0f, 0.05f, 0.0f;
settings.setNodePositions(positions);
```

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
// Spectral metrics evaluate the bins [start, start + count); -1 means the full half spectrum.
settings.set_frequency_bins(-1, -1);
settings.set_keep_trial_data(false); // keep them to compute only appended trials next time
```

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
settings.setConnectivityMethods({"COH", "PLV", "WPLI"});
std::vector<Network> networks = compute_connectivity(settings);
for (Network network : networks) {
    network.set_frequency_range(8.0f, 12.0f); // average the per-bin weights over the alpha band
    std::println("{} 0-1: {:g}", network.method(), edgeWeight(network, 0, 1));
}
```

### set_frequency_bins(start, count)

Restricts the spectral metrics to a range of frequency bins of the half spectrum.

Changing it drops the kept per-trial spectra.

**Parameters:**

- **start** : *int*
  First bin; -1 for the whole spectrum.

- **count** : *int*
  Number of bins; -1 for the whole spectrum.

---

### frequency_bins()

**Returns:**

- *std::pair&lt; int, int &gt;* — The first frequency bin and the number of bins the spectral metrics use: the whole half spectrum of the FFT size unless a range inside it was set.

---

### set_keep_trial_data(keep)

Keeps the tapered spectra and cross-spectra of each trial, so that the next metric call computes only those of the trials appended since.

Off by default to save memory.

**Parameters:**

- **keep** : *bool*
  Whether to keep them.

---

### keeps_trial_data()

**Returns:**

- *bool* — Whether the per-trial spectra are kept between metric calls.
