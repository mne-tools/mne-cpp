# AbstractMetric

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/metrics/abstractmetric.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/connectivity/metrics/abstractmetric.h)

`#include <mne/connectivity/abstractmetric.h>`

```cpp
class mne::AbstractMetric
```

Common base of the connectivity metrics.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
settings.setConnectivityMethods({"COH", "PLV", "WPLI"});
std::vector<Network> networks = compute_connectivity(settings);
for (Network network : networks) {
    network.set_frequency_range(8.0f, 12.0f); // average the per-bin weights over the alpha band
    std::println("{} 0-1: {:g}", network.method(), edgeWeight(network, 0, 1));
}
```
