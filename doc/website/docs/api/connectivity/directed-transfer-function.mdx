# DirectedTransferFunction

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library

:::info[Python equivalent]
`mne_connectivity.spectral_connectivity_epochs (method='dtf')` in MNE-Python.
:::

`#include <connectivity/directed_transfer_function.h>`

```cpp
class CONNECTIVITYLIB::DirectedTransferFunction
```

Directed Transfer Function estimator of Kaminski & Blinowska (1991).

Computes `DTF_{ij}`(f) = |H_\{ij\}(f)|^2 / sum_k |H_\{ik\}(f)|^2 from the transfer matrix `H` delivered by [`MvarModel`](/docs/api/connectivity/mvar-model) and reduces it to a scalar edge weight by averaging over the frequency window defined on [`AbstractMetric`](/docs/api/connectivity/abstract-metric). The resulting [`Network`](/docs/api/connectivity/network) is directional and includes both direct and indirect causal pathways - use [`PartialDirectedCoherence`](/docs/api/connectivity/partial-directed-coherence) for direct-only flow.

Directed Transfer Function estimator (Kaminski & Blinowska 1991); directional, includes indirect paths.
