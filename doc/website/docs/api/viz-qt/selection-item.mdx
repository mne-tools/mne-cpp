# SelectionItem

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/viewers/helpers/selectionitem.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/viewers/helpers/selectionitem.h)

`#include <mne/viz/backends/qt/selectionitem.h>`

```cpp
class mne::viz::qt::SelectionItem
```

The channels picked in a sensor layout: names, numbers, kinds, units and layout positions, one entry per channel in each vector.

[`ChannelSelectionView`](/docs/api/viz-qt/channel-selection-view) emits it when the selection changes; [`AverageLayoutView`](/docs/api/viz-qt/average-layout-view) and the analysis plugins show only these channels.
