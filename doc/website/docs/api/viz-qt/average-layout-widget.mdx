# AverageLayoutWidget

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/viewers/helpers/averagelayoutwidget.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/viewers/helpers/averagelayoutwidget.h)

`#include <mne/viz/backends/qt/averagelayoutwidget.h>`

```cpp
class mne::viz::qt::AverageLayoutWidget
```

Evoked responses, one tile per channel at its layout position, as MNE-Python's plot_evoked_topo.

The widget shows views of data it does not own: each average of a channel points into a column-major evoked matrix that must outlive the next repaint. Pressing a tile enlarges its name until the button is released.
