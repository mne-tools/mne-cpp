# ColorMap

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/plots/helpers/colormap.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/plots/helpers/colormap.h)

`#include <mne/viz/backends/qt/colormap.h>`

```cpp
class mne::viz::qt::ColorMap
```

Static lookup helpers mapping scalar values to `QRgb` / `QColor` across all mne_disp palettes.

The `valueToXxx` accessors map any value in $[0,1]$ to a colour without instantiating an object; `mne::viz::map_color()` is the Qt-free equivalent. Bundled palettes include Viridis, Jet, Hot, HotNeg1, HotNeg2, Bone, Cool, RedBlue and the MNE-Python `hot` variant.

```cpp title="src/examples/ex_disp_plots/main.cpp"
const QRgb low = ColorMap::valueToColor(0.0, "Viridis"); // v in [0, 1]
const QRgb mid = ColorMap::valueToColor(0.5, "Viridis");
const QRgb jet = ColorMap::valueToJet(0.25);
```

## Static Methods

### valueToColor(v, sMap)

Returns a Jet RGB to a given double value [0,1] and a colormap specified by sMap.

If no matching colormap was found return Jet.

**Parameters:**

- **v** : *double*
  the double which has to be part of the intervall [0,1].

- **sMap** : *const QString &*
  the colormap to choose.

**Returns:**

- *QRgb* — the corresponding RGB value.
