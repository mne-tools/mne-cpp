# RenderKey

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/3d/core/rendertypes.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/3d/core/rendertypes.h)

`#include <mne/viz/backends/qt/rendertypes.h>`

```cpp
class mne::viz::qt::RenderKey
```

Identity of a renderable in the renderer's GPU resource cache.

The renderer drops the GPU copies of a renderable once its key is destroyed. A copied renderable gets a key of its own, so it never shares GPU buffers with the original.
