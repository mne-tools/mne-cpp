# BidsViewModel

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/viewers/helpers/bidsviewmodel.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/viewers/helpers/bidsviewmodel.h)

`#include <mne/viz/backends/qt/bidsviewmodel.h>`

```cpp
class mne::viz::qt::BidsViewModel
```

QStandardItemModel mirroring the BIDS dataset hierarchy (subjects / sessions / runs / derivatives).

Rebuilds itself from a top-level dataset path; item roles carry the absolute path, BIDS entity type and loadable-by-this-app flag so the host [`BidsView`](/docs/api/viz-qt/bids-view) can dispatch double-clicks without re-walking the file system.
