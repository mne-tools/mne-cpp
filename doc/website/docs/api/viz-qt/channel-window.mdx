# ChannelWindow

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/viewers/helpers/channelwindow.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/viewers/helpers/channelwindow.h)

`#include <mne/viz/backends/qt/channelwindow.h>`

```cpp
class mne::viz::qt::ChannelWindow
```

Widgets-free QWindow host of the GPU raw-data channel trace view.

The view state and API live in `renderer()`; the window re-emits the renderer's signals. Embed it in a widget layout with `createWindowContainer()` of Qt Widgets.
