# DipoleObject

**Namespace:** `mne::viz::qt` &nbsp;·&nbsp; **Library:** Visualization: Qt Backend &nbsp;·&nbsp; **Source:** [`viz/backends/qt/3d/renderable/dipoleobject.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/backends/qt/3d/renderable/dipoleobject.h)

`#include <mne/viz/backends/qt/dipoleobject.h>`

```cpp
class mne::viz::qt::DipoleObject
```

Renderable dipole object that builds instanced arrow geometry from an [`InvEcdSet`](/docs/api/inv/inv-ecd-set) and provides its CPU streams for instanced rendering.

Renderable dipole arrow set with instanced GPU rendering.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
InvEcdSet dipoles;
InvEcd strong;
strong.rd = Vector3f(0.0f, 0.0f, 0.05f);
strong.Q = Vector3f(0.0f, 0.0f, 20e-9f);
InvEcd weak;
weak.rd = Vector3f(0.03f, 0.0f, 0.05f);
weak.Q = Vector3f(10e-9f, 0.0f, 0.0f);
dipoles.push_back(strong);
dipoles.push_back(weak);
DipoleObject dipoleGlyphs;
dipoleGlyphs.load(dipoles); // one cone per dipole, scaled by moment
float dipoleDistance = 0.0f;
const int pickedDipole = dipoleGlyphs.intersect(QVector3D(0.03f, 0.0f, 0.2f), QVector3D(0.0f, 0.0f, -1.0f), dipoleDistance);
```
