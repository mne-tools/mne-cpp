# SelectionIO

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

`#include <utils/selectionio.h>`

```cpp
class UTILSLIB::SelectionIO
```

Processes selection files (mne .sel) files which contain the channels for each selection group.

Reader/writer for [MNE](/docs/api/mne/mne-class) .sel channel-selection files and Brainstorm .mon montage files.

```cpp title="src/examples/ex_utils/main.cpp"
QMultiMap<QString, QStringList> selections;
selections.insert("Left-temporal", {"MEG0111", "MEG0112", "MEG0113"});
selections.insert("Vertex", {"MEG0711"});
const QString selPath = dir.filePath("groups.sel");
SelectionIO::writeMNESelFile(selPath, selections);
QMultiMap<QString, QStringList> reread;
SelectionIO::readMNESelFile(selPath, reread);
```

## Static Methods

### readMNESelFile(path, selectionMap)

Reads the specified [MNE](/docs/api/mne/mne-class) sel file.

**Parameters:**

- **path** : *QString*
  holds the file path of the .sel file which is to be read.

- **selectionMap** : *QMultiMap&lt; QString, QStringList &gt; &*
  holds the map to which the read selection groups are stored.

**Returns:**

- *bool* — True on success, false if the path lacks a .sel extension or the file cannot be opened.
