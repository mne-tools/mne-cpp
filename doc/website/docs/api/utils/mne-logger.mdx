# MNELogger

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

`#include <utils/mne_logger.h>`

```cpp
class UTILSLIB::MNELogger
```

The Apllicationlogger provides colorized keywords in terminal outputs for better overview.

Custom Qt message handler that formats and routes qDebug/qWarning/qCritical output to file or console.

```cpp title="src/examples/ex_utils/main.cpp"
qInstallMessageHandler(MNELogger::customLogWriter); // coloured console output
MNELogger::setLogFile(dir.filePath("example.log")); // and a plain-text copy
qInfo() << "logging to" << MNELogger::logFile();
```

---

## Static Methods

### customLogWriter(type, context, msg)

Customized logWriter to colorize type of the message in the terminal.

**Parameters:**

- **type** : *QtMsgType*
  Enum to identify the various message types (qDebug, qInfo, qCritical, qWarning and qFatal).

- **context** : *const QMessageLogContext &*
  Context provides information about the source code location.

- **msg** : *const QString &*
  The message to print in the terminal.

---

### setLogFile(sFilePath)

Additionally writes every message to a log file.

Console output is unaffected. The file is opened in append mode and each line is prefixed with a timestamp and the message level, without the terminal colour codes. Passing an empty path stops file logging.

**Parameters:**

- **sFilePath** : *const QString &*
  Path of the log file, or an empty string to disable.

**Returns:**

- *bool* — True if the file could be opened for writing.

---

### logFile()

Returns the path of the current log file, empty if file logging is off.

**Returns:**

- *QString* — Path of the active log file, or an empty string if file logging is disabled.
