# ArtifactDetect

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

`#include <utils/artifact_detect.h>`

```cpp
class UTILSLIB::ArtifactDetect
```

ECG and EOG physiological artifact event detection.

```cpp title="src/examples/ex_dsp_artifacts/main.cpp"
ArtifactDetect::EcgParams ecg;                                                  // mne find_ecg_events defaults: 5-35 Hz, automatic QRS threshold
ArtifactDetect::EogParams eog;                                                  // mne find_eog_events defaults: 1-10 Hz, automatic peak threshold
const QVector<int> beats = ArtifactDetect::detectEcg(data, info, kSFreq, ecg);  // R-peak samples on the ECG channel
const QVector<int> blinks = ArtifactDetect::detectEog(data, info, kSFreq, eog); // blink peaks on the EOG channel
```

---

## Static Methods

### detectEcg(matData, fiffInfo, dSFreq, params)

Detect ECG R-peak events as mne.preprocessing.find_ecg_events does.

Uses the first good channel with kind == FIFFV_ECG_CH; without one, the mean of the good magnetometers (or, failing those, gradiometers) stands in for it.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Raw data matrix (n_channels × n_samples), calibrated (SI units).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info (channel kinds, names).

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **params** : *const EcgParams &*
  Detection parameters.

**Returns:**

- *QVector&lt; int &gt;* — Sample indices (0-based) of detected R-peaks.

---

### detectEog(matData, fiffInfo, dSFreq, params)

Detect EOG blink/saccade events as mne.preprocessing.find_eog_events does.

Of the good channels with kind == FIFFV_EOG_CH, the one with the most 2-45 Hz energy is used. Returns an empty vector if no EOG channel is found.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Raw data matrix (n_channels × n_samples), calibrated (SI units).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info.

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **params** : *const EogParams &*
  Detection parameters.

**Returns:**

- *QVector&lt; int &gt;* — Sample indices (0-based) of the detected EOG peaks.
