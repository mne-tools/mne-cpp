# LayoutLoader

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library &nbsp;·&nbsp; **Source:** [`utils/layoutloader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/utils/layoutloader.h)

`#include <utils/layoutloader.h>`

```cpp
class UTILSLIB::LayoutLoader
```

Reads ANT .elc files, which contain the electrode positions of an EEG cap.

Reads ANT .elc electrode files into Qt/STL containers.

```cpp title="src/examples/ex_utils/main.cpp"
// ANT .elc electrode file: names, 3-D positions and their unit
QStringList capNames;
QList<QVector<float>> cap3D;
QList<QVector<float>> cap2D;
QString capUnit;
LayoutLoader::readAsaElcFile(capFile.fileName(), capNames, cap3D, cap2D, capUnit);
```

---

## Static Methods

### readAsaElcFile(path, channelNames, location3D, location2D, unit)

Reads the specified ANT elc-layout file.

**Parameters:**

- **path** : *const QString &*
  holds the file path of the elc file which is to be read.

- **channelNames** : *QStringList &*
  Receives the channel names.

- **location3D** : *QList&lt; QVector&lt; float &gt; &gt; &*
  holds the vector to which the read 3D positions are stored.

- **location2D** : *QList&lt; QVector&lt; float &gt; &gt; &*
  holds the vector to which the read 2D positions are stored.

- **unit** : *QString &*
  Receives the unit of the positions.

**Returns:**

- *bool* — true if reading was successful, false otherwise.
