# IOUtils

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

`#include <utils/ioutils.h>`

```cpp
class UTILSLIB::IOUtils
```

IO utility routines for reading/writing Eigen matrices to text files.

Eigen matrix I/O utilities.

```cpp title="src/examples/ex_utils/main.cpp"
MatrixXd matrix(2, 3);
matrix << 1.5, -2.0, 3.25, 0.0, 1e-6, 42.0;
const QString matrixPath = dir.filePath("matrix.txt");
IOUtils::write_eigen_matrix(matrix, matrixPath, "example matrix");
MatrixXd readBack;
IOUtils::read_eigen_matrix(readBack, matrixPath);
```

## Static Methods

### write_eigen_matrix(in, sPath, sDescription)

Write Eigen Matrix to file (QString path).

**Parameters:**

- **in** : *const Eigen::Matrix&lt; T, Eigen::Dynamic, Eigen::Dynamic &gt; &*
  Matrix to write as whitespace-separated text, one row per line.

- **sPath** : *const QString &*
  Path of the output file; an existing file is overwritten.

- **sDescription** : *const QString &*
  Optional description; if non-empty, a dimensions and description header is written.

**Returns:**

- *bool* — True on success, false if the file could not be opened for writing.
