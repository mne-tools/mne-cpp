# IOUtils

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library &nbsp;·&nbsp; **Source:** [`utils/ioutils.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/utils/ioutils.h)

`#include <utils/ioutils.h>`

```cpp
class UTILSLIB::IOUtils
```

IO utility routines for reading/writing Eigen matrices to text files.

Eigen matrix I/O utilities.

```cpp title="src/examples/ex_utils/main.cpp"
MatrixXd matrix(2, 3);
matrix << 1.5, -2.0, 3.25, 0.0, 1e-6, 42.0;
const QString matrixPath = dir.filePath("matrix.txt");
IOUtils::write_eigen_matrix(matrix, matrixPath, "example matrix");
MatrixXd readBack;
IOUtils::read_eigen_matrix(readBack, matrixPath);
```

### write_eigen_matrix(in, sPath, sDescription)

Write Eigen Matrix to file (QString path).

**Parameters:**

- **in** : *const Eigen::Matrix&lt; T, Eigen::Dynamic, Eigen::Dynamic &gt; &*
  Matrix to write as whitespace-separated text, one row per line.

- **sPath** : *const QString &*
  Path of the output file; an existing file is overwritten.

- **sDescription** : *const QString &*
  Optional description; if non-empty, a dimensions and description header is written.

**Returns:**

- *bool* — True on success, false if the file could not be opened for writing.

MatrixXd matrix(2, 3);
matrix << 1.5, -2.0, 3.25, 0.0, 1e-6, 42.0;
const QString matrixPath = dir.filePath("matrix.txt");
IOUtils::write_eigen_matrix(matrix, matrixPath, "example matrix");
MatrixXd readBack;
IOUtils::read_eigen_matrix(readBack, matrixPath);

### [ex_inv_hpi](../../examples/inv/ex_inv_hpi.mdx)

Inverse library: continuous head position (HPI) fitting.

````cpp title="src/examples/ex_inv_hpi/main.cpp, line 114"
// MaxFilter head position at t = 0: translation (-0.814, -11.046, 53.572) mm. One 200 ms window, so allow 1 mm
// (test_hpiFit_integration holds the mean over the whole recording to 0.3 mm).
MatrixXd maxfilter;
IOUtils::read_eigen_matrix(maxfilter, data + "/Result/ref_hpiFit_pos.txt");
const Vector3d translation = fit.devHeadTrans.trans.block<3, 1>(0, 3).cast<double>();
const Vector3d reference = maxfilter.block<1, 3>(0, 4).transpose();
ok &= expect(fit.hpiFreqs == QVector<int>({166, 154, 161, 158}) && fit.GoF.minCoeff() > 0.98 && (translation - reference).norm() < 0.001,
             QString("InvHpiDataUpdater/InvHpiModelParameters/InvHpiFit: coils ordered 166/154/161/158 Hz, head position within %1 mm of MaxFilter")
                 .arg(1e3 * (translation - reference).norm(), 0, 'f', 3));
````
