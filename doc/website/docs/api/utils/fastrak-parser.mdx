# FastrakParser

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

`#include <utils/fastrak_parser.h>`

```cpp
class UTILSLIB::FastrakParser
```

Streaming parser for Fastrak / FastSCAN ASCII records.

Thread-affine: the caller is responsible for serialising calls. No heap allocations on the hot path other than the internal buffer.

```cpp title="src/examples/ex_utils/main.cpp"
FastrakParser parser;
parser.setUnits(FastrakParser::Units::Centimetres);
parser.append("01   12.50  -3.25   8.00\r\n02  1.0"); // the second record is still incomplete
FastrakSample sample;
const bool complete = parser.nextSample(sample);
const bool pending = parser.nextSample(sample);
```

### nextSample(out)

Pop the next fully-decoded sample, if any.

**Parameters:**

- **out** : *[FastrakSample](/docs/api/utils/fastrak-sample) &*
  Receives the decoded sample; malformed lines are skipped.

**Returns:**

- *bool* — true when `out` was populated; false when the buffer does not yet contain a complete record.

---

### reset()

## Static Methods

### parseRecord(record, units, out)

Parse one record line (without trailing CR/LF) — exposed for unit tests and for callers that pre-frame their data.

**Parameters:**

- **record** : *const QByteArray &*
  One ASCII record: station, x, y, z, and optional Euler angles or quaternion.

- **units** : *Units*
  Unit of the positions in `record`.

- **out** : *[FastrakSample](/docs/api/utils/fastrak-sample) &*
  Receives the decoded sample with the position in metres.

**Returns:**

- *bool* — true on success; false on malformed input.
