# StandardMontage

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library

:::info[Python equivalent]
`mne.channels.make_standard_montage` in MNE-Python.
:::

`#include <utils/standard_montage.h>`

```cpp
class UTILSLIB::StandardMontage
```

Standard EEG montage with named electrode positions.

```cpp title="src/examples/ex_utils/main.cpp"
const QList<ElectrodePosition> montage1020 = StandardMontage::getMontage(StandardMontage::System::Standard_1020);
Vector3d cz;
const bool found = StandardMontage::findElectrode("Cz", cz); // mne's standard_1005 positions, metres, MNI frame
```

---

## Static Methods

### getMontage(system)

Get a standard montage by system name.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *QList&lt; [ElectrodePosition](/docs/api/utils/electrode-position) &gt;* — List of electrode positions.

---

### getElectrodeNames(system)

Get electrode names for a standard montage.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *QStringList* — List of electrode names.

---

### findElectrode(name, pos)

Look up a single electrode position by name.

Searches every position of the standard_1005 table, including the fiducials Nz, LPA and RPA.

**Parameters:**

- **name** : *const QString &*
  Electrode name (case-insensitive).

- **pos** : *Eigen::Vector3d &*
  Position if found.

**Returns:**

- *bool* — true if found.

---

### electrodeCount(system)

Get the number of electrodes in a montage.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *int* — Number of electrode positions defined for the montage.
