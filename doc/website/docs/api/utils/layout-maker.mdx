Make layout files from given 3D points.

Make layout files from given 3D points.

```cpp title="src/examples/ex_utils/main.cpp"
// Azimuthal equidistant projection around the fitted sphere: Cz lands near the centre, the nose points up
QList<QVector<float>> points3d;
QStringList names;
for (const ElectrodePosition& electrode : montage1020) {
    points3d.append({static_cast<float>(electrode.pos.x()), static_cast<float>(electrode.pos.y()), static_cast<float>(electrode.pos.z())});
    names.append(electrode.name);
}
QList<QVector<float>> layout2d;
QFile layoutFile(dir.filePath("1020.lout"));
LayoutMaker::makeLayout(points3d, layout2d, names, layoutFile, true, 20.0f, 5.0f, 4.0f, true);
```

**Parameters:**

- **inputPoints** : *const QList&lt; QVector&lt; float &gt; &gt; &*
  The input points in 3D space.

- **outputPoints** : *QList&lt; QVector&lt; float &gt; &gt; &*
  The output layout points in 2D space.

- **names** : *const QStringList &*
  The channel names.

- **outFile** : *QFile &*
  The outout file.

- **do_fit** : *bool*
  The flag whether to do a sphere fitting.

- **prad** : *float*
  Radius of the projection disk in layout units.

- **w** : *float*
  Width of each channel box in layout units.

- **h** : *float*
  Height of each channel box in layout units.

- **writeFile** : *bool*
  The flag whether to write to file.

- **mirrorXAxis** : *bool*
  Mirror points at x axis.

- **mirrorYAxis** : *bool*
  Mirror points at y axis.

**Returns:**

- *bool* — true if making layout was successful, false otherwise.
