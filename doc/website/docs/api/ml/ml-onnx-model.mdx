# MlOnnxModel

**Namespace:** `MLLIB` &nbsp;·&nbsp; **Library:** Machine Learning Library

`#include <ml/ml_onnx_model.h>`

```cpp
class MLLIB::MlOnnxModel
```

[`MlModel`](/docs/api/ml/ml-model) backend that runs ``.onnx graphs through ONNX Runtime with a cached CPU session.

When mne-cpp is configured without `USE_ONNXRUNTIME` every method either throws `std::runtime_error` (`predict`) or returns false / logs a warning (`load`, `save`), so the same client code compiles and links on minimal builds and on WebAssembly without conditional call sites.

```cpp title="src/examples/ex_ml/main.cpp"
std::unique_ptr<MlModel> model = std::make_unique<MlOnnxModel>();
const bool loaded = model->load(MNE_EX_ML_DATA_DIR "/affine_softmax.onnx");
const MlTensor probabilities = model->predict(batch); // shape {2, 2}, one row per sample
const QString classes = static_cast<MlOnnxModel&>(*model).metadata("classes");
```
