# CommandParser

**Namespace:** `COMLIB` &nbsp;·&nbsp; **Library:** Communication Library

`#include <com/command_parser.h>`

```cpp
class COMLIB::CommandParser
```

Observer-pattern subject that decodes JSON or CLI command strings into [`RawCommand`](/docs/api/com/raw-command) and notifies attached managers.

Single entry point ``parse()`` accepts either dialect, builds a [`[RawCommand](/docs/api/com/raw-command)`](/docs/api/com/raw-command), and broadcasts it to every attached [`[CommandManager](/docs/api/com/command-manager)`](/docs/api/com/command-manager); the `response` signal carries replies back from whichever manager handled the request so the caller (typically a [`[RtCmdClient](/docs/api/com/rt-cmd-client)`](/docs/api/com/rt-cmd-client)) can forward them to the originating socket.
