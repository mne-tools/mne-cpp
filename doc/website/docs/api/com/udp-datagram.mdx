# UdpDatagram

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Communication Library &nbsp;·&nbsp; **Source:** [`com/udp_socket.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/com/udp_socket.h)

`#include <com/udp_socket.h>`

```cpp
struct mne::UdpDatagram
```

Size and sender of a datagram received with `UdpSocket::receive_from()`.

```cpp title="src/examples/ex_com/main.cpp"
auto service = UdpSocket::bind("127.0.0.1", 0);
auto asking = UdpSocket::bind("127.0.0.1", 0);
std::string answer;
if (service && asking && !asking->send_to(std::as_bytes(std::span(std::string_view("?"))), "127.0.0.1", service->port())) {
    std::array<std::byte, 64> query{};
    const auto from = service->receive_from(query, 500ms); // size, address and port of the sender
    if (from && !service->send_to(std::as_bytes(std::span(std::string_view("here"))), from->address, from->port)) {
        std::array<std::byte, 64> reply{};
        const auto replySize = asking->receive(reply, 500ms);
        answer.assign(reinterpret_cast<const char*>(reply.data()), replySize ? *replySize : 0);
    }
}
```
