# CommandManager

**Namespace:** `COMLIB` &nbsp;·&nbsp; **Library:** Communication Library

`#include <com/command_manager.h>`

```cpp
class COMLIB::CommandManager
```

Observer-side registry of [`Command`](/docs/api/com/command) schemas a subsystem accepts from the shared [`CommandParser`](/docs/api/com/command-parser).

Holds a `QMap<QString,Command>` indexed by command keyword; when [`CommandParser`](/docs/api/com/command-parser) notifies attached managers of a new [`RawCommand`](/docs/api/com/raw-command), each manager looks the keyword up in its own map and either dispatches the corresponding `[`[Command](/docs/api/com/command)`](/docs/api/com/command)` (re-emitting `triggered` / `response`) or silently passes. Schemas can be added one at a time or bulk-loaded from a `QJsonDocument` matching the server’s self-described command list.
