# TcpSocket

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Communication Library &nbsp;·&nbsp; **Source:** [`com/tcp_socket.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/com/tcp_socket.h)

`#include <mne/com/tcp_socket.h>`

```cpp
class mne::TcpSocket
```

A connected TCP socket; move-only, closed on destruction.

```cpp title="src/examples/ex_com/main.cpp"
auto server = TcpSocket::connect("127.0.0.1", 1, 500ms);
if (!server) {
    std::println("no server: {}", server.error().message());
}
```

### write(data, timeout)

As `write()`, within a time limit, e.g.

so a peer that stops reading cannot hold the caller.

**Parameters:**

- **data** : *std::span&lt; const std::byte &gt;*
  Bytes to send, all of them.

- **timeout** : *std::chrono::milliseconds*
  Maximum wait for the peer to take all of them.

**Returns:**

- *std::error_code* — timed_out if the peer did not take them in time (part of them may have been sent), or the system's error if the connection fails.

---

### read(buffer, timeout)

Reads exactly `buffer.size()` bytes.

**Parameters:**

- **buffer** : *std::span&lt; std::byte &gt;*
  Destination.

- **timeout** : *std::chrono::milliseconds*
  Maximum wait for the first byte; the rest must follow within it too.

**Returns:**

- *std::error_code* — timed_out if nothing arrived (nothing is consumed then), io_error if the rest did not follow, connection_reset if the peer closed the connection, or the system's error.

---

### read_some(buffer, timeout)

Reads what has arrived, up to `buffer.size()` bytes.

**Parameters:**

- **buffer** : *std::span&lt; std::byte &gt;*
  Destination.

- **timeout** : *std::chrono::milliseconds*
  Maximum wait for the first byte; 0 only takes what has arrived.

**Returns:**

- *std::expected&lt; std::size_t, std::error_code &gt;* — The number of bytes read (at least one), timed_out if nothing arrived, connection_reset if the peer closed the connection, or the system's error.

---

### is_open()

**Returns:**

- *bool* — Whether the socket holds a connection; one the peer closed is still open until a read reports it.

### [ex_com](../../examples/com/ex_com.mdx)

Communication library: receive datagrams and talk to a TCP server with timeouts.

````cpp title="src/examples/ex_com/main.cpp, line 107"
std::println("TCP: serve a client and answer what it sends");
auto listening = TcpServer::listen("127.0.0.1", 0); // 0: the system chooses the port
auto client = TcpSocket::connect("127.0.0.1", listening ? listening->port() : 0, 500ms);
auto connection = listening ? listening->accept(500ms) : std::unexpected(listening.error());
std::size_t request = 0;
if (client && connection && !client->write(std::as_bytes(std::span(std::string_view("hello"))))) {
    std::array<std::byte, 64> buffer{};
    const auto got = connection->read_some(buffer, 500ms); // what has arrived, at most 64 bytes
    request = got ? *got : 0;
}
ok &= expect(request > 0 && request <= 5, "the server read the request of its client");
````
