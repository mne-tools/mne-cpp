# RawCommand

**Namespace:** `COMLIB` &nbsp;·&nbsp; **Library:** Communication Library

`#include <com/raw_command.h>`

```cpp
class COMLIB::RawCommand
```

Tokenised but unresolved command: a keyword plus a list of raw string arguments awaiting type binding.

Emitted by [`CommandParser`](/docs/api/com/command-parser) before any [`CommandManager`](/docs/api/com/command-manager) has claimed the request. Observers turn the `QList<QString>` arguments into typed [`Command`](/docs/api/com/command) parameters once the matching schema is located. Retains the JSON-vs-CLI dialect flag so replies travel back in the same encoding the caller used.
