# FsSurface

**Namespace:** `FSLIB` &nbsp;·&nbsp; **Library:** FreeSurfer Library

:::info[Python equivalent]
`mne.read_surface` in MNE-Python.
:::

`#include <fs/fs_surface.h>`

```cpp
class FSLIB::FsSurface
```

In-memory FreeSurfer triangular cortical surface for one hemisphere.

Owns the vertex coordinate matrix (n_vertices × 3, Tk-surface RAS mm), the triangle index matrix (n_faces × 3, zero-based into the vertex array) and the hemisphere id (0 = `lh`, 1 = `rh`). Construction is purely an I/O operation: each constructor either takes a direct path to a `lh.pial` / `rh.white` / `lh.inflated` style binary surface file, or the `subject_id` / `hemi` / `surf` shorthand resolved against `$SUBJECTS_DIR`. The instance is intended to be paired with an [`FsAnnotation`](/docs/api/fs/fs-annotation) or [`FsLabel`](/docs/api/fs/fs-label) sharing the same vertex indexing.

```cpp title="src/examples/ex_fs/main.cpp"
FsSurface white("sample", 0, "white", subjectsDir); // lh = 0, rh = 1; curvature is loaded alongside
const MatrixX3f& rr = white.rr();                   // vertices (metres)
const MatrixX3i& tris = white.tris();
const VectorXf& curv = white.curv();
```
