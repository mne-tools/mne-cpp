# FsAnnotationSet

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** FreeSurfer Library &nbsp;·&nbsp; **Source:** [`fs/fs_annotationset.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fs/fs_annotationset.h)

`#include <fs/fs_annotationset.h>`

```cpp
class mne::FsAnnotationSet
```

Container holding the lh and/or rh [`FsAnnotation`](/docs/api/fs/fs-annotation) for one parcellation atlas.

Keyed on hemisphere id (0 = lh, 1 = rh). When loaded from a single atlas name both hemispheres share the same colortable layout, so cross-hemisphere region lookup is consistent. The set is intended to be aligned one-to-one with an [`FsSurfaceSet`](/docs/api/fs/fs-surface-set) sharing the same subject and vertex count per hemisphere.

```cpp title="src/examples/ex_fs/main.cpp"
FsAnnotationSet parcellation("sample", 2, "aparc", subjectsDir.toStdU16String());
```
