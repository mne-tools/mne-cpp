# FsColortable

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** FreeSurfer Library &nbsp;·&nbsp; **Source:** [`fs/fs_colortable.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fs/fs_colortable.h)

`#include <fs/fs_colortable.h>`

```cpp
class mne::FsColortable
```

FreeSurfer colour lookup table: region name + RGBA + packed label, indexed by entry.

Backs the colour/structure mapping used by [`FsAnnotation`](/docs/api/fs/fs-annotation) and by any caller that needs to translate a packed .annot label into the matching anatomical name and RGBA colour. The container is a thin value object: rows of `table` align with `struct_names`, and the label column matches the per-vertex integer stored in .annot files so direct equality lookup is sufficient.

```cpp title="src/examples/ex_fs/main.cpp"
FsAnnotation aparc("sample", 0, "aparc", subjectsDir.toStdU16String());
FsColortable& colors = aparc.getColortable();
std::vector<FsLabel> regions;
std::vector<RowVector4i> regionColors;
aparc.toLabels(white, regions, regionColors);
```

FsAnnotation aparc("sample", 0, "aparc", subjectsDir.toStdU16String());
FsColortable& colors = aparc.getColortable();
std::vector<FsLabel> regions;
std::vector<RowVector4i> regionColors;
aparc.toLabels(white, regions, regionColors);
int precentral = -1;
for (int i = 0; i < std::ssize(regions); ++i) {
    if (regions[i].name == "precentral-lh") {
        precentral = i;
    }
}
// nibabel.freesurfer.read_annot: 36 table entries; mne.read_labels_from_annot: 34 labels, precentral-lh 9505 vertices
ok &= expect(colors.getNames().size() == 36 && regions.size() == 34 && precentral >= 0 && regions[precentral].vertices.size() == 9505,
