# FsLabel

**Namespace:** `FSLIB` &nbsp;·&nbsp; **Library:** FreeSurfer Library &nbsp;·&nbsp; **Source:** [`fs/fs_label.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fs/fs_label.h)

:::info[Python equivalent]
`mne.read_label` in MNE-Python.
:::

`#include <fs/fs_label.h>`

```cpp
class FSLIB::FsLabel
```

A FreeSurfer/[MNE](/docs/api/mne/mne-class) surface label: per-vertex indices, Tk-RAS positions and scalar values for one hemisphere.

Wraps the parsed contents of a .label file or an in-memory label constructed programmatically (e.g. by thresholding a source estimate via `FsLabelUtils::stcToLabel`). Vertex indices reference the matching [`FsSurface`](/docs/api/fs/fs-surface) for the same subject and hemisphere; positions are the Tk-surface RAS coordinates copied from that surface; values are the per-vertex scalar payload (statistic, time, weight). Hemisphere is encoded with the FreeSurfer convention \{0 = lh, 1 = rh\}.

```cpp title="src/examples/ex_fs/main.cpp"
FsLabel v1;
FsLabel::read(subjectsDir + "/sample/label/lh.V1.label", v1);
```

QList<FsLabel> regions;
QList<RowVector4i> regionColors;
aparc.toLabels(white, regions, regionColors);
int precentral = -1;
for (int i = 0; i < regions.size(); ++i) {
    if (regions[i].name == "precentral-lh") {
        precentral = i;
    }

// nibabel.freesurfer.read_annot: 36 table entries; mne.read_labels_from_annot: 34 labels, precentral-lh 9505 vertices
