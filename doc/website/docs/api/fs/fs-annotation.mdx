# FsAnnotation

**Namespace:** `FSLIB` &nbsp;·&nbsp; **Library:** FreeSurfer Library &nbsp;·&nbsp; **Source:** [`fs/fs_annotation.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fs/fs_annotation.h)

:::info[Python equivalent]
`mne.read_annot` in MNE-Python.
:::

`#include <fs/fs_annotation.h>`

```cpp
class FSLIB::FsAnnotation
```

Single-hemisphere FreeSurfer parcellation: vertex → region label plus embedded colortable.

Holds the parsed contents of one .annot file: the dense per-vertex label assignment, the explicit vertex index list it was authored against, and the [`FsColortable`](/docs/api/fs/fs-colortable) describing the colour and name of every region. Indexing is aligned with the matching [`FsSurface`](/docs/api/fs/fs-surface) for the same subject + hemisphere, so `label`[v] is the region of surface vertex `v`.

```cpp title="src/examples/ex_fs/main.cpp"
FsAnnotation aparc("sample", 0, "aparc", subjectsDir);
FsColortable& colors = aparc.getColortable();
QList<FsLabel> regions;
QList<RowVector4i> regionColors;
aparc.toLabels(white, regions, regionColors);
```

### toLabels(p_surf, p_qListLabels, p_qListLabelRGBAs, lLabelPicks)

python labels_from_parc

Converts annotation to a label list and colortable, like mne.read_labels_from_annot: one label per region with vertices, named "&lt;region&gt;-lh|rh", values 1, sorted by name.

**Parameters:**

- **p_surf** : *const [FsSurface](/docs/api/fs/fs-surface) &*
  the surface to read the vertex positions from.

- **p_qListLabels** : *QList&lt; [FsLabel](/docs/api/fs/fs-label) &gt; &*
  the converted labels are appended to a given list. Stored data are not affected.

- **p_qListLabelRGBAs** : *QList&lt; Eigen::RowVector4i &gt; &*
  the converted label RGBAs are appended to a given list. Stored data are not affected.

- **lLabelPicks** : *const QStringList &*
  the label names which should be picked.

**Returns:**

- *bool* — true if successful, false otherwise.
