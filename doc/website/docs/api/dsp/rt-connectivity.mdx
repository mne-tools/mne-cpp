# RtConnectivity

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_connectivity.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/rt/rt_connectivity.h)

`#include <dsp/rt_connectivity.h>`

<Connections topics={["real-time"]} context="api" current="RtConnectivity" />

```cpp
class mne::RtConnectivity
```

Connectivity networks of the newest trials of a stream, updated trial by trial.

The networks equal those `mne::compute_connectivity` computes from the trials in the window.

```cpp title="src/examples/ex_dsp_rt/main.cpp"
RtConnectivity rtConnectivity(settings, 5); // networks of the five newest trials
std::vector<Network> networks;
for (const MatrixXd& trial : trials) {
    networks = rtConnectivity.update(trial); // spectra of this trial only; the oldest one drops out
}
```

---

## Public Methods

### RtConnectivity(settings, trials)

**Parameters:**

- **settings** : *[ConnectivitySettings](/docs/api/connectivity/connectivity-settings)*
  Methods, sampling rate, FFT size, window type, frequency bins and node positions; trials it already holds start the window.

- **trials** : *int*
  Number of newest trials the networks are estimated from; 0 keeps every trial.

---

### update(trial)

Adds a trial, drops the oldest ones beyond the window, and estimates the networks.

A trial of another size than those in the window starts the window over.

**Parameters:**

- **trial** : *const Eigen::MatrixXd &*
  Channels by samples.

**Returns:**

- *std::vector&lt; [Network](/docs/api/connectivity/network) &gt;* — One network per method of the settings.

---

### networks()

**Returns:**

- *std::vector&lt; [Network](/docs/api/connectivity/network) &gt;* — The networks of the trials in the window, e.g. after the methods changed; none for an empty window.

---

### set_trial_count(trials)

**Parameters:**

- **trials** : *int*
  Number of newest trials the networks are estimated from; 0 keeps every trial.

---

### settings()

**Returns:**

- *[ConnectivitySettings](/docs/api/connectivity/connectivity-settings) &* — The settings with the trials of the window, to change the methods, frequency bins or window type; the kept spectra stay valid for a change of methods.

---

### reset()

Forgets every trial.

DSP real-time workers: averaging, covariance, noise spectrum, connectivity, HPI fitting and inverse operators.

````cpp title="src/examples/ex_dsp_rt/main.cpp, line 219"
RtConnectivity rtConnectivity(settings, 5); // networks of the five newest trials
std::vector<Network> networks;
for (const MatrixXd& trial : trials) {
    networks = rtConnectivity.update(trial); // spectra of this trial only; the oldest one drops out
}
ConnectivitySettings newest = settings;
newest.append(std::span(trials).last(5));
const MatrixXd offline = compute_connectivity(newest).front().connectivity_matrix();
const MatrixXd online = networks.front().connectivity_matrix();
ok &= expect(online.isApprox(offline),
             std::format("RtConnectivity equals compute_connectivity of the newest trials (coherence {:.3f})", online(0, 1)));
````
