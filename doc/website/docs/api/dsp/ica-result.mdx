# IcaResult

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library

`#include <dsp/ica.h>`

```cpp
struct UTILSLIB::IcaResult
```

Result of an [`ICA`](/docs/api/dsp/ica) decomposition.

Holds the mixing and unmixing matrices and the extracted source time series. The relationship is: sources = unmixing * (data - mean) data_recon = mixing * sources + mean
