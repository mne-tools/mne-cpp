# RtInvOp

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_inv_op.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/rt/rt_inv_op.h)

`#include <dsp/rt_inv_op.h>`

<Connections topics={["real-time"]} context="api" current="RtInvOp" />

```cpp
class mne::RtInvOp
```

Minimum-norm source estimates of streaming data with an operator that follows the noise covariance.

The estimates equal `mne::InvMinimumNorm::calculateInverse` of an operator built by [`MNEInverseOperator`](/docs/api/mne/mne-inverse-operator) with the same covariance: one row per source, for a free-orientation forward solution either the component normal to the cortex or the magnitude of the current.

```cpp title="src/examples/ex_dsp_rt/main.cpp"
RtCov rtNoise(*rawInfo, 2.0);                                           // noise covariance with a 2 s half-life
RtInvOp rtInvOp(*rawInfo, megFwd, {.method = InvEstimateMethod::dSPM}); // forward-only work happens on the first update
MatrixXd sources;
for (Index start = 0; start + 600 <= rawData.cols(); start += 600) { // 1 s blocks
    const MatrixXd block = rawData.middleCols(start, 600);
    rtNoise.update(block);
    if (const auto cov = rtNoise.covariance(); cov && rtInvOp.update(*cov)) {
        sources = rtInvOp.apply(block); // dSPM of the normal component, one row per source
    }
}
```

## Public Methods

### RtInvOp(info, forward)

Uses dSPM with the default regularization.

**Parameters:**

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info of the data; its bad channels are left out.

- **forward** : *[MNEForwardSolution](/docs/api/mne/mne-forward-solution)*
  Forward solution, e.g. MEG only via pick_types.

---

### RtInvOp(info, forward, settings)

**Parameters:**

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info of the data; its bad channels are left out.

- **forward** : *[MNEForwardSolution](/docs/api/mne/mne-forward-solution)*
  Forward solution, e.g. MEG only via pick_types.

- **settings** : *Settings*
  Inverse method and regularization.

---

### update(noiseCov)

Rebuilds the operator for a new noise covariance.

**Parameters:**

- **noiseCov** : *const [FiffCov](/docs/api/fiff/fiff-cov) &*
  Noise covariance of the data.

**Returns:**

- *bool* — False, with the previous operator kept, if the method is not supported or no channel is in the measurement info, the covariance and the forward solution.

---

### ready()

**Returns:**

- *bool* — Whether an operator was built, so that `apply()` gives estimates.

---

### apply(data, nave)

**Parameters:**

- **data** : *const Eigen::MatrixXd &*
  All channels of the measurement info by samples.

- **nave** : *int*
  Number of averages in the data; scales the dSPM and sLORETA noise normalization.

**Returns:**

- *Eigen::MatrixXd* — The source estimates, sources by samples; empty before an operator was built or if the data has another channel count.

---

### noise_covariance()

**Returns:**

- *const [FiffCov](/docs/api/fiff/fiff-cov) &* — The noise covariance of the operator's channels, projected and decomposed by `mne::FiffCov::prepare_noise_cov`; empty before an operator was built.

---

### gain()

**Returns:**

- *const Eigen::MatrixXd &* — The gain of the operator's channels, channels by source components, in the orientation of the source covariance.

---

### source_covariance()

**Returns:**

- *Eigen::VectorXd* — The diagonal of the source covariance, depth and orientation priors scaled like `mne::MNEInverseOperator::source_cov`; empty before an operator was built.
