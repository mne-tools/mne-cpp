# RtAveraging

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_averaging.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/dsp/rt/rt_averaging.h)

`#include <mne/dsp/rt_averaging.h>`

<Connections topics={["real-time"]} context="api" current="RtAveraging" />

```cpp
class mne::RtAveraging
```

Streaming stimulus-locked averaging.

An onset is a sample at which the stim channel reaches the trigger threshold from below; its value rounded to an integer is the event code. Like `mne.Epochs`, an epoch whose pre-stimulus part lies before the first sample is dropped, and an epoch exceeding a peak-to-peak limit is rejected.

Moving mean of the newest epochs of every event code, updated with each block.

```cpp title="src/examples/ex_dsp_rt/main.cpp"
// 20 samples before and 80 from each onset on stim row 2, the mean of the newest 10 epochs per event code
RtAveraging averaging(info, {.pre_stim = 20, .post_stim = 80, .trigger_channel = 2, .averages = 10});
for (const MatrixXd& block : blocks) {
    for (const int code : averaging.update(block)) {
        std::println("event {}: {} epochs averaged", code, averaging.evoked().evoked.front().nave);
    }
}
```

### RtAveraging(info, settings)

**Parameters:**

- **info** : *std::shared_ptr&lt; const [FiffInfo](/docs/api/fiff/fiff-info) &gt;*
  Measurement info of the data.

  Epoch definition, window length, baseline and rejection.

---

### update(block)

Cuts the epochs of the onsets in the block and averages those that are complete.

**Parameters:**

- **block** : *Eigen::MatrixXd*
  All channels of the measurement info by samples.

**Returns:**

- *std::vector&lt; int &gt;* — The ascending event codes whose evoked response changed.

---

### evoked()

**Returns:**

- *const [FiffEvokedSet](/docs/api/fiff/fiff-evoked-set) &* — The evoked response of every event code seen so far, its comment the event code.

---

### settings()

**Returns:**

- *const Settings &* — The current settings, with the epoch length and the averages raised to their minimum.

---

### set_settings(settings)

Applies new settings.

Another epoch definition drops all epochs; another window length, baseline or rejection keeps the averaged epochs and updates the evoked responses at once.

**Parameters:**

- **settings** : *Settings*
  The new settings.

---

### reset()

Drops all epochs and evoked responses and starts a new stream.

````cpp title="src/examples/ex_dsp_rt/main.cpp, line 137"
// 20 samples before and 80 from each onset on stim row 2, the mean of the newest 10 epochs per event code
RtAveraging averaging(info, {.pre_stim = 20, .post_stim = 80, .trigger_channel = 2, .averages = 10});
for (const MatrixXd& block : blocks) {
    for (const int code : averaging.update(block)) {
        std::println("event {}: {} epochs averaged", code, averaging.evoked().evoked.front().nave);
    }
}
// Average of k = 1..4 is 2.5 after the trigger and 0 before it; MEG0121 stays at -2
bool avgOk = averaging.evoked().evoked.size() == 1;
if (avgOk) {
    const FiffEvoked& evoked = averaging.evoked().evoked.front();
    avgOk = evoked.nave == nBlocks && evoked.data.cols() == 100 && evoked.comment == "1" && std::fabs(evoked.data(0, 30) - 2.5) < 1e-12 && std::fabs(evoked.data(0, 10)) < 1e-12 && std::fabs(evoked.data(1, 60) + 2.0) < 1e-12 && std::fabs(evoked.times(20)) < 1e-6;
}
````
