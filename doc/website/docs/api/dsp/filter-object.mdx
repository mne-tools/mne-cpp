# FilterObject

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_filter.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/rt/rt_filter.h)

```cpp
struct RTPROCESSINGLIB::FilterObject
```

Lightweight filter configuration holding kernel coefficients and overlap-add state for one channel.

---

## Example

No example of its own: Per-channel work item of the parallel overlap-add filter in filterDataBlock; built and consumed only there.

It is exercised by:

````cpp title="src/examples/ex_dsp_filter/main.cpp"
const MatrixXd filtered = filterData(data, lowPass); // zero-phase: the filter delay is removed
````
