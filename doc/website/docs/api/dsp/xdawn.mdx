# Xdawn

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library

:::info[Python equivalent]
`mne.preprocessing.Xdawn` in MNE-Python.
:::

`#include <dsp/xdawn.h>`

```cpp
class UTILSLIB::Xdawn
```

Event-related response enhancement with xDAWN spatial filtering.

```cpp title="src/examples/ex_dsp_preprocessing/main.cpp"
const XdawnResult xdawn = Xdawn::fit(epochs, 1, 1); // enhance the response to event code 1
const MatrixXd component = Xdawn::apply(epochs[0].epoch, xdawn);
```

---

## Static Methods

### fit(epochs, iTargetEvent, nComponents, dReg)

Fit xDAWN spatial filters for a target event code.

Uses non-rejected epochs only. The target signal covariance is estimated from the average of epochs whose [MNEEpochData](/docs/api/mne/mne-epoch-data)::event equals `iTargetEvent`. The noise covariance is estimated from residuals around the class-wise average for each event type.

**Parameters:**

- **epochs** : *const QVector&lt; [MNEEpochData](/docs/api/mne/mne-epoch-data) &gt; &*
  Input epochs.

- **iTargetEvent** : *int*
  Event code whose ERP/ERF should be enhanced.

- **nComponents** : *int*
  Number of xDAWN components to retain.

- **dReg** : *double*
  Relative diagonal regularisation added to the noise covariance.

**Returns:**

- *[XdawnResult](/docs/api/dsp/xdawn-result)* — [`XdawnResult`](/docs/api/dsp/xdawn-result) containing filters, patterns, and covariances.

---

### apply(matEpoch, result)

Project one epoch into xDAWN component space.

**Parameters:**

- **matEpoch** : *const Eigen::MatrixXd &*
  Epoch data (n_channels x n_samples).

- **result** : *const [XdawnResult](/docs/api/dsp/xdawn-result) &*
  Result from `fit()`.

**Returns:**

- *Eigen::MatrixXd* — Component activations (n_components x n_samples).

---

### denoise(matEpoch, result, nComponents)

Reconstruct one epoch from the first `nComponents` xDAWN components.

If `nComponents` &lt;= 0 or exceeds the fitted dimensionality, all fitted components are used.

**Parameters:**

- **matEpoch** : *const Eigen::MatrixXd &*
  Epoch data (n_channels x n_samples).

- **result** : *const [XdawnResult](/docs/api/dsp/xdawn-result) &*
  Result from `fit()`.

- **nComponents** : *int*
  Number of leading xDAWN components to keep.

**Returns:**

- *Eigen::MatrixXd* — Denoised epoch (n_channels x n_samples).

---

### denoiseEpochs(epochs, result, nComponents)

Apply `denoise()` to all epochs in the vector, preserving metadata.

**Parameters:**

- **epochs** : *const QVector&lt; [MNEEpochData](/docs/api/mne/mne-epoch-data) &gt; &*
  Input epochs.

- **result** : *const [XdawnResult](/docs/api/dsp/xdawn-result) &*
  Result from `fit()`.

- **nComponents** : *int*
  Number of leading xDAWN components to keep.

**Returns:**

- *QVector&lt; [MNEEpochData](/docs/api/mne/mne-epoch-data) &gt;* — Copy of the input epochs with denoised epoch matrices.
