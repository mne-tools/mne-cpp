# FilterIO

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/filterio.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/filterio.h)

`#include <dsp/filterio.h>`

```cpp
class mne::FilterIO
```

Reads and writes FIR filters as text: "#key value" lines (sFreq, name, type, order, HPFreq, LPFreq, CenterFreq, DesignMethod, ParksWidth) followed by one coefficient per line.

Processes txt files which hold filter coefficients.

```cpp title="src/examples/ex_dsp_filter/main.cpp"
QTemporaryDir dir;
const std::filesystem::path path = dir.filePath("lp40.txt").toStdString();
const bool written = FilterIO::write_filter(path, lowPass).has_value();
const auto reloaded = FilterIO::read_filter(path); // the taps come back bit for bit
```

---

## Static Methods

### read_filter(path)

**Parameters:**

- **path** : *const std::filesystem::path &*
  The filter file.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [FilterKernel](/docs/api/dsp/filter-kernel) &gt;* — The filter, with as many taps as the file has coefficients, or an error if the file cannot be read or holds a value that is no number.

---

### write_filter(path, filter)

Writes the coefficients with all the digits they need to be read back exactly.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The filter file to write.

- **filter** : *const [FilterKernel](/docs/api/dsp/filter-kernel) &*
  The filter.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; void &gt;* — Nothing, or an error if the file cannot be written.

QTemporaryDir dir;
const std::filesystem::path path = dir.filePath("lp40.txt").toStdString();
