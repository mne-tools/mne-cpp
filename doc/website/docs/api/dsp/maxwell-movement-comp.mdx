## Static Methods

### apply(matData, fiffInfo, headPos, dSFreq, params)

Apply movement compensation via [`SSS`](/docs/api/dsp/sss).

For each time segment (defined by headPos entries), the data is:
Projected into [`SSS`](/docs/api/dsp/sss) multipole space using the actual head position.


Reconstructed at the reference head position.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Full sensor data (n_channels × n_samples).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info (channel positions, etc.).

- **headPos** : *const std::vector&lt; [HeadPosEntry](/docs/api/dsp/head-pos-entry) &gt; &*
  Head positions over time (from cHPI).

- **dSFreq** : *double*
  Sampling frequency (Hz).

- **params** : *const [MaxwellMoveCompParams](/docs/api/dsp/maxwell-move-comp-params) &*
  Compensation parameters.

**Returns:**

- *Eigen::MatrixXd* — Movement-compensated data (n_channels × n_samples).

---

### read_head_pos(path)

Reads a MaxFilter head position file (maxfilter -headpos), like mne.chpi.read_head_pos.

After a header line, each line holds time, q1 q2 q3 (rotation quaternion without its scalar part), q4 q5 q6 (translation), goodness of fit, error and velocity; lines starting with '#' are skipped.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Path to the .pos file.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; std::vector&lt; [HeadPosEntry](/docs/api/dsp/head-pos-entry) &gt; &gt;* — The head positions, or an error if the file cannot be read or a line has another layout.

---

### write_head_pos(path, headPos)

Writes a MaxFilter head position file, like mne.chpi.write_head_pos.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Output file path.

- **headPos** : *std::span&lt; const [HeadPosEntry](/docs/api/dsp/head-pos-entry) &gt;*
  Head positions to write.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; void &gt;* — Nothing, or an error if the file cannot be written.
