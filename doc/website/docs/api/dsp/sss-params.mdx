# SSSParams

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library

`#include <dsp/sss.h>`

```cpp
struct UTILSLIB::SSSParams
```

Configuration parameters for [SSS](/docs/api/dsp/sss)/tSSS (defined outside class to work around a Clang default-argument/nested-struct limitation).

```cpp title="src/examples/ex_dsp_maxwell/main.cpp"
SSS::Params params; // internal order 8, external order 3
params.origin = Vector3d(0.0, 0.0, 0.04);
const SSS::Basis basis = SSS::computeBasis(info, params); // geometry only, reusable for every buffer
```
