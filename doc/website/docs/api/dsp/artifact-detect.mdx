# ArtifactDetect

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/artifact_detect.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/dsp/artifact_detect.h)

`#include <mne/dsp/artifact_detect.h>`

```cpp
class mne::ArtifactDetect
```

ECG and EOG physiological artifact event detection.

```cpp title="src/examples/ex_dsp_artifacts/main.cpp"
ArtifactDetect::EcgParams ecg;                                                      // mne find_ecg_events defaults: 5-35 Hz, automatic QRS threshold
ArtifactDetect::EogParams eog;                                                      // mne find_eog_events defaults: 1-10 Hz, automatic peak threshold
const std::vector<int> beats = ArtifactDetect::detectEcg(data, info, kSFreq, ecg);  // R-peak samples on the ECG channel
const std::vector<int> blinks = ArtifactDetect::detectEog(data, info, kSFreq, eog); // blink peaks on the EOG channel
```

---

## Static Methods

### detectEcg(matData, fiffInfo, dSFreq, params)

Detect ECG R-peak events as mne.preprocessing.find_ecg_events does.

Uses the first good channel with kind == FIFFV_ECG_CH; without one, the mean of the good magnetometers (or, failing those, gradiometers) stands in for it.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Raw data matrix (n_channels × n_samples), calibrated (SI units).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info (channel kinds, names).

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **params** : *const EcgParams &*
  Detection parameters.

**Returns:**

- *std::vector&lt; int &gt;* — Sample indices (0-based) of detected R-peaks.

---

### detectEog(matData, fiffInfo, dSFreq, params)

Detect EOG blink/saccade events as mne.preprocessing.find_eog_events does.

Of the good channels with kind == FIFFV_EOG_CH, the one with the most 2-45 Hz energy is used. Returns an empty vector if no EOG channel is found.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Raw data matrix (n_channels × n_samples), calibrated (SI units).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info.

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **params** : *const EogParams &*
  Detection parameters.

**Returns:**

- *std::vector&lt; int &gt;* — Sample indices (0-based) of the detected EOG peaks.

---

### computeProjEcg(matData, fiffInfo, dSFreq, proj, detect)

SSP projectors for heartbeat artifacts as mne.preprocessing.compute_proj_ecg does: ECG events, band-passed data with the info projectors applied, peak-to-peak rejection, average, then `FiffProj::compute_from_evoked`.

Returns the info projectors followed by the new ones ("ECG-...").

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Raw data (n_channels × n_samples), calibrated (SI units).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info including its projectors.

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **proj** : *const ProjParams &*
  Epoching, filtering, rejection and vector counts.

- **detect** : *const EcgParams &*
  ECG event detection parameters.

**Returns:**

- *std::vector&lt; [FiffProj](/docs/api/fiff/fiff-proj) &gt;* — The projectors, or only the info projectors if no event or epoch survives.

---

### computeProjEog(matData, fiffInfo, dSFreq, proj, detect)

SSP projectors for blink artifacts as mne.preprocessing.compute_proj_eog does (see computeProjEcg).

- **fiffInfo** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info including its projectors.

- **dSFreq** : *double*
  Sampling frequency in Hz.

- **proj** : *const ProjParams &*
  Epoching, filtering, rejection and vector counts.

- **detect** : *const EogParams &*
  EOG event detection parameters.

**Returns:**

- *std::vector&lt; [FiffProj](/docs/api/fiff/fiff-proj) &gt;* — The projectors, or only the info projectors if no event or epoch survives.

### [ex_dsp_artifacts](../../examples/dsp/ex_dsp_artifacts.mdx)

Artifact detection and repair with the dsp library on a recording with planted defects.

````cpp title="src/examples/ex_dsp_artifacts/main.cpp, line 139"
ArtifactDetect::EcgParams ecg;                                                      // mne find_ecg_events defaults: 5-35 Hz, automatic QRS threshold
ArtifactDetect::EogParams eog;                                                      // mne find_eog_events defaults: 1-10 Hz, automatic peak threshold
const std::vector<int> beats = ArtifactDetect::detectEcg(data, info, kSFreq, ecg);  // R-peak samples on the ECG channel
const std::vector<int> blinks = ArtifactDetect::detectEog(data, info, kSFreq, eog); // blink peaks on the EOG channel
ok &= expect(beats.size() == 12 && std::abs(beats[0] - 100) <= 2 && std::abs(beats[1] - beats[0] - 200) <= 2,
             std::format("ECG: {} beats, first at sample {} (12 beats every 200 samples from 100)", beats.size(), beats.empty() ? -1 : beats[0]));
ok &= expect(blinks.size() == 3 && std::abs(blinks[1] - (1100 + 25)) <= 15,
             std::format("EOG: {} blinks, second at sample {} (3 blinks around 325, 1125, 1925)", blinks.size(), blinks.size() > 1 ? blinks[1] : -1));
````
