### [ex_dsp_artifacts](../../examples/dsp/ex_dsp_artifacts.mdx)

Artifact detection and repair with the dsp library on a recording with planted defects.

````cpp title="src/examples/ex_dsp_artifacts/main.cpp, line 221"
MatrixXd loose = data;
loose.row(3).segment(250, 50).setConstant(loose(3, 250));
AnnotateAmplitudeParams amplitude;
amplitude.flat = 1e-12; // consecutive samples within 1 pV of each other
StringList flatChannels;
const FiffAnnotations flatSpans = annotateAmplitude(loose, info, kSFreq, amplitude, &flatChannels);
ok &= expect(flatSpans.size() == 1 && flatSpans[0].description == "BAD_flat" && std::abs(flatSpans[0].onset - 1.0) < 1e-12 && flatChannels == StringList{"EEG2"},
             std::format("annotateAmplitude: {} flat span(s), bad {}", flatSpans.size(), mne::join(flatChannels, ", ")));
````
