# HeadPosEntry

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/maxwell_movement_comp.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/maxwell_movement_comp.h)

`#include <dsp/maxwell_movement_comp.h>`

```cpp
struct mne::HeadPosEntry
```

A head position entry (time, translation, rotation quaternion).

```cpp title="src/examples/ex_dsp_maxwell/main.cpp"
std::vector<HeadPosEntry> headPos(1); // one position from t = 0: identity rotation, no translation
MaxwellMoveCompParams moveParams;
moveParams.origin = params.origin;
const MatrixXd compensated = MaxwellMovementComp::apply(data, info, headPos, 1.0, moveParams);

QTemporaryDir dir;
const std::filesystem::path posPath = dir.filePath("head.pos").toStdString(); // MaxFilter -headpos format
const bool posWritten = MaxwellMovementComp::write_head_pos(posPath, headPos).has_value();
const auto posBack = MaxwellMovementComp::read_head_pos(posPath);
```
