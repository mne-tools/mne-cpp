# RtNoise

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_noise.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/rt/rt_noise.h)

`#include <dsp/rt_noise.h>`

```cpp
class mne::RtNoise
```

Estimates the noise power spectral density of streaming data.

```cpp title="src/examples/ex_dsp_rt/main.cpp"
RtNoise noise(64, info200->sfreq, 10); // 64-point FFT over 10 accumulated blocks
MatrixXd spectrum;
for (int b = 0; b < 10; ++b) {
    if (auto psd = noise.estimate_spectrum(tones.middleCols(64 * b, 64))) { // dB re unit^2/Hz, channels x (fft/2 + 1)
        spectrum = std::move(*psd);
    }
}
```

---

## Public Methods

### RtNoise(fftLength, sfreq, blocks)

**Parameters:**

- **fftLength** : *int*
  Number of samples per FFT segment.

- **sfreq** : *double*
  Sampling frequency in Hz.

- **blocks** : *int*
  Number of blocks to accumulate before a spectrum is estimated (at least 1).

---

### estimate_spectrum(data)

Adds a block of data and returns the spectrum once enough blocks have arrived.

Blocks may have any number of samples; a block with another number of channels than the blocks before it starts the accumulation over.

**Parameters:**

- **data** : *const Eigen::MatrixXd &*
  A block of data, channels by samples.

**Returns:**

- *std::optional&lt; Eigen::MatrixXd &gt;* — The PSD in dB re unit^2/Hz, channels by fftLength / 2 + 1 frequencies, once the configured number of blocks has arrived, after which the next estimate starts from nothing; no value before that.
