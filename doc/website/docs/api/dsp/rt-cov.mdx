# RtCov

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/rt/rt_cov.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/rt/rt_cov.h)

Estimates the noise covariance of the MEG and EEG channels from streaming data.

```cpp title="src/examples/ex_dsp_rt/main.cpp"
RtCov rtCov(*info);
FiffCov cov;
for (int start = 0; start < covData.cols(); start += 1000) {
    if (auto estimate = rtCov.estimate_covariance(covData.middleCols(start, 1000), 4000)) { // once 4000 samples arrived
        cov = std::move(*estimate);
    }
}
```

## Public Methods

### RtCov(info)

**Parameters:**

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info of the data; its MEG and EEG channels are used.

---

### estimate_covariance(data, maxSamples)

Adds a block of data and returns the covariance once enough samples have arrived.

**Parameters:**

- **data** : *const Eigen::MatrixXd &*
  A block of data, all channels of the measurement info by samples.

- **maxSamples** : *int*
  Number of samples to accumulate before a covariance is estimated.

**Returns:**

- *std::optional&lt; [FiffCov](/docs/api/fiff/fiff-cov) &gt;* — The regularized noise covariance of the MEG and EEG channels once at least maxSamples samples have arrived, after which the next estimate starts from nothing; no value before that, or if the measurement info has no channels.

RtCov rtCov(*info);
FiffCov cov;
for (int start = 0; start < covData.cols(); start += 1000) {
    if (auto estimate = rtCov.estimate_covariance(covData.middleCols(start, 1000), 4000)) { // once 4000 samples arrived
        cov = std::move(*estimate);
    }
}
// regularize() adds 0.1 x mean MEG variance to the diagonal; the off-diagonal term is untouched
ok &= expect(cov.dim == 2 && cov.names == StringList{"MEG 0111", "MEG 0121"} && cov.nfree == 4000 && std::fabs(cov.data(0, 1) - numpyCov(0, 1)) < 1e-6 * std::fabs(numpyCov(0, 1)),
             std::format("RtCov: covariance of 4000 samples matches numpy.cov off the diagonal ({:.6g})", cov.data(0, 1)));
