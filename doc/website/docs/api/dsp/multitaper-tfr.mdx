# MultitaperTfr

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/multitaper_tfr.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/multitaper_tfr.h)

:::info[Python equivalent]
`mne.time_frequency.tfr_multitaper` in MNE-Python.
:::

`#include <dsp/multitaper_tfr.h>`

```cpp
class UTILSLIB::MultitaperTfr
```

Sliding-window multitaper time-frequency representation.

Slides a fixed-length analysis window across the data and computes a multitaper PSD at each position, yielding a time-frequency power map per channel.

```cpp title="src/examples/ex_dsp_spectral/main.cpp"
const MultitaperTfrResult tfr = MultitaperTfr::compute(signal, kSFreq, 128, 32); // 128-sample windows, 32-sample hop
```

---

## Static Methods

### compute(matData, sfreq, windowSize, stepSize, halfBandwidth, nTapers)

Compute sliding-window multitaper TFR for every channel of a data matrix.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Data matrix (n_channels × n_times).

- **sfreq** : *double*
  Sampling frequency in Hz.

- **windowSize** : *int*
  Analysis window length in samples (default 256).

- **stepSize** : *int*
  Step size in samples; -1 → windowSize / 2.

- **halfBandwidth** : *double*
  Half-bandwidth parameter (NW); default 4.0.

- **nTapers** : *int*
  Number of DPSS tapers; -1 → floor(2*halfBandwidth - 1).

**Returns:**

- *[MultitaperTfrResult](/docs/api/dsp/multitaper-tfr-result)* — [`MultitaperTfrResult`](/docs/api/dsp/multitaper-tfr-result) with tfrData, vecFreqs, vecTimes.

---

### computeArray(matData, sfreq, vecFreqs, nCycles, timeBandwidth, zeroMean)

Compute multitaper power at every sample with frequency-specific DPSS wavelets, as mne.time_frequency.tfr_array_multitaper(..., output="power") does for one epoch.

**Parameters:**

- **matData** : *const Eigen::MatrixXd &*
  Data matrix (n_channels × n_times).

- **sfreq** : *double*
  Sampling frequency in Hz.

- **vecFreqs** : *const Eigen::RowVectorXd &*
  Frequencies of interest in Hz.

- **nCycles** : *double*
  Number of cycles in each wavelet (default 7).

- **timeBandwidth** : *double*
  Time-bandwidth product; floor(timeBandwidth - 1) tapers (default 4).

- **zeroMean** : *bool*
  Make each wavelet zero mean (default true).

**Returns:**

- *[MultitaperTfrResult](/docs/api/dsp/multitaper-tfr-result)* — [`MultitaperTfrResult`](/docs/api/dsp/multitaper-tfr-result): per channel n_freqs × n_times, vecTimes = sample times.
