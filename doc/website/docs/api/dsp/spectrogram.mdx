# Spectrogram

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/spectrogram.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/dsp/spectrogram.h)

`#include <mne/dsp/spectrogram.h>`

```cpp
class mne::Spectrogram
```

Computes time-frequency spectrograms via short-time Fourier transform with configurable window and overlap.

```cpp title="src/examples/ex_dsp_spectral/main.cpp"
const MatrixXd spectrogram = Spectrogram::make_spectrogram(signal.transpose(), 64); // frequency bins x samples
```

---

## Static Methods

### make_spectrogram(signal, windowSize)

Calculates the spectrogram (tf-representation) of a given signal.

**Parameters:**

- **signal** : *Eigen::VectorXd*
  input-signal to calculate spectrogram of.

- **windowSize** : *int*
  width of the Gaussian window in samples (trades time against frequency resolution); 0 for a fifteenth of the signal.

**Returns:**

- *Eigen::MatrixXd* — Power |STFT|^2, N/2 x N for a signal of N samples: row k is the FFT bin at k * sfreq / N Hz, column j the window centred on sample j.
