# FineCalibration

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library

:::info[Python equivalent]
`mne.preprocessing.read_fine_calibration` in MNE-Python.
:::

`#include <dsp/fine_calibration.h>`

```cpp
class UTILSLIB::FineCalibration
```

Fine calibration data for [`SSS`](/docs/api/dsp/sss).

A fine calibration file (.dat) has one line per MEG sensor, as read and written by mne.preprocessing.read_fine_calibration / write_fine_calibration: channel_number position(3) x_axis(3) y_axis(3) z_axis(3) imbalance(1 or 3)

```cpp title="src/examples/ex_dsp_maxwell/main.cpp"
FineCalibration calibration;
FineCalEntry magnetometer;
magnetometer.chNumber = 111; // numbers ending in 1 are magnetometers
magnetometer.position = Vector3d(-0.1066, 0.0464, -0.0604);
magnetometer.imbalance = VectorXd::Constant(1, 0.996645); // calibration factor
calibration.addEntry(magnetometer);
const QString calPath = dir.filePath("sss_cal.dat"); // the format of mne.preprocessing.write_fine_calibration
const bool calWritten = calibration.write(calPath);
const FineCalibration calBack = FineCalibration::read(calPath);
```

### addEntry(entry)

Add an entry.

**Parameters:**

- **entry** : *const [FineCalEntry](/docs/api/dsp/fine-cal-entry) &*

---

### gainVector()

Magnetometer calibration factors.

**Returns:**

- *Eigen::VectorXd* — One factor per entry: the single calibration term of a magnetometer (channel number ending in 1), 1.0 for gradiometers.

---

### imbalanceMatrix()

Gradiometer imbalance terms.

**Returns:**

- *Eigen::MatrixXd* — Matrix (n_entries × 3): the one or three imbalance terms of each gradiometer, zero-padded; zero rows for magnetometers.

## Static Methods

### read(sPath)

Read a fine calibration file (.dat format).

Each line has 14 or 16 whitespace-separated columns (see the class description); lines starting with '#' are comments and malformed lines are skipped.

**Parameters:**

- **sPath** : *const QString &*
  Path to .dat file.

**Returns:**

- *FineCalibration* — [`FineCalibration`](/docs/api/dsp/fine-calibration) with loaded entries.
