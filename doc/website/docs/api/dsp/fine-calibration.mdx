# FineCalibration

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/fine_calibration.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/fine_calibration.h)

:::info[Python equivalent]
`mne.preprocessing.read_fine_calibration` in MNE-Python.
:::

`#include <dsp/fine_calibration.h>`

```cpp
class mne::FineCalibration
```

Fine calibration data for [`SSS`](/docs/api/dsp/sss).

A fine calibration file (.dat) has one line per MEG sensor, as read and written by mne.preprocessing.read_fine_calibration / write_fine_calibration: channel_number position(3) x_axis(3) y_axis(3) z_axis(3) imbalance(1 or 3)

```cpp title="src/examples/ex_dsp_maxwell/main.cpp"
FineCalibration calibration;
FineCalEntry magnetometer;
magnetometer.chNumber = 111; // numbers ending in 1 are magnetometers
magnetometer.position = Vector3d(-0.1066, 0.0464, -0.0604);
magnetometer.imbalance = VectorXd::Constant(1, 0.996645); // calibration factor
calibration.push_back(magnetometer);
const std::filesystem::path calPath = dir.filePath("sss_cal.dat").toStdString(); // MaxFilter's format
const bool calWritten = calibration.write(calPath).has_value();
const auto calBack = FineCalibration::read(calPath);
```

## Static Methods

### read(path)

Read a fine calibration file (.dat format).

Each line has 14 or 16 whitespace-separated columns (see the class description); lines starting with '#' are comments. Channel names "MEG0113" are read as channel number 113.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Path to the .dat file.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; FineCalibration &gt;* — The calibration, or an error if the file cannot be read or a line has another number of columns.

DSP Maxwell filtering: SSS, bad-channel detection, movement compensation, fine calibration and cHPI removal.

````cpp title="src/examples/ex_dsp_maxwell/main.cpp, line 176"
FineCalibration calibration;
FineCalEntry magnetometer;
magnetometer.chNumber = 111; // numbers ending in 1 are magnetometers
magnetometer.position = Vector3d(-0.1066, 0.0464, -0.0604);
magnetometer.imbalance = VectorXd::Constant(1, 0.996645); // calibration factor
calibration.push_back(magnetometer);
const std::filesystem::path calPath = dir.filePath("sss_cal.dat").toStdString(); // MaxFilter's format
const bool calWritten = calibration.write(calPath).has_value();
const auto calBack = FineCalibration::read(calPath);
ok &= expect(calWritten && calBack && calBack->size() == 1 && calBack->gain_vector()(0) == 0.996645 && calBack->find(111)->position.isApprox(magnetometer.position),
             "FineCalibration round-trips a magnetometer line");
````
