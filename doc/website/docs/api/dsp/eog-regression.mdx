# EogRegression

**Namespace:** `RTPROCESSINGLIB` &nbsp;·&nbsp; **Library:** DSP Library

:::info[Python equivalent]
`mne.preprocessing.regress_artifact` in MNE-Python.
:::

`#include <dsp/eog_regression.h>`

```cpp
class UTILSLIB::EogRegression
```

Remove EOG artifacts via linear regression.

As mne.preprocessing.EOGRegression: fits data_ch = beta * EOG + residual on time-demeaned signals for every good data channel and subtracts beta times the demeaned EOG.

```cpp title="src/examples/ex_dsp_artifacts/main.cpp"
MatrixXd cleaned = data;
EogRegression regression;
regression.fit(cleaned, info); // EOG channels are found by kind
regression.apply(cleaned, info);
```

---

## Public Methods

### EogRegression()

Constructs a default [`EogRegression`](/docs/api/dsp/eog-regression) object.

---

### fit(data, info, eogChannels)

Fit regression coefficients from EOG to all other channels.

Ordinary least squares on demeaned signals: beta = T * E^T * (E * E^T)^\{-1\}, T being the good data channels ([FiffInfoBase](/docs/api/fiff/fiff-info-base)::pick_data_channels without the bads).

**Parameters:**

- **data** : *const Eigen::MatrixXd &*
  Data matrix (n_channels x n_times).

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info (identifies EOG channels by kind == FIFFV_EOG_CH).

- **eogChannels** : *const QStringList &*
  Optional explicit EOG channel names. If empty, the good channels of kind FIFFV_EOG_CH.

---

### apply(data, info)

Apply the fitted regression to remove EOG artifacts in-place.

Subtracts beta times the demeaned EOG from the channels `fit()` regressed. `fit()` must be called first.

**Parameters:**

- **data** : *Eigen::MatrixXd &*
  Data matrix (n_channels x n_times). Modified in-place.

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info.

---

### coefficients()

Returns the fitted regression coefficients.

**Returns:**

- *const Eigen::MatrixXd &* — Matrix (n_non_eog_channels x n_eog_channels).

---

### isFitted()

Returns true if `fit()` has been called successfully.

**Returns:**

- *bool* — True if regression coefficients are available, false otherwise.
