# SpectrumView

**Namespace:** `DISPLIB` &nbsp;·&nbsp; **Library:** Display Library

`#include <disp/spectrumview.h>`

```cpp
class DISPLIB::SpectrumView
```

Per-channel frequency-spectrum heat-map QTableView (rows = channels, columns = freq bins).

Wraps a `QTableView` around a [`FrequencySpectrumModel`](/docs/api/disp/frequency-spectrum-model) and paints each row with [`FrequencySpectrumDelegate`](/docs/api/disp/frequency-spectrum-delegate) so the live FFT amplitudes appear as a rolling colour band per channel.
