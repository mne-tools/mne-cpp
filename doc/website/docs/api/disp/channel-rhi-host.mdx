# ChannelRhiHost

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp/viewers/helpers/channelrhirenderer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp/viewers/helpers/channelrhirenderer.h)

`#include <mne/disp/channelrhirenderer.h>`

```cpp
class mne::disp::ChannelRhiHost
```

Services a host surface provides to a [`ChannelRhiRenderer`](/docs/api/disp/channel-rhi-renderer).

Implemented by the widget host [`ChannelRhiView`](/docs/api/disp/channel-rhi-view) and the window host [`ChannelWindow`](/docs/api/disp/channel-window).
