# MNEOperator

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp/viewers/helpers/mneoperator.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp/viewers/helpers/mneoperator.h)

`#include <mne/disp/mneoperator.h>`

```cpp
class mne::disp::MNEOperator
```

Light-weight wrapper describing one MNE pre-processing operator (FIR / SSP / compensation).

Stores the operator type, display name, active flag and the underlying matrix / kernel reference so [`ChannelInfoModel`](/docs/api/disp/channel-info-model) can track which operators a channel is currently subject to.
