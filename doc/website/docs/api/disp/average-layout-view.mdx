# AverageLayoutView

**Namespace:** `DISPLIB` &nbsp;·&nbsp; **Library:** Display Library

`#include <disp/averagelayoutview.h>`

```cpp
class DISPLIB::AverageLayoutView
```

Sensor-layout viewer drawing per-channel evoked traces at their physical 2-D positions.

Wraps a `QGraphicsView` around an [`AverageScene`](/docs/api/disp/average-scene) fed by an [`EvokedSetModel`](/docs/api/disp/evoked-set-model) and a [`ChannelInfoModel`](/docs/api/disp/channel-info-model); selection groups are pushed in as [`SelectionItem`](/docs/api/disp/selection-item) to show only a subset of channels.
