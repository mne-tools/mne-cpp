# AverageLayoutView

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp_widgets/viewers/averagelayoutview.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp_widgets/viewers/averagelayoutview.h)

`#include <mne/disp/averagelayoutview.h>`

```cpp
class mne::disp::AverageLayoutView
```

Sensor-layout viewer drawing per-channel evoked traces at their physical 2-D positions.

Wraps an [`AverageLayoutWidget`](/docs/api/disp/average-layout-widget) fed by an [`EvokedSetModel`](/docs/api/disp/evoked-set-model) and a [`ChannelInfoModel`](/docs/api/disp/channel-info-model); selection groups are pushed in as [`SelectionItem`](/docs/api/disp/selection-item) to show only a subset of channels.
