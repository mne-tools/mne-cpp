# ScalingView

**Namespace:** `DISPLIB` &nbsp;·&nbsp; **Library:** Display Library

`#include <disp/scalingview.h>`

```cpp
class DISPLIB::ScalingView
```

Per-modality y-scale spinbox panel built from [`ScaleControl`](/docs/api/disp/scale-control) widgets.

One [`ScaleControl`](/docs/api/disp/scale-control) per channel modality in the active `FiffInfo`; edits are emitted as `scalingChanged` maps consumed by [`RtFiffRawView`](/docs/api/disp/rt-fiff-raw-view), [`ChannelDataView`](/docs/api/disp/channel-data-view) and [`ButterflyView`](/docs/api/disp/butterfly-view).
