# SceneViewport

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp_widgets/viewers/helpers/sceneviewport.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp_widgets/viewers/helpers/sceneviewport.h)

`#include <mne/disp/sceneviewport.h>`

```cpp
class mne::disp::SceneViewport
```

Base of the widgets that show a scene model, such as a sensor layout, with zoom, pan and rubber band.

Subclasses report the area of their contents in `sceneBounds()`, draw them in `drawScene()` and react to clicks and bands in `scenePressed()` and `sceneBandSelected()`.
