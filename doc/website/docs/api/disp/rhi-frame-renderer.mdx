# RhiFrameRenderer

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp/plots/helpers/rhiframerenderer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp/plots/helpers/rhiframerenderer.h)

`#include <mne/disp/rhiframerenderer.h>`

```cpp
class mne::disp::RhiFrameRenderer
```

Executes [`GpuFrame`](/docs/api/scene/gpu-frame) descriptions with QRhi.

Use one renderer per QRhi and resource store; call `releaseResources()` before the QRhi goes away.

### render(rhi, target, cb, frame, resources)

Uploads what changed and records the frame into `cb`.

Passes after the first that clear no colour continue the previous QRhi pass; their depth is not cleared then.

**Parameters:**

- **rhi** : *QRhi **
  The QRhi.

- **target** : *QRhiRenderTarget **
  Render target.

- **cb** : *QRhiCommandBuffer **
  Command buffer of the current frame.

- **frame** : *const [GpuFrame](/docs/api/scene/gpu-frame) &*
  Passes and draws.

- **resources** : *const [GpuResources](/docs/api/scene/gpu-resources) &*
  Buffers, textures and pipelines the frame refers to.

---

### checkShaders(frame, resources)

Compares the draws of a frame with the reflection of their shaders: every uniform block a draw sets has a block of the same size at its binding, every texture a sampler, and every vertex attribute of the pipeline an input of the same location and number of components; every block, sampler and input of a shader is set.

**Parameters:**

- **frame** : *const [GpuFrame](/docs/api/scene/gpu-frame) &*
  Passes and draws.

- **resources** : *const [GpuResources](/docs/api/scene/gpu-resources) &*
  Pipelines the frame refers to.

**Returns:**

- *std::vector&lt; std::string &gt;* — The mismatches, empty if the frame fits its shaders.
