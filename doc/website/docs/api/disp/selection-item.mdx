# SelectionItem

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp/viewers/helpers/selectionsceneitem.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/disp/viewers/helpers/selectionsceneitem.h)

`#include <disp/selectionsceneitem.h>`

```cpp
class mne::disp::SelectionItem
```

Value type describing one named selection group (label + list of channel names).

Loaded from / saved to MNE .sel files; consumed by [`AverageScene`](/docs/api/disp/average-scene) and [`ChannelSelectionView`](/docs/api/disp/channel-selection-view) to limit display to a subset of sensors.
