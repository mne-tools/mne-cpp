# SelectionItem

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** Display Library &nbsp;·&nbsp; **Source:** [`disp/viewers/helpers/selectionitem.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp/viewers/helpers/selectionitem.h)

`#include <mne/disp/selectionitem.h>`

```cpp
class mne::disp::SelectionItem
```

The channels picked in a sensor layout: names, numbers, kinds, units and layout positions, one entry per channel in each vector.

[`ChannelSelectionView`](/docs/api/disp/channel-selection-view) emits it when the selection changes; [`AverageLayoutView`](/docs/api/disp/average-layout-view) and the analysis plugins show only these channels.
