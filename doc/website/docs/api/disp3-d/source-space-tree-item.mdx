# SourceSpaceTreeItem

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/sourcespacetreeitem.h>`

```cpp
class DISP3DLIB::SourceSpaceTreeItem
```

[`SourceSpaceTreeItem`](/docs/api/disp3-d/source-space-tree-item) represents a single source space point in the tree model.

Each item stores its 3D position and rendering scale.

Source space point tree item.

## Public Methods

### SourceSpaceTreeItem(text, positions, color, scale, type)

Constructs a [`SourceSpaceTreeItem`](/docs/api/disp3-d/source-space-tree-item) for a hemisphere.

**Parameters:**

- **text** : *const QString &*
  Display text for the item (e.g. "LH", "RH").

- **positions** : *const QVector&lt; QVector3D &gt; &*
  3D positions of all source points in this hemisphere (in meters).

- **color** : *const QColor &*
  Color for rendering.

- **scale** : *float*
  Radius/size of each rendered sphere.

- **type** : *int*
  Item type identifier.
