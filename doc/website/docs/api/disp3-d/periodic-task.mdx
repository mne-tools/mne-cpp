# PeriodicTask

**Namespace:** `mne::disp` &nbsp;·&nbsp; **Library:** 3D Display Library &nbsp;·&nbsp; **Source:** [`disp3D/workers/periodictask.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/disp3D/workers/periodictask.h)

`#include <mne/disp3D/periodictask.h>`

```cpp
class mne::disp::PeriodicTask
```

Calls a tick function every `interval` while running.

The first tick fires one interval after start(). Ticks never overlap and do not queue up: a tick that overruns pushes the next one back. stop() does not interrupt a tick that is already running.
