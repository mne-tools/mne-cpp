# RenderKey

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library &nbsp;·&nbsp; **Source:** [`disp3D/core/rendertypes.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/disp3D/core/rendertypes.h)

`#include <disp3D/rendertypes.h>`

```cpp
class DISP3DLIB::RenderKey
```

Identity of a renderable in the renderer's GPU resource cache.

The renderer drops the GPU copies of a renderable once its key is destroyed. A copied renderable gets a key of its own, so it never shares GPU buffers with the original.
