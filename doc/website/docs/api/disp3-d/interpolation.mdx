# Interpolation

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/interpolation.h>`

```cpp
class DISP3DLIB::Interpolation
```

This class holds methods for creating distance-based weight matrices and for interpolating signals.

This class holds methods for creating distance-based weight matrices and for interpolating signals

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
QSharedPointer<SparseMatrix<float>> weights = Interpolation::createInterpolationMat(projected, distances, Interpolation::linear); // inverse-distance weights
const VectorXf atVertices = Interpolation::interpolateSignal(*weights, Vector2f(1.0f, 4.0f));                                     // one value per sensor
```

## Static Methods

### createInterpolationMat(vecProjectedSensors, matDistanceTable, interpolationFunction, dCancelDist, vecExcludeIndex)

createInterpolationMat Calculates the weight matrix for interpolation.

**Parameters:**

- **vecProjectedSensors** : *const Eigen::VectorXi &*
  Mesh vertex index of each sensor (one column per sensor).

- **matDistanceTable** : *const QSharedPointer&lt;Eigen::MatrixXd&gt;*
  Distance table (nVertices x nSensors), e.g. from `GeometryInfo::scdc`.

- **interpolationFunction** : *double(*)(double)*
  Distance function whose inverse magnitude gives the weight.

- **dCancelDist** : *const double*
  Distances at or above this value get zero weight.

- **vecExcludeIndex** : *const Eigen::VectorXi &*
  Sensor column indices that are not pinned to their own vertex.

**Returns:**

- *QSharedPointer&lt; Eigen::SparseMatrix&lt; float &gt; &gt;* — Row-normalised sparse weight matrix (nVertices x nSensors), or an empty matrix if the table is empty.

### interpolateSignal(matInterpolationMatrix, vecMeasurementData)

interpolateSignal Interpolates sensor data using the weight matrix (shared pointer version).

**Parameters:**

- **matInterpolationMatrix** : *const QSharedPointer&lt; Eigen::SparseMatrix&lt; float &gt; &gt;*
  Weight matrix (nVertices x nSensors).

- **vecMeasurementData** : *const QSharedPointer&lt;Eigen::VectorXf&gt; &*
  Sensor values (nSensors).

**Returns:**

- *Eigen::VectorXf* — Interpolated vertex values, or an empty vector on dimension mismatch.

---

### interpolateSignal(matInterpolationMatrix, vecMeasurementData)

interpolateSignal Interpolates sensor data using the weight matrix (reference version).

**Parameters:**

- **matInterpolationMatrix** : *const Eigen::SparseMatrix&lt; float &gt; &*
  Weight matrix (nVertices x nSensors).

- **vecMeasurementData** : *const Eigen::VectorXf &*
  Sensor values (nSensors).

**Returns:**

- *Eigen::VectorXf* — Interpolated vertex values, or an empty vector on dimension mismatch.

---

### linear(dIn)

linear Identity interpolation function.

**Parameters:**

- **dIn** : *const double*
  Input distance.

**Returns:**

- *double* — dIn unchanged.

---

### gaussian(dIn)

gaussian Gaussian interpolation function (sigma=1).

**Parameters:**

- **dIn** : *const double*
  Input distance.

**Returns:**

- *double* — exp(-dIn^2 / 2).

---

### square(dIn)

square Negative parabola interpolation function with y-offset of 1.

**Parameters:**

- **dIn** : *const double*
  Input distance.

**Returns:**

- *double* — max(1 - dIn^2 / 9, 0).

---

### cubic(dIn)

cubic Cubic hyperbola interpolation function.

**Parameters:**

- **dIn** : *const double*
  Input distance.

**Returns:**

- *double* — dIn^3.
