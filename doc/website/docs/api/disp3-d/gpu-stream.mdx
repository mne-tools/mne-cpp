# GpuStream

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/rendertypes.h>`

```cpp
struct DISP3DLIB::GpuStream
```

CPU-side contents of one GPU buffer of a renderable.

Renderables own only CPU data; the renderer keeps the GPU copies and uploads a stream again when its generation changes. The data must stay valid until the next change of the renderable.
