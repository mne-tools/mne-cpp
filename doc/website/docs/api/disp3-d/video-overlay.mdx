# VideoOverlay

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/videooverlay.h>`

```cpp
class DISP3DLIB::VideoOverlay
```

Camera-facing textured quad rendered at a focus point in the 3-D scene.

The overlay displays any live RGB/video frame "as a small cut-out view" on top of the 3-D scene. It is a billboarded square positioned at `focusPosition` with side length `sizeMeters`, textured with the latest video frame.

This class is a passive data holder: [`BrainRenderer`](/docs/api/disp3-d/brain-renderer) owns the GPU resources (vertex buffer, texture, sampler, pipeline) and reads from here each frame.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
VideoOverlay overlay; // CPU-side state; the renderer uploads frame() when frameGeneration() changes
overlay.setEnabled(true);
overlay.setFocusPosition(QVector3D(0.0f, 0.0f, 0.08f));
overlay.setSizeMeters(0.05f);
QImage frame(64, 48, QImage::Format_RGB32);
frame.fill(Qt::darkGreen);
overlay.setFrame(frame);
overlay.setFrame(QImage()); // null frames are ignored
```
