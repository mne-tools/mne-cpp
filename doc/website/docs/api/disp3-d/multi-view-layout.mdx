# MultiViewLayout

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/multiviewlayout.h>`

```cpp
class DISP3DLIB::MultiViewLayout
```

Pure-geometry class for multi-view viewport layout.

This class has no widget dependencies — it works with sizes, rectangles, and fractional split positions. The hosting widget queries this class for rectangles and hit-test results, and updates separator widgets accordingly.

Layout rules:
1 pane → full area


2 panes → side-by-side, split at m_splitX


3 panes → full-width top row + 2 bottom panes split at m_splitX


4 panes → 2×2 grid split at (m_splitX, m_splitY)

Multi-view geometry computations.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
MultiViewLayout layout;
layout.setSplitX(0.25f);
const QSize canvas(800, 600);
const QRect left = layout.slotRect(0, 2, canvas);
const QRect bottomRight = layout.slotRect(2, 3, canvas);
const SplitterHit onBar = layout.hitTestSplitter(QPoint(200, 300), 2, canvas);
```

### slotRect(slot, numEnabled, outputSize)

Compute the pixel rectangle for a layout slot.

**Parameters:**

- **slot** : *int*
  Slot index (0-based among enabled viewports).

- **numEnabled** : *int*
  Total number of enabled panes (1–4).

- **outputSize** : *const QSize &*
  Total output pixel size.

**Returns:**

- *QRect* — Pixel rectangle for the slot.

### hitTestSplitter(pos, numEnabled, outputSize)

Hit-test the splitter bars.

**Parameters:**

- **pos** : *const QPoint &*
  Cursor position (widget coords).

- **numEnabled** : *int*
  Total number of enabled panes.

- **outputSize** : *const QSize &*
  Total output pixel size.

**Returns:**

- *SplitterHit* — Which splitter(s) are under the cursor.

### viewportIndexAt(pos, enabledViewports, outputSize)

Given a cursor position and output size, determine which viewport index the cursor is in.

**Parameters:**

- **pos** : *const QPoint &*
  Cursor position (widget coords).

- **enabledViewports** : *const QVector&lt; int &gt; &*
  Ordered list of enabled viewport indices.

- **outputSize** : *const QSize &*
  Total output pixel size.

**Returns:**

- *int* — Viewport index, or -1 if outside.

### insetForSeparator(paneRect, slot, numEnabled)

Apply a separator-pixel inset to a pane rect so adjacent panes don't overlap the separator bar.

This is used in the render loop to trim viewports.

**Parameters:**

- **paneRect** : *const QRect &*
  Original pane rectangle.

- **slot** : *int*
  Slot index (0-based).

- **numEnabled** : *int*
  Total enabled count.

**Returns:**

- *QRect* — Inset rectangle.
