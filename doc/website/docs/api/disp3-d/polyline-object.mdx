# PolylineObject

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/polylineobject.h>`

```cpp
class DISP3DLIB::PolylineObject
```

Renders an ordered sequence of points as connected line segments.

Each segment is one instance of a unit cylinder, using the same instance layout as [`DipoleObject`](/docs/api/disp3-d/dipole-object) and [`NetworkObject`](/docs/api/disp3-d/network-object) so the existing Dipole pipeline can draw it without a dedicated shader.

Connected line segments through an ordered list of points.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// Head-position track: N points draw N - 1 tube segments; repeated positions are skipped
PolylineObject track;
track.setPoints({Vector3f(0.0f, 0.0f, 0.0f), Vector3f(0.0f, 0.0f, 0.0f), Vector3f(0.001f, 0.0f, 0.0f), Vector3f(0.002f, 0.001f, 0.0f)});
track.setRadius(0.0005f);
track.setGradient(Qt::blue, Qt::red); // oldest to newest
```

## Public Methods

### PolylineObject()

Constructs a [`PolylineObject`](/docs/api/disp3-d/polyline-object) without any points.

---

### ~PolylineObject()

Destroys the [`PolylineObject`](/docs/api/disp3-d/polyline-object).

---

### setPoints(vecPoints)

Sets the points of the polyline.

Fewer than two points clears the object, since a single point has no segment to draw.

**Parameters:**

- **vecPoints** : *const QVector&lt; Eigen::Vector3f &gt; &*
  Points in scene coordinates, in order.

---

### clear()

Clears all points.

---

### setRadius(fRadius)

Sets the radius of the drawn segments.

**Parameters:**

- **fRadius** : *float*
  Segment radius in scene units.

---

### setGradient(startColor, endColor)

Sets the colours the segments are graded between from start to end.

Grading the line makes the direction of travel readable without any extra decoration.

**Parameters:**

- **startColor** : *const QColor &*
  Colour of the first segment.

- **endColor** : *const QColor &*
  Colour of the last segment.

---
