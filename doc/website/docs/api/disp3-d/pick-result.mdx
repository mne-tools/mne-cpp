# PickResult

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/pickresult.h>`

```cpp
struct DISP3DLIB::PickResult
```

Uniform payload for object-id picking across the multimodal scene.

Producers fill in only the fields relevant to their ``kind``. Consumers (Pick dock, status bar, MRI ortho viewer, time-course panel) read the generic fields (``kind``, ``world``, ``objectId``, ``label``, ``value``) plus any kind-specific fields they understand.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// A picker reports the contact under the cursor; the host reads the most recent pick back
const bool hitBefore = isHit(scene.lastPick());
PickResult contactPick;
contactPick.kind = PickKind::ElectrodeContact;
contactPick.sourceId = "seeg_LH";
const IeegContact& first = electrodes.implantation().contacts().first();
contactPick.world = QVector3D(first.position.x(), first.position.y(), first.position.z());
contactPick.label = first.name;
contactPick.value = 3.5f;
contactPick.timeSample = 120;
scene.reportPick(contactPick);
const PickResult& lastPick = scene.lastPick();
```
