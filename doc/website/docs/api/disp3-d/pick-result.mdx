# PickResult

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/raypicker.h>`

```cpp
struct PickResult
```

Result of a ray–mesh intersection test containing the hit point, triangle index, and distance.

Describes the result of a ray-pick operation.
