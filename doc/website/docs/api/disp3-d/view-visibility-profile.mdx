# ViewVisibilityProfile

**Namespace:** `DISP3DLIB` &nbsp;·&nbsp; **Library:** 3D Display Library

`#include <disp3D/viewstate.h>`

```cpp
struct DISP3DLIB::ViewVisibilityProfile
```

Per-view toggle flags controlling which data layers (brain, sensors, sources, network) are visible.

Per-object visibility flags for a single viewport.

Every viewport (single-view or multi-view pane) carries an independent visibility profile so that each pane can show a different combination of objects.
