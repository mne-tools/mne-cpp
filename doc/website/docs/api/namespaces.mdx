# Namespace List

All public namespaces in the MNE-CPP library tree.

| Namespace | Classes | Description |
|-----------|---------|-------------|
| [`BIDSLIB`](/docs/api/bids/) | 14 | BIDS dataset reading, writing, path construction, and sidecar metadata handling for iEEG/EEG/MEG. |
| [`COMLIB`](/docs/api/com/) | 8 | Real-time client/server communication primitives for talking to `mne_rt_server`. |
| [`CONNECTIVITYLIB`](/docs/api/connectivity/) | 21 | Functional connectivity metrics (coherence, PLV, cross-correlation, etc.). |
| [`DECODINGLIB`](/docs/api/decoding/) | 5 | Supervised and unsupervised spatial-filter decompositions for M/EEG decoding. |
| [`DISP3DLIB`](/docs/api/disp3-d/) | 48 | 3-D brain visualisation using the Qt RHI rendering backend. |
| [`DISPLIB`](/docs/api/disp/) | 69 | 2-D display widgets and visualisation helpers (charts, topography, colour maps). |
| `DSPLIB` | 0 | Digital signal processing (filtering, spectrograms, real-time averaging, HPI, noise reduction). |
| [`FIFFLIB`](/docs/api/fiff/) | 37 | FIFF file I/O, in-memory data structures and high-level readers/writers. |
| [`FSLIB`](/docs/api/fs/) | 8 | FreeSurfer surface, annotation and parcellation I/O for mne-cpp. |
| [`FWDLIB`](/docs/api/fwd/) | 14 | Forward modelling — BEM solver, spherical models, sensor/coil definitions and the lead-field assembly that links current dipoles to MEG/EEG sensor readings. |
| [`INVLIB`](/docs/api/inv/) | 54 | Inverse source estimation (MNE, dSPM, sLORETA, dipole fitting). |
| [`LSLLIB`](/docs/api/lsl/) | 3 | Lab Streaming Layer (LSL) integration for real-time data exchange. |
| [`MATHLIB`](/docs/api/math/) | 0 | Mathematical algorithms and geometry (linear algebra, optimization, spectral estimation). |
| [`MLLIB`](/docs/api/ml/) | 4 | Tensors, model abstraction, ONNX Runtime inference and Python training drivers used across mne-cpp. |
| [`MNALIB`](/docs/api/mna/) | 22 | MNE Analysis Container Format (mna/mnx). |
| [`MNELIB`](/docs/api/mne/) | 65 | Core [`MNE`](/docs/api/mne/mne-class) data structures (source spaces, source estimates, hemispheres). |
| [`MRILIB`](/docs/api/mri/) | 8 | Volume I/O, voxel geometry and slice resampling for structural MRI data inside mne-cpp. |
| [`RTPROCESSINGLIB`](/docs/api/dsp/) | 15 |  |
| [`STSLIB`](/docs/api/sts/) | 10 | Statistical testing (t-tests, F-tests, cluster permutation, multiple comparison correction). |
| `SURFACEKEYS` | 0 | Centralised string constants for surface map keys. |
| [`UTILSLIB`](/docs/api/utils/) | 92 | Shared utilities (I/O helpers, spectral analysis, layout management, warp algorithms). |
| `Ui` | 0 |  |
