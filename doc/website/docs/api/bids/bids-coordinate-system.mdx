# BidsCoordinateSystem

**Namespace:** `BIDSLIB` &nbsp;·&nbsp; **Library:** BIDS Library

`#include <bids/bids_coordinate_system.h>`

```cpp
struct BIDSLIB::BidsCoordinateSystem
```

Coordinate system metadata from *_coordsystem.json.

Describes the spatial reference frame used for electrode positions.

---

## Public Methods

### toFiffCoordTrans(fromFrame, toFrame)

Convert parsed transform to a [FiffCoordTrans](/docs/api/fiff/fiff-coord-trans).

**Parameters:**

- **fromFrame** : *int*
  Source coordinate frame (default FIFFV_COORD_MRI = 5).

- **toFrame** : *int*
  Destination coordinate frame (default FIFFV_COORD_HEAD = 4).

**Returns:**

- *[FiffCoordTrans](/docs/api/fiff/fiff-coord-trans)* — FiffCoordTrans populated with the parsed 4x4 matrix.

**Returns:**

- *[BidsCoordinateSystem](/docs/api/bids/bids-coordinate-system)* — Populated coordinate system, or default if file cannot be read.
