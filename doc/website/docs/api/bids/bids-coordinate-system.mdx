# BidsCoordinateSystem

**Namespace:** `BIDSLIB` &nbsp;·&nbsp; **Library:** BIDS Library &nbsp;·&nbsp; **Source:** [`bids/bids_coordinate_system.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/bids/bids_coordinate_system.h)

`#include <bids/bids_coordinate_system.h>`

```cpp
struct BIDSLIB::BidsCoordinateSystem
```

Coordinate system metadata from *_coordsystem.json.

Describes the spatial reference frame used for electrode positions.

```cpp title="src/examples/ex_bids/main.cpp"
const BidsDatasetDescription description = BidsDatasetDescription::read(root + "/dataset_description.json");
const QList<BidsChannel> channels = BidsChannel::readTsv(channelsTsv);               // one row per channel
const QList<BidsEvent> events = BidsEvent::readTsv(ieeg.eventsTsvPath().filePath()); // onset, duration, sample, value, trial_type
const QList<BidsElectrode> electrodes = BidsElectrode::readTsv(ieeg.electrodesTsvPath().filePath());
const BidsCoordinateSystem coords = BidsCoordinateSystem::readJson(ieeg.coordsystemJsonPath().filePath());
```

## Public Methods

### toFiffCoordTrans(fromFrame, toFrame)

Convert parsed transform to a [FiffCoordTrans](/docs/api/fiff/fiff-coord-trans).

**Parameters:**

- **fromFrame** : *int*
  Source coordinate frame (default FIFFV_COORD_MRI = 5).

- **toFrame** : *int*
  Destination coordinate frame (default FIFFV_COORD_HEAD = 4).

**Returns:**

- *[FiffCoordTrans](/docs/api/fiff/fiff-coord-trans)* — FiffCoordTrans populated with the parsed 4x4 matrix.

---

## Static Methods

### readJson(sFilePath)

Read a BIDS *_coordsystem.json file.

**Parameters:**

- **sFilePath** : *const QString &*
  Path to the coordsystem.json file.

**Returns:**

- *[BidsCoordinateSystem](/docs/api/bids/bids-coordinate-system)* — Populated coordinate system, or default if file cannot be read.

---

### writeJson(sFilePath, cs)

Write a BIDS *_coordsystem.json file.

**Parameters:**

- **sFilePath** : *const QString &*
  Output path.

- **cs** : *const [BidsCoordinateSystem](/docs/api/bids/bids-coordinate-system) &*
  Coordinate system metadata.

**Returns:**

- *bool* — true on success.
