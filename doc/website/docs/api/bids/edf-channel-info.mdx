# EDFChannelInfo

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** BIDS Library &nbsp;·&nbsp; **Source:** [`bids/readers/bids_edf_reader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/bids/readers/bids_edf_reader.h)

struct mne::EDFChannelInfo

const std::vector<EDFChannelInfo>& edfChannels = static_cast<EDFReader*>(edf.get())->measurement_channel_infos(); // header fields per signal

## Public Methods

### to_fiff_ch_info()

**Returns:**

- *[FiffChInfo](/docs/api/fiff/fiff-ch-info)* — The FIFF channel description: kind from the label, volts for voltage dimensions.

---

### to_si()

**Returns:**

- *float* — Factor from the physical dimension to SI (µV/uV 1e-6, mV 1e-3, otherwise 1; 1 for a "Status"/"Trigger" stim channel), as in mne read_raw_edf.
