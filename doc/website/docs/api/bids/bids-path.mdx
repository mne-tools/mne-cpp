# BIDSPath

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** BIDS Library &nbsp;·&nbsp; **Source:** [`bids/bids_path.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/bids/bids_path.h)

:::info[Python equivalent]
`mne_bids.BIDSPath` in MNE-Python.
:::

`#include <mne/bids/bids_path.h>`

```cpp
class mne::BIDSPath
```

Manages BIDS-compliant file paths.

A [`BIDSPath`](/docs/api/bids/bids-path) encodes the BIDS entities (subject, session, task, acquisition, run, etc.) together with a datatype, suffix, extension, and root directory to produce fully qualified file paths that conform to the BIDS specification.

BIDS-compliant path and filename construction.

```cpp title="src/examples/ex_bids/main.cpp"
BIDSPath ieeg(root, "01", "01", "rest", "ieeg", "ieeg", ".vhdr");               // root, sub, ses, task, datatype, suffix, ext
const std::filesystem::path vhdr = ieeg.file_path();                            // <root>/sub-01/ses-01/ieeg/sub-01_ses-01_task-rest_ieeg.vhdr
const std::filesystem::path channelsTsv = ieeg.channels_tsv_path().file_path(); // sibling sidecars share the entities
```

### BIDSPath(sRoot, sSubject, sSession, sTask, sDatatype, sSuffix, sExtension)

Constructs a [`BIDSPath`](/docs/api/bids/bids-path) with the most common entities.

**Parameters:**

- **sRoot** : *std::filesystem::path*
  Root directory of the BIDS dataset.

- **sSubject** : *std::string*
  Subject label (without "sub-" prefix).

- **sSession** : *std::string*
  Session label (without "ses-" prefix). Can be empty.

- **sTask** : *std::string*
  Task label. Can be empty.

- **sDatatype** : *std::string*
  BIDS datatype (e.g. "ieeg", "eeg", "meg", "anat").

- **sSuffix** : *std::string*
  Filename suffix (e.g. "ieeg", "channels", "electrodes").

- **sExtension** : *std::string*
  File extension including dot (e.g. ".vhdr", ".tsv", ".json").

### basename()

Constructs the BIDS-compliant filename (without directory).

Format: `sub-<label>[_ses-<label>][_task-<label>][_acq-<label>][_run-<index>]` `[_proc-<label>][_space-<label>][_recording-<label>][_split-<index>]` `[_desc-<label>]_<`suffix`><`extension`>`

**Returns:**

- *std::string* — The BIDS filename.

---

**Returns:**
