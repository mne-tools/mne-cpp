# BidsTsv

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** BIDS Library &nbsp;·&nbsp; **Source:** [`bids/bids_tsv.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/bids/bids_tsv.h)

`#include <mne/bids/bids_tsv.h>`

```cpp
class mne::BidsTsv
```

Generic BIDS TSV file reader/writer.

BIDS TSV files are tab-separated value files with:

- A mandatory header row defining column names.
- "n/a" for missing values.
- UTF-8 encoding, LF line endings.

Domain-specific TSV I/O (channels, electrodes, events) is handled by [`BidsChannel`](/docs/api/bids/bids-channel), [`BidsElectrode`](/docs/api/bids/bids-electrode), and [`BidsEvent`](/docs/api/bids/bids-event) respectively.

Generic BIDS TSV file I/O.

```cpp title="src/examples/ex_bids/main.cpp"
std::vector<std::string> headers;
const std::vector<BidsTsvRow> rows = BidsTsv::read_tsv(ieeg.events_tsv_path().file_path(), headers);
// each row maps column name -> cell text, e.g. rows[1].at("trial_type") == "response"
```

## Static Methods

### read_tsv(path, headers)

Reads a TSV file into an ordered list of row maps.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Path to the TSV file.

- **headers** : *std::vector&lt; std::string &gt; &*
  Column names from the header row.

**Returns:**

- *std::vector&lt; BidsTsvRow &gt;* — List of rows, each row a map of column-name → value; empty if the file cannot be read.

---

### write_tsv(path, headers, rows)

Writes rows to a TSV file, writing "n/a" for empty and missing values.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Output file path.

- **headers** : *std::span&lt; const std::string &gt;*
  Column names (determines column order).

- **rows** : *std::span&lt; const BidsTsvRow &gt;*
  Data rows.

**Returns:**

- *bool* — true on success, false on I/O error.

---

### value(row, column, fallback)

**Parameters:**

- **row** : *const BidsTsvRow &*
  A row.

- **column** : *std::string_view*
  Column name.

- **fallback** : *std::string_view*
  Value if the row has no such column.

**Returns:**

- *std::string_view* — The value of `column`, valid while `row` is unchanged.
