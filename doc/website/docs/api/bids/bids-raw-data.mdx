# BidsRawData

**Namespace:** `BIDSLIB` &nbsp;·&nbsp; **Library:** BIDS Library

:::info[Python equivalent]
`mne_bids.read_raw_bids` in MNE-Python.
:::

`#include <bids/bids_raw_data.h>`

```cpp
class BIDSLIB::BidsRawData
```

Central container for a BIDS raw dataset, bundling electrophysiological data with all associated sidecar metadata.

[`BidsRawData`](/docs/api/bids/bids-raw-data) is the primary data object of the BIDS library, analogous to [FiffRawData](/docs/api/fiff/fiff-raw-data) for the FIFF library. It owns both the data and the I/O logic:

**`read()`** — static factory that loads a BIDS dataset from disk.


**`write()`** — member that writes the current dataset to a BIDS directory.

Sidecar and coordinate-system fields that are derivable from [FiffInfo](/docs/api/fiff/fiff-info) (sampling frequency, channel counts) are computed on write and applied to [FiffInfo](/docs/api/fiff/fiff-info) on read. Only fields carrying independent information are stored as explicit members.

Example: 
```cpp
BIDSPath path("/data/bids", "01", "implant01", "rest", "ieeg", "ieeg", ".vhdr");
BidsRawData data = BidsRawData::read(path);
if(data.isValid()) {
    qDebug() << "Channels:" << data.raw.info.nchan;
    qDebug() << "Events:"   << data.events.size();

    // Round-trip: write to a new BIDS root
    BIDSPath out("/data/bids_out", "01", "implant01", "rest", "ieeg", "ieeg", ".vhdr");
    data.write(out, path.filePath());
}
```

### write(bidsPath, sourcePath, options)

Write this dataset to a BIDS-compliant directory.

Orchestrates writing of:
Directory structure: root/sub-XX/[ses-YY/]&lt;datatype&gt;/


Raw data file — copies the source file into the BIDS directory


*_channels.tsv


*_electrodes.tsv + *_coordsystem.json


*_events.tsv


*_\{datatype\}.json (iEEG sidecar)


dataset_description.json

**Parameters:**

- **bidsPath** : *const [BIDSPath](/docs/api/bids/bids-path) &*
  Target [`BIDSPath`](/docs/api/bids/bids-path) (root, subject, task, datatype, suffix, extension).

- **sourcePath** : *const QString &*
  Path to the original raw data file to copy. If empty, the raw data file is not copied.

- **options** : *const WriteOptions &*
  Write options (overwrite, dataset name, etc.).

**Returns:**

- *[BIDSPath](/docs/api/bids/bids-path)* — [`BIDSPath`](/docs/api/bids/bids-path) of the written data file, or empty [`BIDSPath`](/docs/api/bids/bids-path) on failure.

## Static Methods

### read(bidsPath)

Read a BIDS dataset from disk.

Static factory that orchestrates reading of:
Raw data file via the appropriate format reader (EDF, BrainVision, …)


*_channels.tsv → channel types, units, bad-channel marking


*_electrodes.tsv + *_coordsystem.json → digitization points


*_events.tsv → event annotations


*_\{datatype\}.json → line frequency and recording metadata

The [`BIDSPath`](/docs/api/bids/bids-path) must have at minimum: root, subject, datatype, suffix, extension.

**Parameters:**

- **bidsPath** : *const [BIDSPath](/docs/api/bids/bids-path) &*
  Fully specified [`BIDSPath`](/docs/api/bids/bids-path) pointing to the raw data file.

**Returns:**

- *[BidsRawData](/docs/api/bids/bids-raw-data)* — Populated [`BidsRawData`](/docs/api/bids/bids-raw-data). Check `isValid()` to determine success.
