### to_fiff_dig_points(electrodes, trans)

Convert a list of BIDS electrodes to a FIFF digitizer point set.

Each electrode with valid numeric x/y/z coordinates is converted to a [`FiffDigPoint`](/docs/api/fiff/fiff-dig-point) with kind FIFFV_POINT_EEG. Electrodes with "n/a" coordinates are skipped.

If a coordinate transform is supplied, the positions are transformed from the BIDS coordinate frame into the FIFF head frame before insertion, and the points are in its target frame; otherwise their frame is FIFFV_COORD_UNKNOWN.

**Parameters:**

- **electrodes** : *std::span&lt; const [BidsElectrode](/docs/api/bids/bids-electrode) &gt;*
  List of BIDS electrode records.

- **trans** : *const [FiffCoordTrans](/docs/api/fiff/fiff-coord-trans) &*
  Optional coordinate transform (BIDS frame → head). Pass a default-constructed [`FiffCoordTrans`](/docs/api/fiff/fiff-coord-trans) to skip.

**Returns:**

- *[FiffDigPointSet](/docs/api/fiff/fiff-dig-point-set)* — [`FiffDigPointSet`](/docs/api/fiff/fiff-dig-point-set) with one point per valid electrode.
