# BidsDatasetDescription

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** BIDS Library &nbsp;·&nbsp; **Source:** [`bids/bids_dataset_description.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/bids/bids_dataset_description.h)

`#include <mne/bids/bids_dataset_description.h>`

```cpp
struct mne::BidsDatasetDescription
```

Dataset-level metadata from dataset_description.json.

Every BIDS dataset must contain a dataset_description.json at its root. This struct captures the required and recommended fields.

```cpp title="src/examples/ex_bids/main.cpp"
const BidsDatasetDescription description = BidsDatasetDescription::read(root / "dataset_description.json");
const std::vector<BidsChannel> channels = BidsChannel::read_tsv(channelsTsv);                  // one row per channel
const std::vector<BidsEvent> events = BidsEvent::read_tsv(ieeg.events_tsv_path().file_path()); // onset, duration, sample, value, trial_type
const std::vector<BidsElectrode> electrodes = BidsElectrode::read_tsv(ieeg.electrodes_tsv_path().file_path());
const BidsCoordinateSystem coords = BidsCoordinateSystem::read_json(ieeg.coordsystem_json_path().file_path());
```

---

## Static Methods

### read(path)

Read a dataset_description.json file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Path to dataset_description.json.

**Returns:**

- *[BidsDatasetDescription](/docs/api/bids/bids-dataset-description)* — Populated description, or default if file cannot be read.

---

### write(path, desc)

Write a dataset_description.json file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Output path.

- **desc** : *const [BidsDatasetDescription](/docs/api/bids/bids-dataset-description) &*
  Dataset description to write.

**Returns:**

- *bool* — true on success.
