# stream_outlet

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** LSL Library &nbsp;·&nbsp; **Source:** [`lsl/lsl_stream_outlet.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/lsl/lsl_stream_outlet.h)

`#include <mne/lsl/lsl_stream_outlet.h>`

```cpp
class mne::stream_outlet
```

Server-side LSL endpoint: binds a TCP data server, answers LSL discovery queries, and fans samples out to every connected inlet.

```cpp title="src/examples/ex_lsl/main.cpp"
stream_info info("ex_lsl_eeg", "EEG", 3, 250.0, ChannelFormat::Float32, "ex_lsl"); // name, type, channels, Hz
stream_outlet outlet(info);                                                        // starts serving immediately
```

---

## Public Methods

### stream_outlet(info)

Construct a [`stream_outlet`](/docs/api/lsl/stream_outlet) for the given [`stream_info`](/docs/api/lsl/stream_info).

This immediately starts the TCP data server and the UDP query responders.

**Parameters:**

- **info** : *const [stream_info](/docs/api/lsl/stream_info) &*
  The [`stream_info`](/docs/api/lsl/stream_info) describing this outlet's stream.

---

### ~stream_outlet()

Destructor.

Stops answering queries and closes all connections.

---

### push_sample(sample)

Push a single multichannel sample into the outlet.

**Parameters:**

- **sample** : *const std::vector&lt; float &gt; &*
  A vector of channel values (must match the stream's channel_count).

---

### push_chunk(chunk)

Push a chunk of multichannel samples into the outlet.

**Parameters:**

- **chunk** : *const std::vector&lt; std::vector&lt; float &gt; &gt; &*
  A vector of samples, where each sample is a vector of channel values.

---

### push_chunk_double(chunk)

Push a chunk of double samples; double64 and int32 streams carry them without loss through float.

**Parameters:**

- **chunk** : *const std::vector&lt; std::vector&lt; double &gt; &gt; &*
  A vector of samples, where each sample is a vector of channel values.

---

### push_sample(sample)

Push a single sample of any numeric type, as liblsl's push_sample&lt;T&gt;; float takes the overload above.

**Parameters:**

- **sample** : *const std::vector&lt; T &gt; &*
  A vector of channel values (must match the stream's channel_count).

---

### push_chunk(chunk)

Push a chunk of samples of any numeric type, as liblsl's push_chunk&lt;T&gt;; float takes the overload above.

**Parameters:**

- **chunk** : *const std::vector&lt; std::vector&lt; T &gt; &gt; &*
  A vector of samples, where each sample is a vector of channel values.

---

### info()

Get the [`stream_info`](/docs/api/lsl/stream_info) associated with this outlet (including the assigned data port).

**Returns:**

- *[stream_info](/docs/api/lsl/stream_info)* — The [`stream_info`](/docs/api/lsl/stream_info) for this outlet.

### have_consumers()

Check whether any consumers are currently connected.

**Returns:**

- *bool* — True if at least one inlet is connected.
