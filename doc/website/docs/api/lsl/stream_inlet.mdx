# stream_inlet

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** LSL Library &nbsp;·&nbsp; **Source:** [`lsl/lsl_stream_inlet.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/lsl/lsl_stream_inlet.h)

`#include <mne/lsl/lsl_stream_inlet.h>`

```cpp
class mne::stream_inlet
```

Client-side LSL endpoint: connects to a resolved outlet over TCP and exposes pulled samples as float or double chunks.

```cpp title="src/examples/ex_lsl/main.cpp"
stream_info source = outlet.info(); // normally an entry of resolve_stream("name", "ex_lsl_eeg")
source.set_data_host("127.0.0.1");
stream_inlet inlet(source);
inlet.open_stream();
QElapsedTimer clock;
clock.start();
while (!outlet.have_consumers() && clock.elapsed() < 5000) { // samples pushed before the outlet accepts the inlet are not delivered
    QThread::msleep(5);
}
outlet.push_sample({1.0f, 2.0f, 3.0f});
outlet.push_chunk({{4.0f, 5.0f, 6.0f}, {7.0f, 8.0f, 9.0f}});

std::vector<std::vector<float>> received;
clock.restart();
while (received.size() < 3 && clock.elapsed() < 5000) {
    QThread::msleep(20);
    for (const std::vector<float>& sample : inlet.pull_chunk<float>()) { // one vector per sample
        received.push_back(sample);
    }
}
inlet.close_stream();
```

### samples_available()

### pull_chunk()

Pull a chunk of multichannel data from the inlet.

Returns all complete samples currently in the buffer, converted to `T` as liblsl's pull_chunk&lt;T&gt; does (integers rounded to the nearest value).

**Returns:**

- *std::vector&lt; std::vector&lt; T &gt; &gt;* — A vector of samples, where each sample is a vector of channel values.

### info(timeout)

The full info of the stream, as liblsl's `stream_inlet::info()`: fetched from the outlet once (fullinfo request), then cached.

Unlike the info from discovery it carries the channel description.

**Parameters:**

- **timeout** : *double*
  Maximum wait in seconds.

**Returns:**

- *[stream_info](/docs/api/lsl/stream_info)* — The stream info with its channel description.

---

### time_correction(timeout)

Estimates the offset between the outlet host's clock and `local_clock()` from round trips to the outlet's service port, keeping the one with the shortest round-trip time.

It sends at least 8 probes and goes on, up to 64, until one returns within 1 ms, so a host that delays a burst of replies does not bias the result.

**Parameters:**

- **timeout** : *double*
  Maximum wait in seconds.

**Returns:**

- *double* — Seconds to add to the outlet's timestamps to express them in `local_clock()`, or NaN if the outlet did not answer within `timeout`.
