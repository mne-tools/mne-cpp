# channel_description

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** LSL Library &nbsp;·&nbsp; **Source:** [`lsl/lsl_stream_info.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/lsl/lsl_stream_info.h)

`#include <lsl/lsl_stream_info.h>`

```cpp
struct mne::channel_description
```

Description of one channel, as liblsl's stream description carries it in desc/channels/channel.

```cpp title="src/examples/ex_lsl/main.cpp"
stream_info described("ex_lsl_labelled", "EEG", 2, 250.0, ChannelFormat::Float32, "ex_lsl_labelled");
described.set_channels({{"Fz", "EEG", "microvolts"}, {"Cz", "EEG", "microvolts"}}); // sent with the full info
stream_outlet labelled(described);
```
