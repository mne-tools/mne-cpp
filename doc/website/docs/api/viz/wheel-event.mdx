# WheelEvent

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/input_event.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/input_event.h)

`#include <mne/viz/input_event.h>`

```cpp
struct mne::viz::WheelEvent
```

A wheel or two-finger scroll event.

The angle deltas follow the convention of most toolkits: one notch of a mouse wheel is 120 (eighths of a degree), positive y scrolls up (away from the user) and positive x scrolls left.

---

## Example

No example of its own: Toolkit-neutral input value type passed to TraceView::handle_wheel(); hosts convert their native events to it.

## Used in examples

    WheelEvent wheel;
    wheel.x = event.wheel.mouse_x;
    wheel.y = event.wheel.mouse_y;
    // SDL counts notches, the scene eighths of a degree (120 per notch)
    wheel.angle_delta_x = -120.0 * event.wheel.x;
    wheel.angle_delta_y = 120.0 * event.wheel.y;
    wheel.modifiers = modifiers_of(SDL_GetModState());
    wheel.timestamp_ms = now;
    view.handle_wheel(wheel);
    break;
