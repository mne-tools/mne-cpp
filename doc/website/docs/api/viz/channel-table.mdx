# ChannelTable

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/models/channel_table.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/models/channel_table.h)

`#include <mne/viz/channel_table.h>`

```cpp
class mne::viz::ChannelTable
```

Channel rows and their presentation attributes for a channel information table.

### ChannelTable()

Creates an empty table.

### set_info(info)

Sets the measurement info; aliases start as the channel names and are mapped to layout names.

**Parameters:**

- **info** : *std::shared_ptr&lt; [FiffInfo](/docs/api/fiff/fiff-info) &gt;*
  Measurement info, shared with the caller.

---

### info()

**Returns:**

- *const std::shared_ptr&lt; [FiffInfo](/docs/api/fiff/fiff-info) &gt; &* — The measurement info.

---

### set_layout(layout)

Sets the 2-D sensor layout and maps the channels to it again.

**Parameters:**

- **layout** : *std::map&lt; std::string, std::array&lt; double, 2 &gt; &gt;*
  Position of each layout channel name.

---

### clear()

Drops the info, the layout and all names.
