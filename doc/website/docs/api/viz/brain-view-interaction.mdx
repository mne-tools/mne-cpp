# BrainViewInteraction

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/brain_view_interaction.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/brain_view_interaction.h)

`#include <mne/viz/brain_view_interaction.h>`

```cpp
class mne::viz::BrainViewInteraction
```

Input state machine of the 3-D brain view.

Drags follow the buttons held according to the pointer events. In the single view a left-button drag orbits the camera; in the multi view it orbits the perspective pane under the pointer and pans the other panes, and dragging a splitter resizes the panes. The wheel zooms the view (or the pane) under the pointer, R resets the rotation of the single view and S asks for a snapshot. A left click without a drag reports the clicked point, a hover move the hovered point.

The camera states are owned by the host (`attach_cameras()`); the host keeps the pane setup up to date with `set_view_size()` and `set_panes()` before it forwards events. `Effects` go out through `Effects`; positions are rounded to whole logical pixels, as pane hit-testing is done in pixels.

### attach_cameras(single, panes)

Attaches the camera states the input changes; they are not owned and must outlive their use.

**Parameters:**

- **single** : *[PaneCamera](/docs/api/viz/pane-camera) **
  Camera of the single view: rotation and zoom.

- **panes** : *std::vector&lt; [PaneCamera](/docs/api/viz/pane-camera) * &gt;*
  Camera of each viewport of the multi view, by viewport index.

### orbit_perspective_views(dx, dy)

Orbits the single view, or every perspective pane of the multi view, as a pointer drag would; used for the automated rotation.

**Parameters:**

- **dx** : *double*
  Horizontal drag in pixels.

- **dy** : *double*
  Vertical drag in pixels.
