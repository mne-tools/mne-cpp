# Font

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/style.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/style.h)

`#include <mne/viz/style.h>`

```cpp
struct mne::viz::Font
```

A font request; a backend picks the closest font it has.

[`Point`](/docs/api/viz/point) sizes are converted with the backend's resolution, pixel sizes are exact. With neither size set, the backend uses its default font size.
