# BrainSurface

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/brainsurface.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/brainsurface.h)

`#include <mne/viz/brainsurface.h>`

```cpp
class mne::viz::BrainSurface
```

[`BrainSurface`](/docs/api/viz/brain-surface) manages the geometry and visual properties of a single brain mesh.

Renderable cortical surface mesh with per-vertex color, curvature data, and GPU buffer management.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// A 2 x 2 cm flat patch at z = 0 (metres), picked by a ray cast straight down
MatrixX3f patchVertices(4, 3);
patchVertices << 0.0f, 0.0f, 0.0f, 0.02f, 0.0f, 0.0f, 0.02f, 0.02f, 0.0f, 0.0f, 0.02f, 0.0f;
MatrixX3i patchTriangles(2, 3);
patchTriangles << 0, 1, 2, 0, 2, 3;
BrainSurface patch;
patch.createFromData(patchVertices, patchTriangles, toColor(QColor(Qt::gray)));
patch.setHemi(0);
float hitDistance = 0.0f;
int hitVertex = -1;
const bool picked = patch.intersects(Eigen::Vector3f(0.019f, 0.019f, 0.05f), Eigen::Vector3f(0.0f, 0.0f, -1.0f), hitDistance, hitVertex);
const VertexData& corner = patch.vertexDataRef().at(2); // interleaved position, normal and packed ABGR colour
```

### intersects(rayOrigin, rayDir, dist, vertexIdx)

**Parameters:**

- **rayOrigin** : *const Eigen::Vector3f &*
  [`Ray`](/docs/api/viz/ray) origin in world/local space (object is assumed at 0,0,0 usually unless transformed externally). Note: The [`BrainSurface`](/docs/api/viz/brain-surface) vertices are typically already transformed (e.g. by View3D model matrix logic? No, BrainView applies matrix in shader. - **dist** : *float &*
  Distance to intersection.

- **vertexIdx** : *int &*

**Returns:**

- *bool* — True if intersected.

````cpp title="src/examples/ex_disp3d_scene/main.cpp, line 231"
patchVertices << 0.0f, 0.0f, 0.0f, 0.02f, 0.0f, 0.0f, 0.02f, 0.02f, 0.0f, 0.0f, 0.02f, 0.0f;

const VertexData& corner = patch.vertexDataRef().at(2); // interleaved position, normal and packed ABGR colour
ok &= expect(picked && std::abs(hitDistance - 0.05f) < 1e-6f && hitVertex == 2 && corner.pos == Eigen::Vector3f(0.02f, 0.02f, 0.0f) && std::abs(std::abs(corner.norm.z()) - 1.0f) < 1e-6f,
             "BrainSurface: a downward ray hits the patch 5 cm below, nearest vertex 2");
````
