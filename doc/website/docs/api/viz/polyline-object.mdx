# PolylineObject

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/polylineobject.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/polylineobject.h)

`#include <mne/viz/polylineobject.h>`

```cpp
class mne::viz::PolylineObject
```

Renders an ordered sequence of points as connected line segments.

Each segment is one instance of a unit cylinder, using the same instance layout as [`DipoleObject`](/docs/api/viz/dipole-object) and [`NetworkObject`](/docs/api/viz/network-object) so the existing Dipole pipeline can draw it without a dedicated shader.

Connected line segments through an ordered list of points.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// Head-position track: N points draw N - 1 tube segments; repeated positions are skipped
PolylineObject track;
track.setPoints({Vector3f(0.0f, 0.0f, 0.0f), Vector3f(0.0f, 0.0f, 0.0f), Vector3f(0.001f, 0.0f, 0.0f), Vector3f(0.002f, 0.001f, 0.0f)});
track.setRadius(0.0005f);
track.setGradient(Color{0, 0, 255, 255}, Color{255, 0, 0, 255}); // oldest to newest
```

### ~PolylineObject()

Destroys the [`PolylineObject`](/docs/api/viz/polyline-object).

---

### setPoints(vecPoints)

Sets the points of the polyline.

Fewer than two points clears the object, since a single point has no segment to draw.

**Parameters:**

- **vecPoints** : *const std::vector&lt; Eigen::Vector3f &gt; &*
  Points in scene coordinates, in order.

---

### clear()

Clears all points.

---

### setRadius(fRadius)

Sets the radius of the drawn segments.

**Parameters:**

- **fRadius** : *float*
  Segment radius in scene units.

---

### setGradient(startColor, endColor)

Sets the colours the segments are graded between from start to end.

Grading the line makes the direction of travel readable without any extra decoration.

**Parameters:**

- **startColor** : *const [Color](/docs/api/viz/color) &*
  Colour of the first segment.

- **endColor** : *const [Color](/docs/api/viz/color) &*
  Colour of the last segment.

---
