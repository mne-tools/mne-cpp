# GpuTexture

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/gpu/gpu_frame.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/gpu/gpu_frame.h)

`#include <mne/viz/gpu_frame.h>`

```cpp
struct mne::viz::GpuTexture
```

A texture: RGBA pixels or a figure the backend rasterizes, and a revision that changes with it.

A figure lets every backend draw text and shapes with its own painter, e.g. the QRhi backend with QPainter and the toolkit's fonts, at `scale` texture pixels per figure pixel on a transparent ground.
