# Theme

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/theme.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/theme.h)

`#include <mne/viz/theme.h>`

```cpp
struct mne::viz::Theme
```

The look of toolkit-free views such as [`FormView`](/docs/api/viz/form-view): one calm palette, font sizes and metrics.

All lengths are in logical units. Backends draw the same [`Theme`](/docs/api/viz/theme), so a panel looks alike in every window.
