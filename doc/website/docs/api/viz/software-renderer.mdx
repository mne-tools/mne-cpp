# SoftwareRenderer

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/gpu/software_renderer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/gpu/software_renderer.h)

`#include <mne/viz/software_renderer.h>`

```cpp
class mne::viz::SoftwareRenderer
```

Executes a [`GpuFrame`](/docs/api/viz/gpu-frame) on the CPU.

Triangles are rasterized with perspective-correct varyings, near- and far-plane clipping, depth testing and face culling; lines and points are one pixel wide, as on the GPU backends. Figure textures are rasterized with `to_raster()`. The shaders of the views in mne_scene are registered on construction; `set_shader()` adds others. Draws whose shader is unknown are skipped.

## Public Methods

### set_shader(id, shader)

Adds or replaces a shader.

**Parameters:**

- **id** : *const std::string &*
  Shader id the pipelines refer to.

- **shader** : *[SoftwareShader](/docs/api/viz/software-shader)*
  Implementation.

---

### has_shader(id)

**Parameters:**

- **id** : *const std::string &*
  Shader id.

**Returns:**

- *bool* — Whether a shader with the id is registered.

---

### render(frame, resources)

Renders a frame.

**Parameters:**

- **frame** : *const [GpuFrame](/docs/api/viz/gpu-frame) &*
  Passes and draws.

- **resources** : *const [GpuResources](/docs/api/viz/gpu-resources) &*
  Buffers, textures and pipelines the frame refers to.

**Returns:**

- *[Image](/docs/api/viz/image)* — The target image, frame.pixel_width x frame.pixel_height, not premultiplied.

---

### set_fonts(fonts)

Sets the fonts figure textures draw their text with; by default they use the bitmap font of `to_raster()`.

**Parameters:**

- **fonts** : *std::shared_ptr&lt; const [FontSource](/docs/api/viz/font-source) &gt;*
  Fonts, e.g. `FontLibrary::shared()`; nullptr restores the bitmap font.
