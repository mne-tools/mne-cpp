# TraceFrameBuilder

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/gpu/trace_frame.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/gpu/trace_frame.h)

`#include <mne/viz/trace_frame.h>`

```cpp
class mne::viz::TraceFrameBuilder
```

Describes the frames of a trace view as [`GpuFrame`](/docs/api/viz/gpu-frame) for any backend.

One pass clears to the background and draws one line strip per trace (shader "channeldata"), then the annotations, events and epoch markers with the per-second bands (shader "overlay" over a texture that spans `overlay_prefetch()` view widths on each side, so scrolling does not redraw it), then the crosshair, scalebars, ruler and annotation selection (shader "overlay" over a screen-sized texture). The builder keeps the vertex buffers, textures and pipelines in `resources()` and streams vertices through its [`TraceGeometry`](/docs/api/viz/trace-geometry).

### build(view, source, style, markers, metrics, target)

Describes the next frame; streams vertices and redraws the textures as needed.

**Parameters:**

- **view** : *const [TraceView](/docs/api/viz/trace-view) &*
  Viewport, overlays and annotations.

- **source** : *const [TraceSource](/docs/api/viz/trace-source) &*
  The channels.

- **style** : *const [TraceStyle](/docs/api/viz/trace-style) &*
  Colours and scales; the background is the clear colour, grid the per-second bands.

- **markers** : *const [TraceMarkers](/docs/api/viz/trace-markers) &*
  Events and epoch markers.

- **metrics** : *const [TextMetrics](/docs/api/viz/text-metrics) &*
  Measures the text of the overlays.

- **target** : *const [GpuFrameTarget](/docs/api/viz/gpu-frame-target) &*
  Size and pixel ratio of the target.

**Returns:**

- *[GpuFrame](/docs/api/viz/gpu-frame)* — The frame, referring to `resources()`.
