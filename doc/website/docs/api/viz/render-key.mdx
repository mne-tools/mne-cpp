# RenderKey

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/rendertypes.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/rendertypes.h)

`#include <mne/viz/rendertypes.h>`

```cpp
class mne::viz::RenderKey
```

Identity of a renderable in the renderer's GPU resource cache.

The renderer drops the GPU copies of a renderable once its key is destroyed. A copied renderable gets a key of its own, so it never shares GPU buffers with the original.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// What a renderer uploads: CPU streams with generations, cached under the renderable's key
const GpuStream patchGeometry = patch.geometryStream();
const InstancedStreams glyphStreams = dipoleGlyphs.streams();
const RenderKey& patchKey = patch.renderKey();
```
