# RtSensorInterpolationMatWorker

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/realtime/rtsensorinterpolationmatworker.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/realtime/rtsensorinterpolationmatworker.h)

`#include <mne/viz/rtsensorinterpolationmatworker.h>`

```cpp
class mne::viz::RtSensorInterpolationMatWorker
```

[`RtSensorInterpolationMatWorker`](/docs/api/viz/rt-sensor-interpolation-mat-worker) computes dense sensor-to-surface field-mapping matrices in a background thread.

This worker encapsulates the expensive `mne::FwdFieldMap::computeMegMapping()` and computeEegMapping() calls that were previously performed synchronously on the main thread inside [BrainView](/docs/api/viz-qt/brain-view)::buildSensorFieldMapping().

The worker stores all relevant parameters (evoked info, surface geometry, transforms, etc.) and recomputes the mapping matrices when any parameter changes. It emits newMappingMatrixAvailable() when a new matrix is ready.

Thread-safety: all public setters are mutex-protected and schedule a recomputation via the `computeMapping()` slot.

Background worker for computing sensor field mapping matrices.

### computeMapping()

Compute the sensor-to-surface mapping matrices.

This slot can be called directly or connected to a signal. The computation reads the stored parameters and builds dense mapping matrices via `mne::FwdFieldMap::computeMegMapping()` / computeEegMapping().
