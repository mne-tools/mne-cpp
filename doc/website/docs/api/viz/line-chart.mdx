# LineChart

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/line_chart.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/line_chart.h)

`#include <mne/viz/line_chart.h>`

```cpp
class mne::viz::LineChart
```

Line series over shared axes, like matplotlib's plot().

The axes span the data with 5 % padding in y; ticks fall on round numbers with a light grid. `Series` without colour take the first palette colour no series uses yet. Labelled series get a legend in the corner of the axes that hides the least of the lines, or to the right of the axes if every corner hides some.

```cpp title="src/examples/ex_scene/main.cpp"
// Qt:   QPainter p(&widget); p.setPen(...); p.drawRect(...); p.drawText(...);
Canvas canvas(200, 120, Color::white());
canvas.set_antialiasing(true);
canvas.set_pen(Pen{{50, 100, 150}, 1.5});
canvas.set_brush(Brush::solid({70, 130, 180}));
canvas.draw_rounded_rect({20, 20, 80, 50}, 6, 6);
canvas.set_pen(Color::black());
canvas.draw_text(Rect{0, 80, 200, 30}, Align::Center, "Hello scene");
const DisplayList figure = canvas.take();

// A plot: the same model a disp widget shows on screen
std::vector<double> x;
std::vector<double> y;
for (int i = 0; i < 100; ++i) {
    x.push_back(i * 0.01);
    y.push_back(std::sin(2 * 3.14159265358979 * 5 * x.back()));
}
LineChart plot;
plot.set_title("5 Hz sine");
plot.set_x_label("time (s)");
plot.add_series(x, y, "signal");
const ApproximateTextMetrics metrics;
const DisplayList chart = plot.render(480, 320, metrics, Font{"", 0.0, 13.0});

const Expected<void> svg = write_svg(chart, dir / "plot.svg");
const Expected<void> png = to_raster(chart).save_png(dir / "plot.png");
```

### set_data(x, y)

Replaces all series by one series.

**Parameters:**

- **x** : *const std::vector&lt; double &gt; &*
  X values.

- **y** : *const std::vector&lt; double &gt; &*
  Y values; the shorter of `x` and `y` sets the length.

---

### add_series(x, y, label, color, style)

Adds a series; the shorter of `x` and `y` sets its length.

**Parameters:**

- **x** : *const std::vector&lt; double &gt; &*
  X values.

- **y** : *const std::vector&lt; double &gt; &*
  Y values.

- **label** : *std::string*
  Legend entry, none if empty.

- **color** : *std::optional&lt; [Color](/docs/api/viz/color) &gt;*
  Line colour, or the next unused palette colour.

- **style** : *LineStyle*
  Dash pattern.

---

### clear()

Removes all series; title and labels stay.

### draw(canvas, metrics, font)

Draws the plot into the rectangle (0, 0, width, height) of `canvas`.

**Parameters:**

- **canvas** : *[Canvas](/docs/api/viz/canvas) &*
  [`Canvas`](/docs/api/viz/canvas).

- **metrics** : *const [TextMetrics](/docs/api/viz/text-metrics) &*
  Measures the labels.

- **font** : *const [Font](/docs/api/viz/font) &*
  [`Font`](/docs/api/viz/font) of ticks and labels; the title is bold and 1.25 times larger.
