# FontFace

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/font_face.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/font_face.h)

`#include <mne/viz/font_face.h>`

```cpp
class mne::viz::FontFace
```

One face of a TrueType (.ttf) or TrueType collection (.ttc) font.

Fonts with CFF outlines (.otf without a glyf table) are rejected. Of a variable font the default instance is read. Glyph coordinates are in font units with y growing upwards; `units_per_em()` of them make the font size.

```cpp title="src/examples/ex_scene/main.cpp"
// One face: glyphs, advances and pair kerning in font units
const std::shared_ptr<const FontFace> face = FontLibrary::sans();
const std::uint32_t t = face->glyph_index(U'T');
const double kerning = face->kerning(t, face->glyph_index(U'o')) * 13.0 / face->units_per_em(); // pixels at 13 px
```

**Parameters:**

- **pixels_per_em** : *double*

**Returns:**

- *std::shared_ptr&lt; const std::vector&lt; Polygon &gt; &gt;* — Closed polygons in font units, y up, with their original orientation (fill with non-zero winding).
