# ButterflyPlot

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/butterfly_plot.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/butterfly_plot.h)

`#include <mne/viz/butterfly_plot.h>`

```cpp
class mne::viz::ButterflyPlot
```

Evoked responses of many channels drawn on top of each other, as in MNE-Python's butterfly plot.

Each channel's traces are scaled so that its range fills half the height above and below the zero line; bad channels are drawn faint. A dashed red line marks the stimulus, a light red band the baseline interval and dashed grey lines every 50 ms, labelled at the bottom.

Geometry follows the single-precision arithmetic of the QPainter code it replaces, so the QPainter backend draws the same pixels as before.

```cpp title="src/examples/ex_scene/main.cpp"
// Qt:   QPainter p(&widget); p.setPen(...); p.drawRect(...); p.drawText(...);
Canvas canvas(200, 120, Color::white());
canvas.set_antialiasing(true);
canvas.set_pen(Pen{{50, 100, 150}, 1.5});
canvas.set_brush(Brush::solid({70, 130, 180}));
canvas.draw_rounded_rect({20, 20, 80, 50}, 6, 6);
canvas.set_pen(Color::black());
canvas.draw_text(Rect{0, 80, 200, 30}, Align::Center, "Hello scene");
const DisplayList figure = canvas.take();

// A plot: the same model a disp widget shows on screen
std::vector<double> x;
std::vector<double> y;
for (int i = 0; i < 100; ++i) {
    x.push_back(i * 0.01);
    y.push_back(std::sin(2 * 3.14159265358979 * 5 * x.back()));
}
LineChart plot;
plot.set_title("5 Hz sine");
plot.set_x_label("time (s)");
plot.add_series(x, y, "signal");
const ApproximateTextMetrics metrics;
const DisplayList chart = plot.render(480, 320, metrics, Font{"", 0.0, 13.0});

const Expected<void> svg = write_svg(chart, dir / "plot.svg");
const Expected<void> png = to_raster(chart).save_png(dir / "plot.png");
```

## Public Methods

### set_timing(samples, preStimSamples, sfreq)

Sets the time axis.

**Parameters:**

- **samples** : *int*
  Samples per trace.

- **preStimSamples** : *int*
  Samples before the stimulus.

- **sfreq** : *float*
  Sampling frequency in Hz.

---

### set_baseline(from, to)

Sets the baseline interval in seconds relative to the stimulus.

**Parameters:**

- **from** : *float*
  Start in seconds.

- **to** : *float*
  End in seconds.

---

### set_time_spacers(on)

Shows or hides the lines every 50 ms.

**Parameters:**

- **on** : *bool*
  Whether the lines are shown.

---

### set_background(color)

Sets the background colour.

**Parameters:**

- **color** : *[Color](/docs/api/viz/color)*
  Background colour.

---

### set_frozen(frozen)

Draws the traces half transparent, to compare a frozen average with live data.

**Parameters:**

- **frozen** : *bool*
  Whether the traces are frozen.

---

### set_channels(channels)

Sets the channels, drawn in order.

**Parameters:**

- **channels** : *std::vector&lt; Channel &gt;*
  Channels in drawing order.

---

### channels()

**Returns:**

- *const std::vector&lt; Channel &gt; &* — The channels.

---

### draw(canvas, font)

Draws the plot into the rectangle (0, 0, width, height) of `canvas`.

**Parameters:**

- **canvas** : *[Canvas](/docs/api/viz/canvas) &*
  [`Canvas`](/docs/api/viz/canvas).

- **font** : *const [Font](/docs/api/viz/font) &*
  [`Font`](/docs/api/viz/font) of the time labels.

---

### render(width, height, font)

**Parameters:**

- **width** : *double*
  Width in pixels.

- **height** : *double*
  Height in pixels.

- **font** : *const [Font](/docs/api/viz/font) &*
  [`Font`](/docs/api/viz/font) of the time labels.

**Returns:**

- *[DisplayList](/docs/api/viz/display-list)* — The plot as a figure of `width` x `height`.
