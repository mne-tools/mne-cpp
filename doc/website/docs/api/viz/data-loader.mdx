# DataLoader

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/dataloader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/dataloader.h)

`#include <mne/viz/dataloader.h>`

```cpp
class mne::viz::DataLoader
```

Pure I/O helpers that load MNE data files and return results.

These static methods have zero coupling to the widget layer. [BrainView](/docs/api/viz-qt/brain-view) calls them to obtain data and then wires the results into its own model / surface map / member state.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// The Neuromag helmet shipped with MNE-CPP, shifted 4 cm up as a device-to-head transform would
Eigen::Matrix4f devToHead = Eigen::Matrix4f::Identity();
devToHead(2, 3) = 0.04f;
const auto helmet = DataLoader::loadHelmetSurface(mne::resource_path("general/sensorSurfaces/306m.fif"), devToHead, true);
const DataLoader::SensorLoadResult noSensors = DataLoader::loadSensors("missing.fif"); // reports, never throws
```

## Static Methods

### loadSensors(fifPath, megHelmetOverridePath)

Load sensor channels, digitizer points and MEG helmet from a FIF file.

**Parameters:**

- **fifPath** : *const std::filesystem::path &*
  Path to the FIF file.

- **megHelmetOverridePath** : *const std::filesystem::path &*
  Optional override for the helmet surface file.

**Returns:**

- *SensorLoadResult* — Populated `SensorLoadResult`.

---

### loadHelmetSurface(helmetFilePath, devHeadTrans, applyTrans)

Load a standalone MEG helmet surface from a BEM FIF file.

**Parameters:**

- **helmetFilePath** : *const std::filesystem::path &*
  Path to the helmet BEM FIF file.

- **devHeadTrans** : *const Eigen::Matrix4f &*
  Device-to-Head transformation matrix (identity if none).

- **applyTrans** : *bool*
  Whether to apply the dev→head transform.

**Returns:**

- *std::shared_ptr&lt; [BrainSurface](/docs/api/viz/brain-surface) &gt;* — Shared pointer to the loaded [`BrainSurface`](/docs/api/viz/brain-surface), or nullptr on failure.

---

### loadDipoles(dipPath)

Load dipole set from a .dip file.

**Parameters:**

- **dipPath** : *const std::filesystem::path &*
  Path to the dipole file.

**Returns:**

- *[InvEcdSet](/docs/api/inv/inv-ecd-set)* — The loaded [`InvEcdSet`](/docs/api/inv/inv-ecd-set) (may be empty on failure).

---

### loadSourceSpace(fwdPath)

Load source space from a forward-solution FIF file.

**Parameters:**

- **fwdPath** : *const std::filesystem::path &*
  Path to the FIF file with source space.

**Returns:**

- *[MNESourceSpaces](/docs/api/mne/mne-source-spaces)* — The loaded source space (may be empty on failure).

---

### loadHeadToMriTransform(transPath, trans)

Load the Head ↔ MRI transformation from a FIF file and normalise it to Head → MRI orientation.

Other transforms in the file are ignored.

**Parameters:**

- **transPath** : *const std::filesystem::path &*
  Path to the FIF file.

- **trans** : *[FiffCoordTrans](/docs/api/fiff/fiff-coord-trans) &*
  The resulting transform (Head → MRI).

**Returns:**

- *bool* — true on success; false if the file holds no Head ↔ MRI transform.

---

### loadEvoked(evokedPath, aveIndex)

Load an [`FiffEvoked`](/docs/api/fiff/fiff-evoked) from a FIF file.

**Parameters:**

- **evokedPath** : *const std::filesystem::path &*
  Path to the FIF file.

- **aveIndex** : *int*
  Set index to load.

**Returns:**

- *[FiffEvoked](/docs/api/fiff/fiff-evoked)* — The loaded [`FiffEvoked`](/docs/api/fiff/fiff-evoked) (may be empty on failure).

---

### probeEvokedSets(evokedPath)

Probe a FIF file for the available evoked data sets.

**Parameters:**

- **evokedPath** : *const std::filesystem::path &*
  Path to the FIF file.

**Returns:**

- *std::vector&lt; std::string &gt;* — List of human-readable labels for each set.

````cpp title="src/examples/ex_disp3d_scene/main.cpp, line 337"
// The Neuromag helmet shipped with MNE-CPP, shifted 4 cm up as a device-to-head transform would
Eigen::Matrix4f devToHead = Eigen::Matrix4f::Identity();
devToHead(2, 3) = 0.04f;
const auto helmet = DataLoader::loadHelmetSurface(mne::resource_path("general/sensorSurfaces/306m.fif"), devToHead, true);
const DataLoader::SensorLoadResult noSensors = DataLoader::loadSensors("missing.fif"); // reports, never throws
Eigen::Vector3f helmetMin;
Eigen::Vector3f helmetMax;
if (helmet) {
    helmet->boundingBox(helmetMin, helmetMax);
}
ok &= expect(helmet && helmet->vertexCount() > 0 && helmetMax.z() > 0.04f && !noSensors.hasInfo,
             "DataLoader: the helmet loads and moves with the transform; a missing file yields no sensors");
````
