# PointerEvent

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/input_event.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/input_event.h)

`#include <mne/viz/input_event.h>`

```cpp
struct mne::viz::PointerEvent
```

A mouse or touch-pad pointer event in logical (device-independent) pixels of the view.

---

## Example

No example of its own: Toolkit-neutral input value type passed to TraceView::handle_pointer(); hosts convert their native events to it.
