# OrbitCamera

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/camera.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/camera.h)

`#include <mne/viz/camera.h>`

```cpp
class mne::viz::OrbitCamera
```

Orbit camera of the 3-D brain view: looks at the scene centre from a distance set by the scene size and the zoom.

The camera sits at 1.5 scene sizes from the centre, minus 0.05 scene sizes per zoom notch, with a 45 degree field of view, the near plane at 0.01 scene sizes and the far plane at 20 scene sizes but at least 100 units.

## Static Methods

### orbit(rotation, dx, dy, degrees_per_pixel)

Orbits a user rotation (applied on top of the perspective preset) by a pointer drag: horizontal motion turns about the camera's up axis, vertical motion about its right axis.

**Parameters:**

- **rotation** : *const Eigen::Quaternionf &*
  User rotation.

- **dx** : *double*
  Horizontal pointer motion in pixels.

- **dy** : *double*
  Vertical pointer motion in pixels.

- **degrees_per_pixel** : *float*
  Speed.

**Returns:**

- *Eigen::Quaternionf* — The new, normalised user rotation.

---

### panned(pan, dx, dy, scene_size)

Pans by a pointer drag: 0.002 scene sizes per pixel, the scene following the pointer.

**Parameters:**

- **pan** : *const Eigen::Vector2f &*
  Pan offset.

- **dx** : *double*
  Horizontal pointer motion in pixels.

- **dy** : *double*
  Vertical pointer motion in pixels.

- **scene_size** : *float*
  Extent of the scene.

**Returns:**

- *Eigen::Vector2f* — The new pan offset.
