# ViewAnimator

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/view_animator.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/view_animator.h)

`#include <mne/viz/view_animator.h>`

```cpp
class mne::viz::ViewAnimator
```

Runs the scroll and zoom animations a [`TraceView`](/docs/api/viz/trace-view) asks for, without timers.

The host starts the animations from the view's animate_scroll and animate_zoom effects, stops the scroll animation on stop_animations, and calls `tick()` with the current time for every frame (or from a timer) while it returns true. Animations use the cubic ease-out curve f(t) = 1 - (1 - t)^3, whose initial speed is three times the mean speed: an inertial glide of duration T over a distance v T / 3 starts at speed v.

There is at most one scroll animation (a requested scroll or an inertial glide) and one zoom animation; starting one replaces the running one of its kind.

## Public Methods

### start_scroll(animation, now_ms)

### tick(now_ms, view)

Sets the animated values of `view` for `now_ms` and ends the animations that reached their end; a finished requested scroll (not a glide) is reported with `TraceView::scroll_animation_finished()`.

**Parameters:**

- **now_ms** : *std::int64_t*
  Time.

- **view** : *[TraceView](/docs/api/viz/trace-view) &*
  The animated view.

**Returns:**

- *bool* — Whether an animation still runs, i.e. more frames are needed.
