# ItemList

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/models/item_list.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/models/item_list.h)

`#include <mne/viz/item_list.h>`

```cpp
class mne::viz::ItemList
```

Toolkit-free model of a list view: its items, which of them are selected, and whether the user may remove them.

Panels hold item lists and hosts show them, e.g. [`ItemListView`](/docs/api/viz-qt/item-list-view) in Qt and [`FormView`](/docs/api/viz/form-view) without a toolkit. The selection follows the clicks of a list view: in Single mode a click selects one item; in Multi mode a click selects one item and a click with `extend` (Ctrl held) toggles it. Removable lists drop their selected items, except the protected ones, when the user presses Delete.

```cpp title="src/examples/ex_scene_sdl/main.cpp"
// The Vectorview layout and the mne_browse_raw groups of the installed resources
ChannelSelectionPanel panel;
ChannelSelectionPanel::Callbacks callbacks;
callbacks.channels_shown = [](const std::vector<std::string>& channels) {
    std::printf("Showing %zu channels\n", channels.size());
};
panel.set_callbacks(std::move(callbacks));
panel.set_mapped_channels({"MEG 0111", "MEG 0112", "MEG 0113", "MEG 0121"});
panel.select_channels({"MEG 0112"});

// Any panel's lists, without a view written for them
FormView view(panel);
view.set_text_metrics(&metrics);
return host.run(view);
```

### click(row, extend)

Changes the selection as a click on `row` does; a row outside the list clears the selection.

**Parameters:**

- **row** : *int*
  Row clicked.

- **extend** : *bool*
  Toggle the row instead of selecting only it (Multi mode, Ctrl held).
