# SensorLayout

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/figures/sensor_layout.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/figures/sensor_layout.h)

`#include <mne/viz/sensor_layout.h>`

```cpp
class mne::viz::SensorLayout
```

Sensors of a 2-D layout (an .lout file) as labelled dots, with their selection.

A sensor at layout position (x, y) sits at (10 x, -10 y) in scene coordinates, y pointing down. Hidden sensors are neither drawn nor hit; sensors that cannot be selected are drawn faint. Clicks and rubber bands change the selection as in a QGraphicsScene: without `extend` they replace it, with `extend` (Ctrl held) a click toggles one sensor and a band adds to the selection.

```cpp title="src/examples/ex_scene/main.cpp"
// Three sensors of an .lout layout; the click selects the middle one, as in the channel selection view
SensorLayout sensors;
sensors.set_sensors({{"MEG 0111", {0.0, 0.0}}, {"MEG 0121", {6.0, 0.0}}, {"MEG 0131", {12.0, 0.0}}});
sensors.click(sensors.scene_position(1), false);
Canvas sensorCanvas(240, 100, Color::white());
sensorCanvas.translate(40, 60);
sensors.draw(sensorCanvas, metrics, Font{"", 0.0, 13.0});
```

### click(point, extend)

Changes the selection as a click at `point` does.

- **point** : *[Point](/docs/api/viz/point)*
  [`Point`](/docs/api/viz/point) in scene coordinates.

- **extend** : *bool*

**Returns:**

- *bool* — Whether the selection changed.

### select_in(band, extend)

**Parameters:**

- **band** : *const [Rect](/docs/api/viz/rect) &*

- **extend** : *bool*
  Add to the selection instead of replacing it (Ctrl held).

**Returns:**

- *bool* — Whether the selection changed.

---

### select_names(names)
