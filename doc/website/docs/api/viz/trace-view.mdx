# TraceView

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/views/trace_view.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/views/trace_view.h)

`#include <mne/viz/trace_view.h>`

```cpp
class mne::viz::TraceView
```

Viewport and interaction state of a raw-data trace view, without a GUI toolkit.

[`TraceView`](/docs/api/viz/trace-view) knows which samples and channel rows a view of a given size shows, handles pointer and wheel input (wheel zoom and scrolling, drag scrolling with inertia, the right-button ruler, annotation range selection and boundary resizing, the crosshair) and draws the overlays on top of the traces (crosshair, scalebars, ruler and annotation selection) into a [`Canvas`](/docs/api/viz/canvas). It does not animate or render traces: what the host has to do is reported through `Effects`, e.g. animate a scroll, change the cursor or redraw.

Positions are logical (device-independent) pixels with x = 0 at the left edge of the traces.

## Used in examples

### [ex_scene_sdl](../../examples/viz/ex_scene_sdl.mdx)

Trace view in an SDL3 window, without Qt: mne_scene's view and software renderer in another toolkit.

````cpp title="src/examples/ex_scene_sdl/main.cpp, line 198"
TraceViewClient client;
client.style().background = Color{250, 250, 250};
TraceView& view = client.view();
view.set_sfreq(kSfreq);
view.set_first_file_sample(0);
view.set_visible_channel_count(16);
view.set_samples_per_pixel(5.0);
view.set_scalebars_visible(true);
client.set_source(&buffer);
````
