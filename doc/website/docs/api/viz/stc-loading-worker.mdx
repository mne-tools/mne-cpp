# StcLoadingWorker

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/realtime/stcloadingworker.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/realtime/stcloadingworker.h)

`#include <mne/viz/stcloadingworker.h>`

```cpp
class mne::viz::StcLoadingWorker
```

[`StcLoadingWorker`](/docs/api/viz/stc-loading-worker) performs source estimate loading and interpolation matrix computation in a background thread to avoid blocking the UI.

Background worker that loads source estimate (STC) files and emits loaded data for visualization.

---

## Public Methods

### StcLoadingWorker(lhPath, rhPath, lhSurface, rhSurface, cancelDist)

Constructor.

**Parameters:**

- **lhPath** : *const std::filesystem::path &*
  Path to left hemisphere STC file.

- **rhPath** : *const std::filesystem::path &*
  Path to right hemisphere STC file.

- **lhSurface** : *[BrainSurface](/docs/api/viz/brain-surface) **
  Pointer to left hemisphere surface.

- **rhSurface** : *[BrainSurface](/docs/api/viz/brain-surface) **
  Pointer to right hemisphere surface.

- **cancelDist** : *double*
  Cancel distance for interpolation.
