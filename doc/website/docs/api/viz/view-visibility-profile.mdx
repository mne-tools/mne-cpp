# ViewVisibilityProfile

**Namespace:** `mne::viz` &nbsp;·&nbsp; **Library:** Visualization Library &nbsp;·&nbsp; **Source:** [`viz/brain/viewstate.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/viz/brain/viewstate.h)

`#include <mne/viz/viewstate.h>`

```cpp
struct mne::viz::ViewVisibilityProfile
```

Per-view toggle flags controlling which data layers (brain, sensors, sources, network) are visible.

Per-object visibility flags for a single viewport.

Every viewport (single-view or multi-view pane) carries an independent visibility profile so that each pane can show a different combination of objects.

```cpp title="src/examples/ex_disp3d_scene/main.cpp"
// A pane's camera, shaders and layer visibility survive a restart through any SettingsStore
MemorySettingsStore viewSettings; // QtSettingsStore puts the same keys into a QSettings
SubView pane = SubView::defaultForIndex(2);
pane.surfaceType = "inflated";
pane.visibility.setObjectVisible("dipoles", false);
pane.save(viewSettings, "multi2_");
SubView restored;
restored.load(viewSettings, "multi2_");
```
