# AverageLayout

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/average_layout.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/average_layout.h)

`#include <mne/scene/average_layout.h>`

```cpp
class mne::scene::AverageLayout
```

The evoked responses of many channels, each in a tile at its place in a sensor layout.

A channel at layout position (x, y) gets a 120 x 60 box centred on (160 x, -160 y) in scene coordinates, y pointing down, as MNE-Python's plot_evoked_topo arranges them.

```cpp title="src/examples/ex_scene/main.cpp"
// One tile per channel at its layout position, as plot_evoked_topo arranges them
AverageTile tile;
tile.box = AverageLayout::box_at({0.5, 0.25});
tile.name = "EEG 001";
tile.columns = 100;
tile.traces.push_back({std::vector<double>(100, 0.5), Color{0, 80, 180}});
AverageLayout topo;
topo.set_tiles({tile});
```
