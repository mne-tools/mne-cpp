# SoftwareBindings

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/software_renderer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/software_renderer.h)

`#include <mne/scene/software_renderer.h>`

```cpp
class mne::scene::SoftwareBindings
```

The uniform blocks and textures of a draw as a software shader reads them.

---

## Public Methods

### uniforms(binding)

**Parameters:**

- **binding** : *int*
  Binding number of the uniform block.

**Returns:**

- *T* — The block as `T`, the bytes missing from the draw's block (or of a missing block) zero.

---

### sample(binding, uv)

Samples a texture with clamp-to-edge addressing and the texture's filter.

**Parameters:**

- **binding** : *int*
  Binding number of the sampler.

- **uv** : *const Eigen::Vector2f &*
  Texture coordinates, (0, 0) at the top left of the image.

**Returns:**

- *Eigen::Vector4f* — RGBA from 0 to 1, or transparent black for a missing texture.
