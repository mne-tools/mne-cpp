# TraceSource

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/trace_view.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/trace_view.h)

`#include <mne/scene/trace_view.h>`

```cpp
class mne::scene::TraceSource
```

The channels a [`TraceView`](/docs/api/scene/trace-view) shows, as the view needs them for its overlays and its channel window.

Channels are addressed by their logical index: the position in the list of channels the view scrolls through, after any channel filter of the host.
