# ViewAnimator

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/view_animator.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/view_animator.h)

`#include <mne/scene/view_animator.h>`

```cpp
class mne::scene::ViewAnimator
```

Runs the scroll and zoom animations a [`TraceView`](/docs/api/scene/trace-view) asks for, without timers.

The host starts the animations from the view's animate_scroll and animate_zoom effects, stops the scroll animation on stop_animations, and calls `tick()` with the current time for every frame (or from a timer) while it returns true. Animations use the cubic ease-out curve f(t) = 1 - (1 - t)^3, whose initial speed is three times the mean speed: an inertial glide of duration T over a distance v T / 3 starts at speed v.

There is at most one scroll animation (a requested scroll or an inertial glide) and one zoom animation; starting one replaces the running one of its kind.

## Public Methods

### start_scroll(animation, now_ms)

Starts a scroll animation, replacing a running one.

**Parameters:**

- **animation** : *const [TraceView](/docs/api/scene/trace-view)::ScrollAnimation &*
  The scroll the view asked for.

- **now_ms** : *std::int64_t*

### tick(now_ms, view)

Sets the animated values of `view` for `now_ms` and ends the animations that reached their end; a finished requested scroll (not a glide) is reported with `TraceView::scroll_animation_finished()`.

**Parameters:**

- **now_ms** : *std::int64_t*
  Time.

- **view** : *[TraceView](/docs/api/scene/trace-view) &*
  The animated view.

**Returns:**

- *bool* — Whether an animation still runs, i.e. more frames are needed.

## Used in examples

### [ex_scene_sdl](../../examples/scene/ex_scene_sdl.mdx)

Trace view in an SDL3 window, without Qt: mne_scene's view and software renderer in another toolkit.

````cpp title="src/examples/ex_scene_sdl/main.cpp, line 181"
TraceView view;
ViewAnimator animator;
TraceFrameBuilder builder;
bool followEnd = true;
bool following = false; // the scroll below is the example's, not the user's
TraceView::Effects effects;
effects.animate_scroll = [&](const TraceView::ScrollAnimation& animation) {
    animator.start_scroll(animation, static_cast<std::int64_t>(SDL_GetTicks()));
};
effects.animate_zoom = [&](const TraceView::ZoomAnimation& animation) {
    animator.start_zoom(animation, static_cast<std::int64_t>(SDL_GetTicks()));
};
effects.stop_animations = [&] {
    animator.stop_scroll();
````
