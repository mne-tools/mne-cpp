# TraceMarkers

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/trace_markers.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/trace_markers.h)

`#include <mne/scene/trace_markers.h>`

```cpp
class mne::scene::TraceMarkers
```

`Event` and epoch markers of a trace view, and the drawing of all time markers.

Draws, on a time axis given by a first sample and a scale, the annotation spans (a translucent band with border lines and a label pill), the event lines and the dashed epoch trigger lines. The GPU trace view paints this into a texture wider than the view; the image export draws it between the grid and the traces (annotations) and on top of the traces (events and epochs).

### draw_annotations(canvas, metrics, font, annotations, first_sample, pixels_per_sample)

**Parameters:**

  Measures the labels.
