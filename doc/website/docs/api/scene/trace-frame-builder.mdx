# TraceFrameBuilder

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/trace_frame.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/trace_frame.h)

`#include <mne/scene/trace_frame.h>`

```cpp
class mne::scene::TraceFrameBuilder
```

Describes the frames of a trace view as [`GpuFrame`](/docs/api/scene/gpu-frame) for any backend.

One pass clears to the background and draws one line strip per trace (shader "channeldata"), then the annotations, events and epoch markers with the per-second bands (shader "overlay" over a texture that spans `overlay_prefetch()` view widths on each side, so scrolling does not redraw it), then the crosshair, scalebars, ruler and annotation selection (shader "overlay" over a screen-sized texture). The builder keeps the vertex buffers, textures and pipelines in `resources()` and streams vertices through its [`TraceGeometry`](/docs/api/scene/trace-geometry).

### build(view, source, style, markers, metrics, target)

Describes the next frame; streams vertices and redraws the textures as needed.

**Parameters:**

- **view** : *const [TraceView](/docs/api/scene/trace-view) &*
  Viewport, overlays and annotations.

- **source** : *const [TraceSource](/docs/api/scene/trace-source) &*
  The channels.

- **style** : *const [TraceStyle](/docs/api/scene/trace-style) &*
  Colours and scales; the background is the clear colour, grid the per-second bands.

- **markers** : *const [TraceMarkers](/docs/api/scene/trace-markers) &*
  Events and epoch markers.

- **metrics** : *const [TextMetrics](/docs/api/scene/text-metrics) &*
  Measures the text of the overlays.

- **target** : *const [GpuFrameTarget](/docs/api/scene/gpu-frame-target) &*
  Size and pixel ratio of the target.

**Returns:**

- *[GpuFrame](/docs/api/scene/gpu-frame)* — The frame, referring to `resources()`.

## Used in examples

### [ex_scene_sdl](../../examples/scene/ex_scene_sdl.mdx)

Trace view in an SDL3 window, without Qt: mne_scene's view and software renderer in another toolkit.

````cpp title="src/examples/ex_scene_sdl/main.cpp, line 181"
TraceView view;
ViewAnimator animator;
TraceFrameBuilder builder;
bool followEnd = true;
bool following = false; // the scroll below is the example's, not the user's
TraceView::Effects effects;
effects.animate_scroll = [&](const TraceView::ScrollAnimation& animation) {
    animator.start_scroll(animation, static_cast<std::int64_t>(SDL_GetTicks()));
};
effects.animate_zoom = [&](const TraceView::ZoomAnimation& animation) {
    animator.start_zoom(animation, static_cast<std::int64_t>(SDL_GetTicks()));
};
effects.stop_animations = [&] {
    animator.stop_scroll();
````
