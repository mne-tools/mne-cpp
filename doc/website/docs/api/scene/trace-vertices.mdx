# TraceVertices

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/trace_source.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/trace_source.h)

`#include <mne/scene/trace_source.h>`

```cpp
struct mne::scene::TraceVertices
```

Vertices of one channel trace over a sample window.

`xy` holds interleaved (x, y) pairs: x is the sample offset from `first_sample` (fractional for decimated traces), y the value in physical units. This is the vertex layout of the trace shader (vec2 per vertex, drawn as a line strip).
