# Rect

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/geometry.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/geometry.h)

`#include <mne/scene/geometry.h>`

```cpp
struct mne::scene::Rect
```

An axis-aligned rectangle given by its top-left corner and its size.

### adjusted(dx1, dy1, dx2, dy2)

**Parameters:**

- **dy2** : *double*
