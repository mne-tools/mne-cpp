# TraceUniforms

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/trace_geometry.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/trace_geometry.h)

`#include <mne/scene/trace_geometry.h>`

```cpp
struct mne::scene::TraceUniforms
```

Shader parameters of one drawn trace.

The layout is the uniform block of channeldata.vert / channeldata.frag (std140, 52 bytes): copy the struct as is into a uniform buffer slot.

---

## Example

No example of its own: Plain uniform-block value type produced by TraceGeometry::draws() and copied into a GPU buffer.
