# WheelEvent

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/input_event.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/input_event.h)

`#include <mne/scene/input_event.h>`

```cpp
struct mne::scene::WheelEvent
```

A wheel or two-finger scroll event.

The angle deltas follow the convention of most toolkits: one notch of a mouse wheel is 120 (eighths of a degree), positive y scrolls up (away from the user) and positive x scrolls left.

---

## Example

No example of its own: Toolkit-neutral input value type passed to TraceView::handle_wheel(); hosts convert their native events to it.
