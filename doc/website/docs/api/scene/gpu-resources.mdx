# GpuResources

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/gpu_frame.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/gpu_frame.h)

`#include <mne/scene/gpu_frame.h>`

```cpp
class mne::scene::GpuResources
```

Buffers, textures and pipelines a view keeps across frames.

A handle stays valid until its resource is released and is not reused by the store, so a backend can keep one GPU object per handle and upload again when the revision changed.

---

## Public Methods

### create_buffer(usage)

Adds an empty buffer.

**Parameters:**

- **usage** : *GpuBufferUsage*
  What the buffer holds.

**Returns:**

- *GpuHandle* — The handle.

---

### set_buffer_data(buffer, bytes)

Replaces the contents of a buffer.

**Parameters:**

- **buffer** : *GpuHandle*
  Handle of a buffer of this store; others are ignored.

- **bytes** : *std::span&lt; const std::byte &gt;*
  New contents.

---

### set_buffer_values(buffer, values)

Replaces the contents of a buffer with trivially copyable values.

**Parameters:**

- **buffer** : *GpuHandle*
  Handle of a buffer of this store; others are ignored.

- **values** : *std::span&lt; const T &gt;*
  New contents.

### create_texture(texture)

Adds a texture.

**Parameters:**

- **texture** : *[GpuTexture](/docs/api/scene/gpu-texture)*

**Returns:**

- *GpuHandle* — The handle.

---

### set_texture(texture, content, scale)

Replaces the contents of a texture and keeps its filter.

**Parameters:**

- **texture** : *GpuHandle*
  Handle of a texture of this store; others are ignored.

- **content** : *std::variant&lt; [Image](/docs/api/scene/image), [DisplayList](/docs/api/scene/display-list) &gt;*
  Pixels or a figure.

- **scale** : *double*
  Texture pixels per figure pixel of a figure.

### create_pipeline(pipeline)

### release(handle)

Releases a buffer, texture or pipeline; its handle becomes invalid.

**Parameters:**

- **handle** : *GpuHandle*
  Handle; 0 and unknown handles are ignored.
