# Font

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/style.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/style.h)

`#include <mne/scene/style.h>`

```cpp
struct mne::scene::Font
```

A font request; a backend picks the closest font it has.

[`Point`](/docs/api/scene/point) sizes are converted with the backend's resolution, pixel sizes are exact. With neither size set, the backend uses its default font size.
