# SweepBuffer

**Namespace:** `mne::scene` &nbsp;·&nbsp; **Library:** Scene Library &nbsp;·&nbsp; **Source:** [`scene/sweep_buffer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/scene/sweep_buffer.h)

`#include <mne/scene/sweep_buffer.h>`

```cpp
class mne::scene::SweepBuffer
```

The sweeping window of a real-time raw-data view: new samples overwrite the oldest from the left.

Holds a raw and a filtered layer of channels x window samples, written column by column at the write position, which wraps to column 0 at the end of the window and starts a new sweep. Left of the write position is the current sweep, from it on the previous one. Freezing keeps a copy of both layers and of the write position for display while writing goes on.

---

## Public Methods

### resize(channels, window, zero)

Resizes the layers, keeping the stored values that remain.

If the write position lies beyond the new window, a new sweep starts.

**Parameters:**

- **channels** : *int*
  Number of channels.

- **window** : *int*
  Samples per sweep.

- **zero** : *bool*
  Zero the layers and the first values.

---

### window()

**Returns:**

- *int* — Samples per sweep (1024 until resized).

---

### write(count, on_new_sweep, piece)

Writes `count` samples at the write position: calls `on_new_sweep` when the write position wraps to column 0 (after the sweep has started) and `piece` (column, offset, length) for each contiguous piece, which writes the samples [offset, offset + length) of the block to the layers at column.

**Parameters:**

- **count** : *int*
  Samples in the block.

- **on_new_sweep** : *OnNewSweep*
  Called when a new sweep starts.

- **piece** : *Piece*
  Writes a piece of the block.

---

### raw()

**Returns:**

- *Matrix &* — The raw layer being written.

---

### filtered()

**Returns:**

- *Matrix &* — The filtered layer being written.

---

### layer(filtered)

Returns the layer to display: the frozen copy while frozen.

**Parameters:**

- **filtered** : *bool*
  The filtered layer, else the raw one.

**Returns:**

- *const Matrix &* — The layer.

---

### last_block(filtered)

Returns the last written block, unwrapped.

**Parameters:**

- **filtered** : *bool*
  From the filtered layer, else from the raw one.

**Returns:**

- *Eigen::MatrixXd* — Channels x block samples.

---

### first_value(row, filtered)

Returns a channel's value in column 0 when the current sweep started (kept while frozen).

**Parameters:**

- **row** : *int*
  Channel.

- **filtered** : *bool*
  Of the filtered layer, else of the raw one.

**Returns:**

- *double* — The value, 0 for an unknown channel.

---

### sample_at_column(column)

Returns the absolute sample shown at a column of the window.

**Parameters:**

- **column** : *int*
  Column of the window.

**Returns:**

- *int* — The sample, -1 outside the window or before the first sample.

---

### set_frozen(frozen)

Freezes or thaws the display; freezing copies the layers and the write position.

**Parameters:**

- **frozen** : *bool*
  Whether to freeze.

---

### frozen()

**Returns:**

- *bool* — Whether the display is frozen.

---

### write_position()

**Returns:**

- *int* — The column the next sample is written to (the window size at the end of a sweep).

---

### frozen_write_position()

**Returns:**

- *int* — The write position when the display was frozen.

---

### sweep_start()

**Returns:**

- *int* — The absolute sample at column 0 of the current sweep.

---

### block_size()

**Returns:**

- *int* — The number of samples of the last written block (at most the window).

---

### clear()

Zeroes the layers, their frozen copies and the first values.

---
