# MnaParamBinding

**Namespace:** `MNALIB` &nbsp;·&nbsp; **Library:** MNA Library

`#include <mna/mna_param_binding.h>`

```cpp
struct MNALIB::MnaParamBinding
```

A formula-driven parameter binding: links a target parameter path to an expression that is re-evaluated when a trigger condition is met.

Dynamic parameter binding for the MNA parameter tree.

```cpp title="src/examples/ex_mna/main.cpp"
graph.paramTree.setParam("shift/offset", 0.5);
MnaParamBinding binding;
binding.targetPath = "scale/gain";
binding.expression = "clamp(ref('source::out') * 2, 0, 5)"; // evaluated against node results
binding.trigger = "on_change";
graph.paramTree.addBinding(binding);
```
