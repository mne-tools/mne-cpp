# MnaParamBinding

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_param_binding.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mna/mna_param_binding.h)

`#include <mne/mna/mna_param_binding.h>`

```cpp
struct mne::MnaParamBinding
```

Formula that recomputes one parameter of an [`MnaParamTree`](/docs/api/mna/mna-param-tree).

Dynamic parameter binding for the MNA parameter tree.

```cpp title="src/examples/ex_mna/main.cpp"
graph.param_tree.set_param("shift/offset", 0.5);
MnaParamBinding binding;
binding.target_path = "scale/gain";
binding.expression = "clamp(ref('source::out') * 2, 0, 5)"; // evaluated against node results
binding.trigger = "on_change";
graph.param_tree.add_binding(binding);
```
