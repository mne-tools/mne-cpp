# MnaVerification

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_verification.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mna/mna_verification.h)

`#include <mne/mna/mna_verification.h>`

```cpp
struct mne::MnaVerification
```

Top-level verification container attached to each [`MnaNode`](/docs/api/mna/mna-node).

Combines human-readable explanation, declarative checks, evaluation results, and a complete provenance snapshot.

Verification, explanation, and provenance for a graph node.

```cpp title="src/examples/ex_mna/main.cpp"
MnaVerification& checks = graph.node("shift").verification;
checks.explanation = "Adds the offset; the result must stay positive.";
MnaVerificationCheck positive;
positive.id = "out_positive";
positive.description = "Output is positive";
positive.phase = "post";         // "pre" sees attributes and inputs, "post" also outputs
positive.expression = "out > 0"; // or MnaScript code whose exit code 0 passes
positive.severity = "error";     // a failed "error" check stops the run
checks.checks.push_back(positive);
graph.node("source").attributes["value"] = -2.0;
graph.node("source").dirty = true;
MnaGraphExecutor::execute_incremental(graph, ctx);
const MnaVerificationResult& verdict = checks.post_results.front();
const MnaProvenance& provenance = checks.provenance; // versions, host, input SHA-256, timing
```
