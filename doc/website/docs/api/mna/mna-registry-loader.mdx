# MnaRegistryLoader

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_registry_loader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mna/mna_registry_loader.h)

`#include <mna/mna_registry_loader.h>`

```cpp
class mne::MnaRegistryLoader
```

Reads op-schema manifests ("mna_registry_version", "provider", "ops") into an [`MnaOpRegistry`](/docs/api/mna/mna-op-registry).

Reads MNA op-schema manifests and feeds them into [`MnaOpRegistry`](/docs/api/mna/mna-op-registry), with drop-in directory merge support.

```cpp title="src/examples/ex_mna/main.cpp"
MnaOpRegistry& registry = MnaOpRegistry::instance();
const int nLoaded = MnaRegistryLoader::load_file(registryFile, registry); // schemas only
registry.register_op_func("ex_constant", [](const MnaValues&, const JsonObject& attrs) -> MnaValues {
    return {{"out", attrs["value"].to_double()}};
});
registry.register_op_func("ex_affine", [](const MnaValues& inputs, const JsonObject& attrs) -> MnaValues {
    return {{"out", attrs["gain"].to_double(1.0) * std::any_cast<double>(inputs.at("in")) + attrs["offset"].to_double(0.0)}};
});
```

## Static Methods

### load_file(path, registry)

**Parameters:**

- **path** : *const std::filesystem::path &*
  A manifest file.

- **registry** : *[MnaOpRegistry](/docs/api/mna/mna-op-registry) &*
  Receives the schemas.

**Returns:**

- *int* — The number of schemas loaded, or -1 if the file cannot be read or is not a manifest.

---

### load_directory(dir, registry)

Loads mna-registry.json and then every *.json in mna-registry.d/ in name order, so drop-ins override.

**Parameters:**

- **dir** : *const std::filesystem::path &*
  The registry directory.

- **registry** : *[MnaOpRegistry](/docs/api/mna/mna-op-registry) &*
  Receives the schemas.

**Returns:**

- *int* — The number of schemas loaded.

---

### save_file(path, provider, registry)

**Parameters:**

- **path** : *const std::filesystem::path &*
  The manifest file to write.

- **provider** : *std::string_view*
  Who provides the operations.

- **registry** : *const [MnaOpRegistry](/docs/api/mna/mna-op-registry) &*
  The schemas to write.

**Returns:**

- *bool* — Whether the file was written.
