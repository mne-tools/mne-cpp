# MnaGraph

**Namespace:** `MNALIB` &nbsp;·&nbsp; **Library:** MNA Library

`#include <mna/mna_graph.h>`

```cpp
class MNALIB::MnaGraph
```

Directed acyclic graph of processing nodes forming a computational pipeline.

In-memory DAG of `MnaNode` operations with validation, topological sort and JSON/CBOR persistence.

```cpp title="src/examples/ex_mna/main.cpp"
MnaGraph graph;
MnaNode source;
source.id = "source";
source.opType = "ex_constant";
source.attributes["value"] = 3.0;
source.outputs.append(port("out", MnaPortDir::Output));
graph.addNode(source);

for (const QString& id : {QStringLiteral("scale"), QStringLiteral("shift")}) {
    MnaNode node;
    node.id = id;
    node.opType = "ex_affine";
    node.inputs.append(port("in", MnaPortDir::Input));
    node.outputs.append(port("out", MnaPortDir::Output));
    graph.addNode(node);
}
graph.node("scale").attributes["gain"] = 2.0;
graph.connect("source", "out", "scale", "in");
graph.connect("scale", "out", "shift", "in");
```

### connect(srcNodeId, srcPortName, dstNodeId, dstPortName)

Connect output port of srcNode to input port of dstNode.

Sets the sourceNodeId and sourcePortName on the destination input port.

**Parameters:**

- **srcNodeId** : *const QString &*
  Id of the node providing the output.

- **srcPortName** : *const QString &*
  Name of the output port on the source node.

- **dstNodeId** : *const QString &*
  Id of the node receiving the input.

- **dstPortName** : *const QString &*
  Name of the input port on the destination node.

**Returns:**

- *bool* — true if connection was made, false if ports not found.
