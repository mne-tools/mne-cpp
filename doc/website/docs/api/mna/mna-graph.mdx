# MnaGraph

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_graph.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mna/mna_graph.h)

`#include <mna/mna_graph.h>`

```cpp
class mne::MnaGraph
```

Directed acyclic graph of processing nodes forming a computational pipeline.

In-memory DAG of [`MnaNode`](/docs/api/mna/mna-node) operations with validation, topological sort and JSON/CBOR persistence.

```cpp title="src/examples/ex_mna/main.cpp"
MnaGraph graph;
MnaNode source;
source.id = "source";
source.op_type = "ex_constant";
source.attributes["value"] = 3.0;
source.outputs.push_back(port("out", MnaPortDir::Output)); // name, data kind, direction
graph.add_node(source);

for (const char* id : {"scale", "shift"}) {
    MnaNode node;
    node.id = id;
    node.op_type = "ex_affine";
    node.inputs.push_back(port("in", MnaPortDir::Input));
    node.outputs.push_back(port("out", MnaPortDir::Output));
    graph.add_node(std::move(node));
}
graph.node("scale").attributes["gain"] = 2.0;
graph.connect("source", "out", "scale", "in");
graph.connect("scale", "out", "shift", "in");
```

### connect(src_node_id, src_port_name, dst_node_id, dst_port_name)

Connects an output port of one node to an input port of another by setting the source of the input port.

**Parameters:**

- **src_node_id** : *std::string_view*
  Id of the node providing the output.

- **src_port_name** : *std::string_view*
  Name of the output port on the source node.

- **dst_node_id** : *std::string_view*
  Id of the node receiving the input.

- **dst_port_name** : *std::string_view*
  Name of the input port on the destination node.

**Returns:**

- *bool* — Whether both ports exist and were connected.
