# MnaPort

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_port.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mna/mna_port.h)

`#include <mna/mna_port.h>`

```cpp
struct mne::MnaPort
```

Typed input/output slot on a graph node.

Named, typed port on an MNA graph node with upstream link and optional real-time stream binding.

```cpp title="src/examples/ex_mna/main.cpp"
MnaGraph graph;
MnaNode source;
source.id = "source";
source.op_type = "ex_constant";
source.attributes["value"] = 3.0;
source.outputs.push_back(port("out", MnaPortDir::Output)); // name, data kind, direction
graph.add_node(source);

for (const char* id : {"scale", "shift"}) {
    MnaNode node;
    node.id = id;
    node.op_type = "ex_affine";
    node.inputs.push_back(port("in", MnaPortDir::Input));
    node.outputs.push_back(port("out", MnaPortDir::Output));
    graph.add_node(std::move(node));
}
graph.node("scale").attributes["gain"] = 2.0;
graph.connect("source", "out", "scale", "in");
graph.connect("scale", "out", "shift", "in");
```
