# MnaGraphExecutor

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_graph_executor.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mna/mna_graph_executor.h)

`#include <mna/mna_graph_executor.h>`

```cpp
class mne::MnaGraphExecutor
```

Executes a computational graph by traversing nodes in topological order and invoking registered operation functions, external programs (IPC nodes) or interpreters (Script nodes).

Results are stored as "nodeId::portName"; graph inputs as "graph::portName". Checks and parameter bindings see the scalar values among them (numbers, booleans, text); \{\{name\}\} placeholders in IPC arguments and scripts are replaced by the text of a node input or attribute.

Stateless batch and stream-mode runner for an [`MnaGraph`](/docs/api/mna/mna-graph).

```cpp title="src/examples/ex_mna/main.cpp"
MnaGraphExecutor::Context ctx = MnaGraphExecutor::execute(graph);
const double first = number(ctx.results, "shift::out"); // "nodeId::port"
const double gainAfterFirst = graph.param_tree.param("scale/gain").to_double();

graph.node("source").attributes["value"] = 1.0;
graph.node("source").dirty = true; // only source and its downstream nodes run again
MnaGraphExecutor::execute_incremental(graph, ctx);
const double second = number(ctx.results, "shift::out");
```

## Static Methods

### execute(graph, graph_inputs)

Executes the full graph in topological order.

**Parameters:**

- **graph** : *[MnaGraph](/docs/api/mna/mna-graph) &*
  The graph; parameter bindings and node verification are updated.

- **graph_inputs** : *const MnaValues &*
  Named inputs fed into graph-level input ports.

**Returns:**

- *Context* — The execution context with all results.

---

### execute_incremental(graph, context)

Executes only dirty nodes and their downstream dependents.

**Parameters:**

- **graph** : *[MnaGraph](/docs/api/mna/mna-graph) &*
  The graph.

- **context** : *Context &*
  Prior results; updated with the new ones.

---

### execute_node(node, inputs)

Executes a single node.

**Parameters:**

- **node** : *const [MnaNode](/docs/api/mna/mna-node) &*
  The node.

- **inputs** : *const MnaValues &*
  Input values keyed by port name.

**Returns:**

- *MnaValues* — Output values keyed by port name; IPC and Script nodes give "stdout", "stderr" (std::string) and "exit_code" (int, -1 if the program did not run to completion).

---

### set_progress_callback(callback)

**Parameters:**

- **callback** : *ProgressCallback*
  Progress callback; an empty callback disables reporting.

---

### start_stream(graph, factory)

Starts stream-mode execution: validates the graph, sorts it, applies the parameter tree and creates a live plugin per node.

Wiring the plugins together is up to the host application.

**Parameters:**

- **graph** : *[MnaGraph](/docs/api/mna/mna-graph) &*
  The pipeline graph.

- **factory** : *const PluginFactory &*
  Creates the live plugin of an op type.

**Returns:**

- *StreamContext* — The stream context; running tells whether startup succeeded.

---

### stop_stream(context)

Stops a running stream, releasing the plugins in reverse topological order.

**Parameters:**

- **context** : *StreamContext &*
  The stream context.
