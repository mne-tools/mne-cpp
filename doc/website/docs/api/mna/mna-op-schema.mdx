# MnaOpSchema

**Namespace:** `MNALIB` &nbsp;·&nbsp; **Library:** MNA Library

`#include <mna/mna_op_schema.h>`

```cpp
class MNALIB::MnaOpSchema
```

Contract declaring an operation's expected inputs, outputs, and attributes.

Operation schema for graph validation.

```cpp title="src/examples/ex_mna/main.cpp"
QStringList problems;
const bool nodeValid = registry.schema("ex_affine").validate(graph.node("scale"), &problems);
MnaNode unset = graph.node("source");
unset.attributes.clear(); // "value" is required
const bool unsetValid = registry.schema("ex_constant").validate(unset);
```

---

## Public Methods

### validate(node, errors)

Validate that a node conforms to this schema.

**Parameters:**

- **node** : *const [MnaNode](/docs/api/mna/mna-node) &*
  Node to validate.

- **errors** : *QStringList **
  Optional list of validation error messages.

**Returns:**

- *bool* — True if the node conforms to the schema.
