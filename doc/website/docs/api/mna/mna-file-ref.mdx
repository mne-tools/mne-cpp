# MnaFileRef

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_file_ref.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mna/mna_file_ref.h)

`#include <mna/mna_file_ref.h>`

```cpp
struct mne::MnaFileRef
```

Reference to a file inside an MNA project, optionally with its content embedded.

Embedded data is base64 text in .mna (JSON) files and a byte string in .mnx (CBOR) files.

```cpp title="src/examples/ex_mna/main.cpp"
MnaFileRef raw;
raw.role = MnaFileRole::Raw;
raw.path = "sub-01/ses-01/meg/sample_audvis_raw.fif"; // relative POSIX path
raw.format = "fiff";
MnaRecording recording;
recording.id = "run-01";
recording.files.push_back(raw);
MnaSession session;
session.id = "ses-01";
session.recordings.push_back(recording);
MnaSubject subject;
subject.id = "sub-01";
subject.freesurfer_dir = "subjects/sample";
subject.sessions.push_back(session);
MnaScript report; // a script node: inline code run by an interpreter
report.language = "python";
report.code = "print({{in}})";
```

## Public Methods

### to_json()

**Returns:**

- *[JsonObject](/docs/api/base/json-object)* — The reference as a JSON object, embedded data as base64.

---

### to_cbor()

**Returns:**

- *[CborMap](/docs/api/base/cbor-map)* — The reference as a CBOR map, embedded data as a byte string.

---

### embed(file)

Embeds the content of a file: sets data, size_bytes and embedded; path is left to the caller.

**Parameters:**

- **file** : *const std::filesystem::path &*
  The file to read.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; void &gt;* — Nothing, or why the file cannot be read; the reference is unchanged then.

---

### extract(file)

Writes the embedded data to a file and turns this into a reference to it: clears data and embedded; path is left to the caller.

**Parameters:**

- **file** : *const std::filesystem::path &*
  The file to write.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; void &gt;* — Nothing, or why the file cannot be written; the reference is unchanged then.

---
