# MnaParamTree

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_param_tree.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mna/mna_param_tree.h)

`#include <mne/mna/mna_param_tree.h>`

```cpp
class mne::MnaParamTree
```

Hierarchical parameter store keyed by "nodeId/attrKey" paths, with bindings that recompute parameters from formulas.

Formulas combine numbers, true/false, 'text', names (a parameter, else a result), ref('path'), the functions clamp(v, lo, hi), scale(v, f), threshold(v, t, above, below) and lerp(a, b, t), the operators + - * / with parentheses, and one comparison (&gt;= &lt;= == != &gt; &lt;). Names may contain '.', ':' and '/', so put spaces around a division that follows a name.

Path-keyed parameter store with formula-driven dynamic bindings.

```cpp title="src/examples/ex_mna/main.cpp"
graph.param_tree.set_param("shift/offset", 0.5);
MnaParamBinding binding;
binding.target_path = "scale/gain";
binding.expression = "clamp(ref('source::out') * 2, 0, 5)"; // evaluated against node results
binding.trigger = "on_change";
graph.param_tree.add_binding(binding);
```

### evaluate(results)

Evaluates every binding that is not "manual" and stores the new values.

**Parameters:**

- **results** : *const [JsonObject](/docs/api/base/json-object) &*
  Values that names and `ref()` fall back to, e.g. "nodeId::portName" results.

**Returns:**

- *StringList* — The paths whose value changed.

---

### evaluate_expression(expression, results)

**Parameters:**

- **expression** : *std::string_view*
  A formula.

- **results** : *const [JsonObject](/docs/api/base/json-object) &*
  Values that names and `ref()` fall back to after the parameters.

**Returns:**

- *[JsonValue](/docs/api/base/json-value)* — The value of `expression`, or an undefined value if it cannot be evaluated (unknown name or function, syntax error, division by zero).
