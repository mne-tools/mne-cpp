# MnaIO

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_io.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mna/mna_io.h)

`#include <mne/mna/mna_io.h>`

```cpp
class mne::MnaIO
```

Reads and writes MNA projects: .mna files hold indented JSON, .mnx files the magic bytes "MNX1" and CBOR.

Files of another major schema version are rejected.

Reader and writer for .mna (JSON) and .mnx (CBOR) project containers.

```cpp title="src/examples/ex_mna/main.cpp"
MnaProject project;
project.name = "ex_mna";
project.subjects.push_back(subject);
project.pipeline = graph.nodes();
const std::filesystem::path jsonPath = dir / "pipeline.mna"; // UTF-8 JSON
const std::filesystem::path cborPath = dir / "pipeline.mnx"; // CBOR with an "MNX1" magic
const bool saved = project.write(jsonPath) && project.write(cborPath);
const Expected<MnaProject> fromJson = MnaProject::read(jsonPath); // or why it cannot be read
const Expected<MnaProject> fromCbor = MnaProject::read(cborPath);
```
