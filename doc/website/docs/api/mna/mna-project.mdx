# MnaProject

**Namespace:** `MNALIB` &nbsp;·&nbsp; **Library:** MNA Library

`#include <mna/mna_project.h>`

```cpp
class MNALIB::MnaProject
```

Top-level MNA project container.

Holds subjects, pipeline steps, and project metadata.

```cpp title="src/examples/ex_mna/main.cpp"
MnaProject project;
project.name = "ex_mna";
project.subjects.append(subject);
project.pipeline = graph.nodes();
const QString jsonPath = dir.filePath("pipeline.mna"); // UTF-8 JSON
const QString cborPath = dir.filePath("pipeline.mnx"); // CBOR with an "MNX1" magic
const bool saved = MnaIO::write(project, jsonPath) && MnaIO::write(project, cborPath);
const MnaProject fromJson = MnaIO::read(jsonPath);
const MnaProject fromCbor = MnaIO::read(cborPath);
```

## Public Methods

### MnaProject()

Default constructor.

---

### toJson()

Serialize to QJsonObject.

**Returns:**

- *QJsonObject* — JSON object with all project fields, subjects, pipeline nodes and preserved extras.

---

### toCbor()

Serialize to QCborMap.

**Returns:**

- *QCborMap* — CBOR map with all project fields, subjects, pipeline nodes and preserved extras.

---

## Static Methods

### fromJson(json)

Deserialize from QJsonObject.

**Parameters:**

- **json** : *const QJsonObject &*
  JSON object as produced by `toJson()`.

**Returns:**

- *[MnaProject](/docs/api/mna/mna-project)* — The project; missing keys take default values and unknown keys go to extras.

---

### fromCbor(cbor)

Deserialize from QCborMap.

**Parameters:**

- **cbor** : *const QCborMap &*
  CBOR map as produced by `toCbor()`.

**Returns:**

- *[MnaProject](/docs/api/mna/mna-project)* — The project; missing keys take default values and unknown keys go to extras.

---

### read(path)

Read an MNA project from file.

Delegates to [`MnaIO`](/docs/api/mna/mna-io).

**Parameters:**

- **path** : *const QString &*
  Path to the .mna or .mnx file.

**Returns:**

- *[MnaProject](/docs/api/mna/mna-project)* — The deserialized [`MnaProject`](/docs/api/mna/mna-project).

---

### write(project, path)

Write an MNA project to file.

Delegates to [`MnaIO`](/docs/api/mna/mna-io).

**Parameters:**

- **project** : *const [MnaProject](/docs/api/mna/mna-project) &*
  The project to write.

- **path** : *const QString &*
  Path to the .mna or .mnx file.

**Returns:**

- *bool* — True if successful.
