# MnaScript

**Namespace:** `MNALIB` &nbsp;·&nbsp; **Library:** MNA Library

`#include <mna/mna_script.h>`

```cpp
struct MNALIB::MnaScript
```

Inline script definition embedded in an [`MnaNode`](/docs/api/mna/mna-node).

When the node's execMode is Script, the executor writes the code to a temporary file, invokes the interpreter, and captures the results.

Inline interpreter-launched source code carried by a Script-mode [`MnaNode`](/docs/api/mna/mna-node).

```cpp title="src/examples/ex_mna/main.cpp"
MnaFileRef raw;
raw.role = MnaFileRole::Raw;
raw.path = "sub-01/ses-01/meg/sample_audvis_raw.fif"; // relative POSIX path
raw.format = "fiff";
MnaRecording recording;
recording.id = "run-01";
recording.files.append(raw);
MnaSession session;
session.id = "ses-01";
session.recordings.append(recording);
MnaSubject subject;
subject.id = "sub-01";
subject.freeSurferDir = "subjects/sample";
subject.sessions.append(session);
MnaScript report; // a script node: inline code run by an interpreter
report.language = "python";
report.code = "print({{in}})";
```
