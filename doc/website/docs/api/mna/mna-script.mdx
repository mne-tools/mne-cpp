# MnaScript

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** MNA Library &nbsp;·&nbsp; **Source:** [`mna/mna_script.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/mna/mna_script.h)

`#include <mne/mna/mna_script.h>`

```cpp
struct mne::MnaScript
```

Inline interpreter-launched source code carried by a Script-mode [`MnaNode`](/docs/api/mna/mna-node).

```cpp title="src/examples/ex_mna/main.cpp"
MnaFileRef raw;
raw.role = MnaFileRole::Raw;
raw.path = "sub-01/ses-01/meg/sample_audvis_raw.fif"; // relative POSIX path
raw.format = "fiff";
MnaRecording recording;
recording.id = "run-01";
recording.files.push_back(raw);
MnaSession session;
session.id = "ses-01";
session.recordings.push_back(recording);
MnaSubject subject;
subject.id = "sub-01";
subject.freesurfer_dir = "subjects/sample";
subject.sessions.push_back(session);
MnaScript report; // a script node: inline code run by an interpreter
report.language = "python";
report.code = "print({{in}})";
```
