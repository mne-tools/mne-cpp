# MatVariable

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Math Library &nbsp;·&nbsp; **Source:** [`math/mat_file.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/math/mat_file.h)


One variable of a MAT-file: its name and the matrix it holds.

The matrix is referenced, not copied.
