# AcqChannelInfo

**Namespace:** `mne` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_stream_info.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libs/mne/acq/acq_stream_info.h)

`#include <mne/acq/acq_stream_info.h>`

```cpp
struct mne::AcqChannelInfo
```

Description of one channel.

For output channels, rangeMin/rangeMax are the safety limits the encoder saturates to.

```cpp title="src/examples/ex_acq_performance/main.cpp"
AcqStreamInfo inInfo;
inInfo.name = "neural";
inInfo.format = AcqSampleFormat::Int16;
inInfo.sfreq = kSfreq;
inInfo.channels.resize(kChannels);
for (std::size_t c = 0; c < kChannels; ++c) {
    inInfo.channels[c].name = "e" + std::to_string(c);
    inInfo.channels[c].kind = AcqChannelKind::Seeg;
    inInfo.channels[c].unit = AcqUnit::Volt;
    inInfo.channels[c].scale = 0.195e-6;
}
```
