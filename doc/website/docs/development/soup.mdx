# Third-party software (SOUP)

Every third-party component that MNE-CPP builds, ships, loads at run time or is built with, as IEC 62304 calls for software of unknown provenance: version, license, purpose, what fails if it fails, and how MNE-CPP detects or contains that. The machine-readable inventory is [`doc/compliance/soup.json`](https://github.com/mne-tools/mne-cpp/blob/staging/doc/compliance/soup.json), the SBOM of the shipped components [`doc/compliance/sbom.cdx.json`](https://github.com/mne-tools/mne-cpp/blob/staging/doc/compliance/sbom.cdx.json) (CycloneDX 1.5). CI fails when a library links a third-party CMake target that the catalog does not list.

## Purpose, risk and mitigation

### Qt

- **Used by:** disp, disp3D, applications, CLI tools; not the acquisition, processing or file I/O libraries
- **Purpose:** Windows, widgets, painting, GPU rendering through QRhi, the applications' event loop.
- **If it fails:** Wrong, stale or frozen display; a crashed application. Acquired data, processing results and files do not pass through Qt.
- **Mitigation:** The libraries that acquire, process and store data build and pass their tests without Qt (Qt-free SDK job on three platforms). Qt use is ratcheted per library (audit_qt_usage.py) and per module (audit_qt_modules.py). Display tests run offscreen in CI.

### Eigen

- **Used by:** the numerical libraries: math, dsp, fwd, inv, mne, sts, connectivity, decoding
- **Purpose:** Dense and sparse linear algebra and decompositions.
- **If it fails:** Numerically wrong forward models, inverse solutions, filters or statistics without a visible error.
- **Mitigation:** Results are compared with MNE-Python on shared reference data (scripts/parity, test_crossval_*); one pinned release for every build.

### zlib

- **Used by:** base (gzip streams), fiff and mri (compressed FIFF and NIfTI)
- **Purpose:** Reading and writing gzip-compressed files.
- **If it fails:** Corrupted data when reading or writing compressed files.
- **Mitigation:** gzip's CRC-32 and length trailer reject corrupted streams; round trips of gzip streams (test_base_byte_stream) and .nii.gz files (test_mri_nifti_io).

### ONNX Runtime

- **Used by:** ml
- **Purpose:** Inference of user-supplied ONNX models.
- **If it fails:** Wrong model output; a crash inside the runtime.
- **Mitigation:** Optional; no built-in processing step depends on it. test_ml_models covers the model wrapper.

### DLPack

- **Used by:** acq (acq_dlpack.h)
- **Purpose:** Struct layout for handing sample blocks to Python and ML frameworks without a copy.
- **If it fails:** A layout mismatch with the consumer's DLPack version corrupts shared tensors.
- **Mitigation:** Plain C structs with version fields; test_acq_dlpack.

### BrainFlow

- **Used by:** acq devices (brainflow://)
- **Purpose:** Drivers of research and consumer EEG boards.
- **If it fails:** Lost, duplicated or mis-scaled samples.
- **Mitigation:** The major version is checked at load time (UnsupportedVersion otherwise); test_acq_devices runs against BrainFlow's streaming and file boards.

### liblsl

- **Used by:** test_acq_lsl
- **Purpose:** Checks that MNE-CPP's own LSL implementation reads streams of the reference implementation.
- **If it fails:** None in the product; a test that skips when it is not installed.
- **Mitigation:** Not loaded by any library or application.

### Amplifier vendor SDKs (eego SDK, TMSi SDK, g.USBamp API, BrainAmp driver)

- **Used by:** acq devices (eego://, tmsi://, gusbamp://, brainamp://)
- **Purpose:** Access to the vendor's amplifier hardware.
- **If it fails:** Lost or mis-scaled samples, wrong channel mapping.
- **Mitigation:** Every backend has a simulate=1 mode tested in CI; the vendor library is resolved at run time with explicit errors.

### Python and MNE-Python

- **Used by:** pybridge; the parity tests
- **Purpose:** User Python scripts; reference results for the parity tests.
- **If it fails:** A failing or wrong result of an optional Python script.
- **Mitigation:** Process boundary with timeouts and exit-code checks; the acquisition and processing path does not depend on it.

### Lato and Roboto fonts

- **Used by:** MNE Scan, MNE Analyze
- **Purpose:** User interface typefaces.
- **If it fails:** Appearance only.
- **Mitigation:** None needed.

### Operating system, C++ standard library and threads

- **Used by:** everything
- **Purpose:** Files, sockets, threads, real-time scheduling (avrt on Windows), the C++ standard library.
- **If it fails:** Missed real-time deadlines; socket or file errors.
- **Mitigation:** Ring overruns and device errors are counted and reported per stream; every supported platform is tested in CI.

### Build toolchain

- **Used by:** the build
- **Purpose:** Compiling, linking and documenting MNE-CPP.
- **If it fails:** Miscompilation; builds that cannot be reproduced.
- **Mitigation:** Warnings are errors with Clang, GCC and MSVC; sanitizer and coverage builds; tests on every platform; tool versions pinned in CI.
