# MNA Library API

The `mne_mna` library (namespace `mne`) implements the MNA graph-execution engine — a framework for defining, validating, serializing, and executing MEG/EEG analysis pipelines as directed acyclic graphs (DAGs). It is the runtime behind the [MNA project format](/docs/manual/mna-format).

```cmake
target_link_libraries(my_app PRIVATE mne_mna)
```

Dependencies: `mne_base` only. The library and its headers use no Qt.

## Project Model

### MnaProject

Top-level container. Holds subjects, the processing pipeline, and project metadata.

```cpp
#include <mne/mna/mna_project.h>

mne::MnaProject project;           // mna_version, created and modified are set
project.name        = "audvis_dspm";
project.description = "dSPM source localization";
```

| Member | Type | Description |
|---|---|---|
| `name` | `std::string` | Project name |
| `description` | `std::string` | Project description |
| `mna_version` | `std::string` | MNA schema version (current: `CURRENT_SCHEMA_VERSION`, `"1.0"`) |
| `created` | `std::optional<UtcTime>` | Creation timestamp |
| `modified` | `std::optional<UtcTime>` | Last modification timestamp |
| `subjects` | `std::vector<MnaSubject>` | Subjects in the project |
| `pipeline` | `std::vector<MnaNode>` | Processing pipeline nodes |
| `extras` | `JsonObject` | Unknown keys, kept for a lossless round trip |

| Method | Description |
|---|---|
| `to_json()` / `from_json()` | JSON serialization |
| `to_cbor()` / `from_cbor()` | CBOR serialization |
| `read(path)` | Read from `.mna` or `.mnx`; returns `Expected<MnaProject>` |
| `write(path)` | Write to `.mna` or `.mnx`; returns `Expected<void>` |

### MnaSubject

```cpp
mne::MnaSubject subject;
subject.id             = "sample";
subject.freesurfer_dir = "subjects/sample";
```

| Member | Type | Description |
|---|---|---|
| `id` | `std::string` | Subject identifier |
| `freesurfer_dir` | `std::string` | Relative path to FreeSurfer directory |
| `sessions` | `std::vector<MnaSession>` | Sessions for this subject |

### MnaSession

| Member | Type | Description |
|---|---|---|
| `id` | `std::string` | Session identifier |
| `recordings` | `std::vector<MnaRecording>` | Recordings in this session |

### MnaRecording

| Member | Type | Description |
|---|---|---|
| `id` | `std::string` | Recording identifier |
| `files` | `std::vector<MnaFileRef>` | Files belonging to this recording |

### MnaFileRef

```cpp
mne::MnaFileRef ref;
ref.role   = mne::MnaFileRole::Raw;
ref.path   = "data/sample_audvis_raw.fif";
ref.format = "fiff";
if (auto embedded = ref.embed("/data/sample_audvis_raw.fif"); !embedded) {
    std::println(stderr, "{}", embedded.error().what());
}
```

| Member | Type | Description |
|---|---|---|
| `role` | `MnaFileRole` | Semantic role of the file |
| `path` | `std::string` | Relative POSIX path from project root |
| `sha256` | `std::string` | SHA-256 hash of file contents |
| `format` | `std::string` | File format string (e.g., `"fiff"`, `"stc"`, `"mgh"`) |
| `size_bytes` | `std::int64_t` | File size in bytes |
| `embedded` | `bool` | Whether data is embedded in the MNA container |
| `data` | `std::vector<std::byte>` | Embedded file data (only when `embedded == true`) |

| Method | Description |
|---|---|
| `embed(file)` | Read a file into `data`, set `size_bytes` and `embedded` |
| `extract(file)` | Write `data` to a file |

## Computational Graph

### MnaGraph

The graph container manages nodes, ports, connections, and validation:

```cpp
#include <mne/mna/mna_graph.h>

mne::MnaGraph graph;
graph.add_node(read_raw);
graph.add_node(filter);
graph.add_node(inverse);

graph.connect("read_raw_01", "raw", "filter_01", "raw_input");
graph.connect("filter_01", "filtered_raw", "inverse_01", "raw_input");

for (const std::string& error : graph.validate()) {
    std::println(stderr, "{}", error);
}
```

| Method | Description |
|---|---|
| `add_node(node)` | Add a node to the graph |
| `remove_node(node_id)` | Remove a node by ID |
| `node(node_id)` | Access a node by ID; throws `std::out_of_range` for an unknown ID |
| `find_node(node_id)` | Pointer to a node, or `nullptr` |
| `nodes()` | Access the full node list |
| `has_node(node_id)` | Check if a node exists |
| `connect(src, src_port, dst, dst_port)` | Connect an output port to an input port |
| `validate()` | Problems with acyclicity, port connections, data kinds and schemas; empty if valid |
| `topological_sort()` | Node IDs in execution order |
| `upstream_nodes(id)` / `downstream_nodes(id)` | Nodes a node depends on / that depend on it |
| `dirty_nodes()` | Nodes that need re-execution |
| `to_json()` / `from_json()` | JSON serialization |
| `to_cbor()` / `from_cbor()` | CBOR serialization |

| Member | Type | Description |
|---|---|---|
| `graph_inputs` | `std::vector<MnaPort>` | Named, typed graph-level entry points |
| `graph_outputs` | `std::vector<MnaPort>` | Named, typed graph-level exit points |
| `param_tree` | `MnaParamTree` | Hierarchical parameter store |

### MnaNode

A single processing step in the graph:

```cpp
mne::MnaNode node;
node.id         = "filter_01";
node.op_type    = "dsp.band_pass_filter";
node.attributes = {{"low_freq", 1.0}, {"high_freq", 40.0}};
node.inputs.push_back({.name = "raw_input", .data_kind = mne::MnaDataKind::FiffRaw});
node.outputs.push_back({.name = "filtered_raw", .data_kind = mne::MnaDataKind::FiffRaw,
                        .direction = mne::MnaPortDir::Output});
```

| Member | Type | Description |
|---|---|---|
| `id` | `std::string` | Unique node identifier |
| `op_type` | `std::string` | Operation type (looked up in `MnaOpRegistry`) |
| `attributes` | `JsonObject` | Operation parameters |
| `inputs` | `std::vector<MnaPort>` | Input ports |
| `outputs` | `std::vector<MnaPort>` | Output ports |
| `exec_mode` | `MnaNodeExecMode` | Execution mode (`Batch`, `Stream`, `Ipc`, `Script`) |
| `ipc_command` | `std::string` | External executable (for `Ipc` mode) |
| `ipc_args` | `StringList` | Command-line arguments with `{{placeholder}}` tokens |
| `ipc_work_dir` | `std::string` | Working directory for external process |
| `ipc_transport` | `std::string` | `"stdio"`, `"tcp"`, `"shm"`, `"file"` |
| `script` | `MnaScript` | Inline source code (for `Script` mode) |
| `verification` | `MnaVerification` | Pre/post-condition checks and provenance |
| `tool_version` | `std::string` | Version of tool that last executed this node |
| `executed_at` | `std::optional<UtcTime>` | Timestamp of last execution |
| `dirty` | `bool` | Whether the node needs re-execution |

### MnaPort

| Member | Type | Description |
|---|---|---|
| `name` | `std::string` | Port name (unique within a node) |
| `data_kind` | `MnaDataKind` | Type of data flowing through |
| `direction` | `MnaPortDir` | `Input` or `Output` |
| `source_node_id` | `std::string` | Upstream node ID (input ports only) |
| `source_port_name` | `std::string` | Upstream output port name |
| `stream_protocol` | `std::string` | Real-time protocol: `"fiff-rt"`, `"lsl"`, `"tcp"`, `"shm"` |
| `stream_endpoint` | `std::string` | Protocol-specific address |
| `stream_buffer_ms` | `int` | Ring-buffer length in ms (0 = unbounded) |
| `cached_result_path` | `std::string` | Path to cached result file |
| `cached_result_hash` | `std::string` | SHA-256 for cache invalidation |

## Operator Schemas and Registry

### MnaOpSchema

Declarative contract for an operation:

```cpp
#include <mne/mna/mna_op_schema.h>

mne::MnaOpSchema schema;
schema.op_type     = "dsp.band_pass_filter";
schema.version     = "2.2.0";
schema.binding     = "internal";
schema.category    = "preprocessing";
schema.description = "Apply a band-pass FIR filter";
schema.library     = "mne_dsp";
schema.input_ports.push_back({.name = "raw_input", .data_kind = mne::MnaDataKind::FiffRaw});
schema.attributes.push_back({.name = "low_freq", .type = mne::MnaAttrType::Double, .required = true,
                             .description = "Lower cutoff frequency in Hz"});
```

| Method | Description |
|---|---|
| `validate(node)` | Ways in which a node does not conform to this schema; empty if it does |

### MnaOpSchemaPort

| Member | Type | Description |
|---|---|---|
| `name` | `std::string` | Port name |
| `data_kind` | `MnaDataKind` | Expected data kind |
| `required` | `bool` | Must be connected? |
| `description` | `std::string` | Human-readable description |

### MnaOpSchemaAttr

| Member | Type | Description |
|---|---|---|
| `name` | `std::string` | Attribute key |
| `type` | `MnaAttrType` | Expected value type: `String`, `Double`, `Float`, `Int`, `Bool` |
| `required` | `bool` | Must be set? |
| `default_value` | `JsonValue` | Default when not set; undefined if there is none |
| `description` | `std::string` | Human-readable description |

### MnaOpRegistry

Singleton catalog of all registered operations:

```cpp
#include <mne/mna/mna_op_registry.h>

auto& registry = mne::MnaOpRegistry::instance();
registry.register_op(schema);
registry.register_op_func("dsp.band_pass_filter",
                          [](const mne::MnaValues& inputs, const mne::JsonObject& attributes) {
                              mne::MnaValues outputs;
                              // ... std::any_cast the inputs, compute, fill outputs
                              return outputs;
                          });

const bool exists = registry.has_op("inv.compute_mne");
registry.load_registry_files();
```

| Method | Description |
|---|---|
| `instance()` | Access the singleton |
| `register_op(schema)` | Register an operation schema |
| `has_op(op_type)` | Check if an op type is registered |
| `schema(op_type)` | The schema for an op type |
| `registered_ops()` | All registered op type strings |
| `register_op_func(op_type, func)` | Register an implementation (`OpFunc`) |
| `op_func(op_type)` | The implementation function |
| `load_registry_files()` | Load registry files from `resources/mna/` next to the executable |
| `missing_ops(tools)` | Op types of the given tools that are not registered |

### MnaRegistryLoader

Loads operator schemas from declarative JSON manifest files:

| Method | Description |
|---|---|
| `load_file(path, registry)` | Load a single manifest file |
| `load_directory(dir, registry)` | Load master manifest + drop-in files from `mna-registry.d/` |
| `save_file(path, provider, registry)` | Serialize current registry to a JSON manifest |

## Execution

### MnaGraphExecutor

```cpp
#include <mne/mna/mna_graph_executor.h>

// Full execution
auto context = mne::MnaGraphExecutor::execute(graph, {{"raw_file", std::string("/data/sample_audvis_raw.fif")}});
if (!context.aborted_node.empty()) {
    std::println(stderr, "stopped at {}", context.aborted_node);
}

// Access results
const std::any& stc = context.results.at("inverse_01::source_estimate");

// Incremental execution (only dirty nodes)
mne::MnaGraphExecutor::execute_incremental(graph, context);
```

| Method | Description |
|---|---|
| `execute(graph, inputs)` | Execute all nodes in topological order |
| `execute_incremental(graph, context)` | Execute only dirty nodes and their dependents |
| `execute_node(node, inputs)` | Execute a single node |
| `set_progress_callback(callback)` | Set a per-node progress callback |
| `start_stream(graph, factory)` / `stop_stream(context)` | Run `Stream` nodes as live plugins created by the factory |

#### Context

The execution context (`MnaGraphExecutor::Context`) holds:

| Member | Type | Description |
|---|---|---|
| `results` | `MnaValues` | `nodeId::portName` → data |
| `graph_inputs` | `MnaValues` | Graph-level inputs populated before execution |
| `aborted_node` | `std::string` | Node whose failed `"error"` check stopped the run; empty if it ran to the end |

## Parameters

### MnaParamTree

```cpp
#include <mne/mna/mna_param_tree.h>

mne::MnaParamTree tree;
tree.set_param("filter_01/low_freq", 1.0);
tree.set_param("filter_01/high_freq", 40.0);

const double low = tree.param("filter_01/low_freq").to_double();  // 1.0
const bool has = tree.has_param("filter_01/low_freq");            // true
```

| Method | Description |
|---|---|
| `set_param(path, value)` | Set a parameter value |
| `param(path)` | A parameter value; undefined if not set |
| `has_param(path)` | Check if a parameter exists |
| `all_paths()` | All parameter paths |
| `add_binding(binding)` | Add a dynamic binding |
| `remove_binding(target_path)` | Remove a binding |
| `bindings()` | All bindings |
| `has_binding(target_path)` | Check if a binding exists |
| `evaluate(results)` | Evaluate all `on_change` bindings; returns the changed paths |
| `evaluate_expression(expr, results)` | Evaluate a single expression; undefined if it cannot be evaluated |

Expressions support numbers, `'text'`, parameter paths, `ref('path')`, `clamp`, `scale`, `threshold`, `lerp`, `+ - * /`, parentheses and comparisons.

### MnaParamBinding

```cpp
mne::MnaParamBinding binding;
binding.target_path  = "inverse_01/lambda2";
binding.expression   = "1 / (ref('inverse_01/snr') * ref('inverse_01/snr'))";
binding.trigger      = "on_change";
binding.dependencies = {"inverse_01/snr"};
tree.add_binding(binding);
```

| Member | Type | Description |
|---|---|---|
| `target_path` | `std::string` | Parameter to control: `"nodeId/attrKey"` |
| `expression` | `std::string` | Formula string |
| `trigger` | `std::string` | `"on_change"`, `"periodic"`, `"manual"` |
| `period_ms` | `int` | Period for periodic triggers (ms) |
| `dependencies` | `StringList` | Paths this binding reads from |

## Script Support

### MnaScript

Inline code embedded in nodes (for `Script` exec mode) or verification checks:

```cpp
mne::MnaScript script;
script.language    = "python";
script.interpreter = "python3";
script.code        = "import mne\nraw = mne.io.read_raw_fif('{{raw_path}}')\nraw.filter(1, 40)\nraw.save('{{output_path}}')";
```

| Member | Type | Description |
|---|---|---|
| `language` | `std::string` | `"python"`, `"shell"`, `"r"`, `"matlab"`, `"octave"`, `"julia"` |
| `interpreter` | `std::string` | Interpreter command; empty = auto-detect |
| `interpreter_args` | `StringList` | Extra args before the script file |
| `code` | `std::string` | The inline source code |
| `source_uri` | `std::string` | Optional authoring-time reference |
| `code_sha256` | `std::string` | SHA-256 of `code` for integrity |
| `keep_temp_file` | `bool` | Preserve temp script file after execution |

## File I/O

### MnaIO

Read/write MNA project files. Dispatches by file extension:

```cpp
#include <mne/mna/mna_io.h>

auto project = mne::MnaIO::read("pipeline.mna");
if (!project) {
    std::println(stderr, "{}", project.error().what());
    return 1;
}

auto json = mne::MnaIO::write(*project, "pipeline.mna");   // JSON
auto cbor = mne::MnaIO::write(*project, "pipeline.mnx");   // compact binary
```

| Method | Description |
|---|---|
| `read(path)` | Read an MNA project from `.mna` (JSON) or `.mnx` (CBOR); returns `Expected<MnaProject>` |
| `write(project, path)` | Write an MNA project to `.mna` or `.mnx`; returns `Expected<void>` |
| `to_mnx(project)` | The `.mnx` bytes of a project, without writing a file |

## Built-in Operations

The MNA registry ships with built-in operations covering common workflows:

| Namespace | Operation | Description |
|---|---|---|
| `io` | `io.read_raw_fif` | Load a raw FIFF file |
| `io` | `io.write_raw_fif` | Save a raw FIFF file |
| `io` | `io.read_forward` | Load a forward solution |
| `io` | `io.read_covariance` | Load a noise-covariance matrix |
| `io` | `io.read_source_space` | Load a source space |
| `dsp` | `dsp.band_pass_filter` | Apply a band-pass FIR filter |
| `dsp` | `dsp.compute_covariance` | Compute noise covariance from raw data |
| `fwd` | `fwd.make_forward` | Compute forward solution |
| `fwd` | `fwd.make_bem_model` | Compute BEM model |
| `inv` | `inv.compute_mne` | Compute MNE/dSPM/sLORETA inverse |
| `inv` | `inv.dipole_fit` | Sequential dipole fitting |

Custom operations can be registered at runtime via `MnaOpRegistry::register_op()` and `MnaOpRegistry::register_op_func()`.

## MNE-Python Cross-Reference

| MNE-CPP (mne_mna) | MNE-Python Equivalent |
|---|---|
| `MnaProject` | No direct equivalent (closest: `mne.Report` or BIDS-based project management) |
| `MnaGraph` / `MnaNode` | No direct equivalent (MNE-Python uses procedural scripting) |
| `MnaIO::read()` / `write()` | No direct equivalent |
| `MnaOpRegistry` | No direct equivalent |

The MNA format is unique to MNE-CPP and fills a gap in the MNE ecosystem by providing a declarative, executable project format.
